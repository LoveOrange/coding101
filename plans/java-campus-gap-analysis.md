# Java 校招资源站目标对照

本文件对照[用户故事地图](./java-campus-user-story-map.md)检查当前实现。范围为当前工作区；线上版本以 GitHub Pages 部署提交为准。

| 用户故事 | 当前实现 | 仍需注意的边界 |
| --- | --- | --- |
| 我想知道后端岗位要求什么 | 20 条 JD、11 家公司，2027 校招季标签、逐公司详情和投递链接 | 全栈与 AI 方向明确标注；样本不能代表所有 Java 岗位，开放状态以原页为准 |
| 我想用两周抓住重点 | 20 个核心主题有前置、67 篇阅读范围、停止条件和题目入口 | 两周是取舍情境，用户自行估计时间，不承诺读完全部核心 |
| 我想用一个月理解原理 | 同一知识正文提供核心、深入与按岗范围，路线保留三个回答深度 | 时间更长也不等于所有架构和专项内容都必读 |
| 我想知道面试可能怎么问 | 40 个公开面试流程归纳 20 组考点；277 道文章题目可按主题查找 | 仅 7 条日期在最近 18 个月；2 条历史流程为检索返回正文，不能声称均直接读到页面 |
| 我想检查自己是否会 | 题目、默认折叠答案、原理锚点、编码和 SQL 练习 | 网站不评分；题目总数不等于已逐题完成全部来源和技术复审 |
| 我想准备简历与项目 | 写法、教学示例、空白模板、真实贡献与验证证据清单 | 不接收简历、不分析个人经历、不虚构业务指标 |
| 我想回查刚遇到的问题 | 主题索引到题目，再回到具体原理章节；首页和标签提供直接入口 | 外部来源可能失效，需持续维护 |

当前主要产品缺口已由资源与导航补齐，阅读流程不再依赖进度、自评或自动续学。后续优先处理内容质量：补近期可追溯面经、复核公司归属和版本边界、按实际 JD 增加必要专项。没有证据支持扩展所有岗位、完整架构课程或用户状态服务。

数据与生成机制见[首版交付](./java-campus-weekend-plan.md)，内容对应关系见[证据与内容映射](./java-campus-content-mapping.md)。
