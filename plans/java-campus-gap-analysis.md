# Java 校招产品目标对照

本文件对照[项目计划](./product-roadmap.md)与[用户故事地图](./java-campus-user-story-map.md)，区分当前工作区能力和待建设目标。线上状态以实际部署提交为准，已有题目与链接不代表独立闪卡已经完成。

| 能力 | 当前依据 | 待建设目标 |
| --- | --- | --- |
| 岗位与面经资料 | JD 与面经台账、生成页面已有；来源状态见[资源与研究说明](./java-campus-weekend-plan.md) | 持续补近期来源、核验公司归属和适用范围；不推断全市场频率 |
| 岗位路线 | [Java 路线](../src/data/interviewRoadmaps/java.ts)有主题、优先级、回答深度和文章引用 | 已形成[原子考点清单评审稿](./knowledge-tree/m1-knowledge-points.md)；M1 仍需核定范围并接入知识点与岗位模型 |
| 核心阅读 | [阅读资源](../src/data/reviewPlans/javaReadingResources.json)记录章节范围、前置与题目链接 | M1 核定首批清单，补缺失解释，建立稳定文章与知识点关联 |
| 文章自测 | [Review 组件](../src/components/Review/index.tsx)提供核心范围、题目入口和下一篇导航；正文有折叠答案 | M1 将合格题目整理成单一来源的卡片，文内引用与独立练习共享问答 |
| 独立闪卡 | 现有题目索引可回到正文，尚无目标模型要求的统一卡片实体与练习流程 | M1 原子问题、自检要点、多篇关联文章、会话内重练 |
| 标签与检索 | 已有文档标签与主题入口 | M1 建立知识点派生岗位标签，完成文章与卡片混合检索及筛选 |
| 编码与求职材料 | [编码与 SQL](../docs/interview/coding-practice.mdx)、[简历](../docs/interview/resume.mdx)、[项目](../docs/interview/project-preparation.mdx)资料已有 | 保留独立练习与材料入口；不将卡片回答等同于实际完成 |
| 个人复习状态 | 当前阅读与路线组件不保存个人复习进度 | M2 保存自评与练习记录，支持跨设备继续及内容修订后的复习处理 |
| 用户与计划 | 尚无本计划定义的账户、个人任务与间隔复习服务 | M2 用户管理、可调整的个人计划、待复习队列 |

M1 的差距包括内容结构、卡片质量、岗位映射和两条完整学习路径。M2 在这些内容与引用稳定后加入个人数据服务。详细任务、依赖和完成标准统一维护在[项目计划](./product-roadmap.md)，不以已有文章数量判断里程碑完成。
