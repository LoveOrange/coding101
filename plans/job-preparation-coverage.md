# 求职准备内容覆盖检查

Coding 101 当前能够支持以 Java 后端为主的技术知识复习，但还不能满足技术求职者的一站式准备。通用基础已有第一轮阅读链路；岗位选择、简历项目、完整设计演练与面试反馈之间仍有断点。

检查范围为当前工作区的文档、路线数据与页面实现，不代表线上部署已经同步。评价单位是求职者能否完成一项准备任务，不以文章数量或规划中的栏目数量代替可用能力。

## 1. 验收标准

读者应能完成以下流程：选择目标岗位并解读 JD，确定优先级和停止条件，补技术基础，练习现场编码，准备可信的项目与经历，完成适用岗位的系统设计及行为面演练，最后根据模拟或真实面试反馈调整复习。

官方招聘资料也强调这些环节的组合：[Amazon 的软件开发面试主题](https://www.amazon.jobs/content/en/how-we-hire/interview-prep/software-development-topics)覆盖编码、设计与行为问题；[Microsoft 的技术面试说明](https://careers.microsoft.com/v2/global/en/hiring-tips/technical-interviewing.html/)要求展示问题分析、可运行代码和测试能力。这些来源用于核验评价维度，不把一家公司的流程套用到所有岗位。

| 求职任务 | 当前状态与仓库证据 | 对读者的影响 | 优先级 |

| 自测与复习反馈 | Java 路线有本地进度，部分文章有折叠答案，集合专题有专项复习界面 | 勾选属于自报进度；没有跨主题的统一诊断、错因记录和模拟面试反馈；本地数据不等于跨设备学习账户 | P1 |
| 资料质量 | 新文有一手参考资料；有证据的题目记录公司与面经，其余标为本站自测 | 存量仍有草稿、重复内容、公司来源缺项和目录归属问题，需要持续校验 | P1 |

P0 表示会让目标流程直接中断，P1 表示能阅读但练习或反馈不足。投递管理和薪酬比较可以作为以后扩展，不是当前技术面试准备站必须先建设的功能。

## 3. 通用基础的完成边界

本轮生成的是第一轮必会内容和必要的常考前置：8 篇数据结构、7 篇算法、7 篇操作系统、4 篇网络、5 篇 SQL／约束／执行计划、2 篇 Redis，共 33 篇；Git 第一次提交教程补成可操作正文。已有算法、事务、锁、缓存一致性、消息、测试、鉴权与交付文章继续复用。

入口已接入基础知识、算法首页入口、岗位目录与 Java 路线。SQL 与操作系统进入 Java 必会主题，DNS、TLS、执行计划与 Redis 生命周期进入相关阅读。

[通用基础规划](./knowledge-tree/foundations.md)中的全部按岗选学并未完成：例如向量索引、WebSocket/SSE、存储引擎日志、专门的图算法与性能测试仍是后续任务。存量文章搬迁与合篇拆分也未混入本轮正文生成。

## 4. 后续实施顺序与验收

1. **完成 Java 求职全流程。** 补 JD 解读、简历核对、项目介绍、项目故障复盘和行为面试；读者应能输出一份 JD 对照表、一张项目图、两段有证据的经历回答，并经受连续追问。无需先增加更多岗位名称。
2. **完成两个系统设计案例。** 先补已有 Pastebin 与网页爬虫；每个案例包含需求澄清、数量估算、数据模型、最小读写路径、失败与取舍，以及折叠参考方案。
3. **建立按主题练习与复测。** 每个算法模式配置一题基础练习、一题迁移练习；SQL 配综合查询；用正确性、边界、复杂度和表达记录薄弱点，不用已读数量当掌握度。
4. **再扩展下一条完整岗位路线。** 根据实际用户和招聘需求选一个方向，补齐对应语言、框架、项目与面试环节后再标记可用；共用内容继续引用现有正文。
5. **持续整理内容。** 从高频重复和有误导的存量建议开始，更新标题、来源、归属和链接，并保持规划与实际文件一致。

上线验收应使用真实候选人的完整任务走查：从首页出发选择方向，找到今日复习内容，完成一道题和一次口述，定位薄弱点，再找到下一步。在上述 P0 缺口补齐前，产品定位应保持“Java 后端与通用基础复习”，避免宣称已经覆盖所有技术岗位的一站式准备。

## 5. 验证与限制

- 站点构建、TypeScript 类型检查、文档链接规范检查通过；新增正文的本地引用与页面标题一致，折叠答案默认关闭。
- 直接提取文章中的 Java 实现，用临时 JDK 21 编译运行；通过边界、随机数据与穷举对照检查，覆盖二分、双指针、Top K、前缀和、递归、链表反转、回溯和贪心。
- SQL 的 7 组查询结果、NULL 与约束行为使用 SQLite 内存库验证通用语义；MySQL 8.4 特有的执行计划、排序规则与实现保证依据官方文档核验，未在 MySQL 实例实跑。
- Git 教程在独立临时仓库中验证暂存、提交内容和取消暂存；浏览器检查通用入口、SQL 正文与答案展开、Java 新主题入口。
- 存量博客仍有作者配置和截断标记提醒；本轮没有宣称全站存量文章已逐篇完成事实审校，也没有发布线上站点。
