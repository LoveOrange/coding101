# 求职准备内容覆盖检查

Coding 101 当前以 Java 后端与共享技术基础为主要准备范围。本文按求职任务检查内容边界；产品任务与里程碑统一见[项目计划](./product-roadmap.md)，功能现状见[目标对照](./java-campus-gap-analysis.md)。文章和闪卡服务于知识理解与自测，编码实现、项目表达等任务仍需实际练习。

## 1. 内容覆盖与建设范围

| 求职任务 | 当前内容入口 | 本轮安排与边界 |
| --- | --- | --- |
| 确定目标岗位 | [路线目录](../src/data/interviewRoadmaps/outlineCatalog.ts) | M1 优先核定 Java 后端校招范围；其余岗位不能仅凭目录入口宣称可用 |
| 按范围学习 | [Java 路线](../src/data/interviewRoadmaps/java.ts)、[通用基础](../docs/basic-knowledge/common/index.mdx) | M1 将知识点、文章章节、停止条件与卡片对应，补首批必会知识的解释和前置 |
| 现场编码与 SQL | [编码与 SQL 练习](../docs/interview/coding-practice.mdx)、算法主题与现有题解 | 保留动手任务、自检条件和参考实现，不用回答卡片替代实现能力 |
| 简历与项目表达 | [简历准备](../docs/interview/resume.mdx)、[项目准备](../docs/interview/project-preparation.mdx) | 已有指南继续维护；个人材料分析不属于 M1、M2 必交功能 |
| 系统设计与综合讨论 | [系统设计](../docs/system-design/index.mdx)及案例内容 | 校招所需基础按清单进入 M1；完整案例需单独复核，不要求完成全部设计课程 |
| 经历与行为面准备 | [面试流程](../docs/interview/interview-process.mdx)和项目指南 | 按真实经历准备并实际口述；不将技术卡片覆盖等同于完整面试准备 |
| 知识自测与回查 | 文章折叠答案、题目索引和章节链接 | M1 增加独立闪卡、多篇关联阅读、检索和会话内重练 |
| 持续复习 | 当前用户自行安排与记录 | M2 增加账户、自评记录、个人计划和间隔复习 |

## 2. 内容验收

按知识点核定范围：每个纳入首批必会范围的目标都应有可发布解释、可独立作答的问题、自检要点和有效的原理链接。文章可服务多个考点，卡片可关联多篇文章；岗位关系和优先级从知识点层维护。

现有题目需要逐项检查问题粒度、答案边界、版本和来源。公开面经只证明出现过某个问题，资料数量不证明频率或面试命中率。前置不足、草稿、占位页与缺少技术核验的内容不得计入完成。

Go、Node.js、AI 应用及其他方向按后续岗位需求扩展。上线说明只描述已经验收的内容和功能，不将规划中的多岗位覆盖、个人计划或完整模拟面试写成现有能力。
