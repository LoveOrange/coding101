# 欢迎来到 Coding 101

欢迎来到 Coding 101。

Coding 101 是一个面向软件从业者的知识站。本站会记录不同岗位、不同职级的开发者需要掌握的开发技能，也会整理应聘相关岗位时需要进行的面试准备。

## Coding 101 适合哪些读者

**软件行业从业者**：根据当前岗位和职业阶段，补充需要掌握的开发技能，继续学习更深入的技术内容。

**学生**：从计算机基础、编程语言和开发工具开始，按照清晰的顺序学习软件开发需要的知识。

**求职者**：根据目标岗位和职级确定复习范围，找到需要优先准备的知识点、算法题、项目内容和面试经验。

## Coding 101 包含哪些内容

本站会持续整理以下内容：

- **计算机基础**：数据结构、算法、操作系统、计算机网络和数据库等基础知识。
- **编程语言与技术栈**：不同编程语言、框架和工具的学习路线与实践内容。
- **开发工具与工程技能**：Git、测试、构建、发布、故障排查等日常开发能力。
- **系统设计**：从常见系统开始，学习架构设计、分布式系统和方案取舍。
- **面试准备**：按照岗位和职级整理复习路线、常见考点、算法题、项目准备与面试经验。

> **更新说明**：Coding 101 仍在建设中。目前已经包含 LeetCode 题解、计算机基础、数据库、系统设计、Git 和面试准备等内容，其他技术栈与岗位路线会继续补充。

## 如何使用 Coding 101

### 学习开发技能

1. 选择当前岗位、希望学习的技术栈，或者需要补充的基础知识。
2. 按照对应路线确认学习顺序和目标深度。
3. 进入具体文章学习，并通过题目或实践检查掌握程度。
4. 已经掌握的内容可以跳过，遇到缺少的前置知识再回来补充。

### 准备技术面试

1. 确定目标岗位和大致职级。
2. 查看对应的面试路线，先复习高优先级内容。
3. 根据岗位要求、个人简历和薄弱项调整复习顺序。
4. 完成知识复习后，继续准备算法题、简历项目和模拟面试。

> **不知道从哪里开始？** 在职者可以从当前使用的技术栈开始，学生可以先学习计算机基础，求职者可以直接选择目标岗位。
