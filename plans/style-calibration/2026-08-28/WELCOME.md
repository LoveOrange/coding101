# 欢迎来到 Coding 101

Coding 101 是一个面向技术岗位求职者的就业准备网站。本站按照目标岗位整理复习范围、优先级和回答深度，帮助你把有限时间用在更可能影响面试结果的内容上。

## 适合哪些读者

- 正在准备校招、社招或转岗面试，希望快速确定复习范围。
- 已经有技术基础，但面对大量资料时无法判断先学什么、学到哪里。
- 需要检查技术答案、算法、项目介绍和系统设计是否达到面试要求。

本站不提供职业晋升或通用管理成长路线。资深岗位涉及的架构和协作内容，只会作为对应岗位的面试准备出现。

## 提供什么

- **岗位路线**：按照目标岗位组织知识顺序、复习优先级和回答深度。
- **技术文章**：先给核心结论，再解释支撑结论所需的机制和边界。
- **面试自测**：用代表性问题检查你能否独立解释，而不是继续堆积阅读量。
- **算法与项目准备**：补齐现场编码、简历项目和系统设计环节。

> **更新说明**：Coding 101 仍在建设中。当前重点是 Java 后端开发面试路线，其他岗位路线会逐步补充。

## 如何使用

1. 确定目标岗位，进入对应面试路线。
2. 第一轮只完成“必会”和每个 Topic 的“核心阅读”。
3. 合上文章完成自测问题，再进入“常考”。
4. “按岗选学”和深入阅读只根据 JD、简历项目与面试反馈补充。

> **不知道从哪里开始？** Java 后端求职者可以直接进入 Java 后端开发面试路线，从第一阶段的“必会”内容开始。
