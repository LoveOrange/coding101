## 修订大纲

核心结论：训练改变模型参数；生成时，模型利用已有参数和当前上下文逐步预测 Token。这些机制共同解释模型的能力、输出差异与限制。

1. 面试核心：按正文顺序概括模型定位、Token、上下文、训练、生成、采样和能力边界。
2. 语言模型与生成式 AI：解释文本任务怎样通过生成完成，辨清机器学习、深度学习与生成式 AI 的关系，定义模型参数。
3. Token 与上下文窗口：
   - 分词器：用中英文对照解释 Token 与字数的关系。
   - 上下文窗口：解释输入、历史与生成内容的关系，以及长度限制和上下文记忆。
   - Token 用量与费用：简要说明计量方式、推理 Token 与输出预算。
4. 训练与生成：
   - 训练阶段：先区分训练与推理，再解释预训练、指令微调、偏好优化各自的训练信号。
   - 一次生成的过程：解释向量、注意力与候选概率的基本关系，再讲预填充、逐步解码和停止条件。
5. 采样参数：保留参数对照、候选概率示例与贪心解码；输出一致性解释计算差异如何改变候选排名并影响后续生成。
6. 能力边界：说明信息时效、事实可靠性、精确计算和外部执行的限制，与前文的训练和生成机制对应。
7. 面试题：七道卡片按正文主题重排，使用“回答要点”和“进一步探索”。每条先直接给出核心内容，再解释原因、条件或例子。
8. 参考资料：保留核验依据，新增 Transformer 原论文作为基础计算过程的依据。

术语随正文引入，不另设术语表。采用时保留 `knowledge.id: ai.llm.llm-basics` 和七道题目的显式 ID；三个不再独立成节的旧锚点以兼容标记保留，跨文章引用更新到实际讲解位置。临时文章及卡片到原 ID 的映射已登记在 `src/data/contentMoves.json`。

## 大纲回检

调整前的正文顺序为“Token 与用量 → 上下文与预算 → 生成与缓存 → 采样 → 概念关系、训练与能力边界”。

- **模型定位应先于具体调用知识。** 将语言模型的用途及其与机器学习等概念的关系前移，先回答读者正在认识什么。
- **训练与生成需要区分并建立联系。** Token 定义之后讲训练目标，再解释模型如何使用已有参数生成，避免把普通对话中的上下文变化误认为参数更新。
- **生成过程需要必要的计算解释。** 增加 Token ID、向量、注意力和候选概率之间的关系，补足仅列服务处理步骤留下的理解缺口；详细注意力计算仍由相邻文章承接。
- **费用、预算与缓存不应成为基础认识的主线。** 合并用量和推理预算，保留支持结论的简短例子；删除独立的前缀缓存小节。缓存条件、结构化输出、结果缓存等补充留在卡片或对应专题。
- **能力边界需要独立收束前文。** 读者理解训练数据、上下文和生成机制之后，再解释模型为什么需要外部信息、事实验证及工具执行。
- **核心摘要和卡片应与正文同步。** 面试核心按新顺序重写；卡片保留稳定 ID，重排顺序并更新“相关内容”，继续沿用现有组件与样式。
