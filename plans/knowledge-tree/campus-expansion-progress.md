## 研究口径

每个方向先核验至少 100 篇符合纳入规则的候选人校招或实习复盘，再依据实际披露的问题校准文章范围。当前主样本如下：

| 方向 | 主样本篇数 |
| --- | --- |
| 前端 | 101 |
| 移动端 | 100 |
| 测试开发 | 102 |
| Go 后端 | 101 |
| 各方向主样本记录合计 | 404 |

404 是各方向纳入记录的合计，不用于声称跨方向全局去重后的独立作者或独立访谈数量。补充材料与排除项单独保存，不混入主分母；符合纳入规则但没有披露具体提问的复盘仍保留在分母中。移动端等方向的子分层可以重叠，不能简单相加。

题目归纳以原帖正文和实际查看的附件为依据，保留定位与归属边界。宽泛问题不能扩写成全部细分考点；候选人的回答、平台生成摘要或站点的教学补充，也不能自动当作面试官的原问。个人项目的协议、设备、规模和结果没有披露时，保持未知，不用教学实验补成个人经历。

“必会”“常考”“按岗选学”综合前置关系、岗位任务和本批证据确定，是复习顺序建议。公开复盘存在检索、自述和年代偏差，样本命中比例不代表市场真实概率；没有被样本点名但承担必要前置职责的概念，也可以保留。
