# 通用基础复习知识树与文档目录

通用基础覆盖数据组织、程序运行、数据存储和服务交付。Java、Agent 和后续岗位路线从这里选择相关节点，语言实现和业务案例引用原理正文。

> 本文是[总纲](../interview-roadmap-outline-proposal.md)的分纲。本轮完成第一轮核心缺口及必要的常考前置，按岗扩展仍为待建设项。默认优先级以 Java 后端为主要参照；Agent 路线保留数据访问、网络、并发、测试与安全核心，算法深度按编码面试要求调整。

## 1. 知识树与停止条件

表中的分组用于导航，具体概念作为独立节点。深入阅读只有在核心停止条件达成后，或目标岗位明确涉及时进入。

| 分组 | 核心节点 | 深入或按岗节点 | 默认优先级／深度 | 前置与停止条件 |
| --- | --- | --- | --- | --- |
| F01 复杂度与正确性 | 算法复杂度、算法正确性、递归 | 摊还分析、循环不变量、递归复杂度 | 必会／原理解释 | 前置：一门语言基本语法。能从操作次数和输入约束推导时间、空间成本，构造空值、重复、极值等反例 |
| F02 线性结构与哈希 | 数组、链表、栈、队列、哈希表 | 双端队列、跳表、位图、布隆过滤器 | 必会／原理解释；扩展结构按岗 | 前置：F01。能解释访问、插入、删除成本及内存组织，按顺序和查找需求选结构 |
| F03 树与图 | 二叉树、二叉搜索树、堆、图、树与图搜索 | 平衡搜索树、Trie、并查集、拓扑排序、最短路径 | 必会／原理解释；后半按编码范围 | 前置：F01/F02。能定义节点与边，选择 DFS/BFS，使用堆处理 Top K，并说明遍历边界 |
| F04 算法模式 | 二分查找、双指针、滑动窗口、前缀和、排序、回溯、动态规划、贪心 | 差分、单调栈、单调队列、区间问题、分治、位运算 | 常见模式必会／原理解释；专题按题型选择 | 前置：F01—F03。能说明模式成立条件、状态与转移，识别不能套用的反例 |
| F05 进程与并发 | 进程与线程、调度、上下文切换、互斥与同步、死锁 | 进程间通信、协程、CPU 缓存一致性、伪共享 | 必会／原理解释 | 前置：基本程序执行。能区分共享和隔离资源，解释等待、竞争和死锁条件 |
| F06 内存与 I/O | 虚拟内存、文件描述符、阻塞与非阻塞 I/O、I/O 多路复用 | 文件系统、页缓存、零拷贝、Reactor、CPU 缓存、Linux 诊断 | 虚拟内存必会，其余常考／原理解释 | 前置：F05。能画出地址访问、缺页和网络 I/O 路径；区分资源不足、阻塞与繁忙计算 |
| F07 网络与传输 | 网络模型、IP、DNS、TCP 与 UDP、TCP 连接 | TCP 可靠传输、流量控制、拥塞控制、NAT | 必会／原理解释；路由细节按岗 | 前置：F05/F06 的基本概念。能串起域名解析、连接、传输、关闭及失败重试 |
| F08 应用协议 | HTTP、TLS、HTTP 缓存 | HTTP/2、HTTP/3、WebSocket、SSE、RPC、序列化协议 | HTTP/TLS 必会，其余常考／原理解释 | 前置：F07。能解释一次 HTTPS 请求、缓存判断与超时；为普通请求和流式响应选协议 |
| F09 关系模型与 SQL | 关系型数据库、数据约束、SQL 查询、SQL 连接、SQL 聚合 | 子查询、窗口函数、范式、CTE | 必会／基础回答与实际查询 | 前置：集合与逻辑条件。能写连接、分组和去重，解释 NULL、重复行及约束对结果的影响 |
| F10 索引与查询 | 数据库索引、B+ 树、聚簇索引、联合索引与覆盖索引、执行计划 | 统计信息、连接算法、排序、深分页 | 必会／原理解释 | 前置：F03/F09。能从过滤与排序条件推导索引范围，用计划解释扫描、回表与查询成本 |
| F11 事务与并发控制 | 数据库事务、事务隔离级别、MVCC、InnoDB 锁、数据库死锁 | 长事务、写偏差、乐观并发控制、串行化实现 | 必会／原理解释；异常场景进入场景分析 | 前置：F05/F09/F10。能画并发时序，解释数据可见性、锁范围和回滚重试，限定具体数据库实现 |
| F12 存储引擎与复制 | InnoDB、Buffer Pool、redo log、undo log、binlog | WAL、LSM 树、MySQL 复制、PostgreSQL、备份恢复 | 常考／原理解释；具体引擎按岗 | 前置：F06/F10/F11。能解释提交与崩溃恢复、日志职责和副本延迟；通用复制与恢复策略引用系统设计 |
| F13 缓存与 Redis | Redis、Redis 数据结构、缓存一致性、缓存穿透／击穿／雪崩、过期、淘汰、持久化 | Redis 复制、Sentinel、Cluster、热点 Key、大 Key、分布式锁 | 核心必会／原理解释；锁和集群按场景深入 | 前置：F02/F05/F11。能解释命中、失效、回源和故障路径，区分缓存数据丢失与业务状态丢失 |
| F14 消息与任务 | 消息队列、消息可靠性、消息幂等性 | Kafka、RabbitMQ、顺序消息、积压、分布式任务调度 | 常考／原理解释 | 前置：事务、重试与幂等。能界定确认和提交时机，解释重复、丢失、乱序与消费失败；任务调度正文归系统设计 |
| F15 搜索与存储选择 | 倒排索引、Elasticsearch、向量索引 | 混合检索、对象存储、文档数据库、图数据库、时序数据库 | 按岗选学；RAG 的检索基础必会／原理解释 | 前置：F01/F03/F10。能按查询条件与更新方式选存储，解释索引可见性和近似检索的代价 |
| F16 工程基础 | Git、测试金字塔、测试替身、Maven、可重复交付、可观测性、生产故障诊断 | 契约测试、性能测试、Docker、CI/CD | Git 与基本测试必会，其余常考／基础回答到场景分析 | 前置：一个可运行程序。能定位变更、验证行为、复现构建，并用指标、日志和追踪检查具体问题 |
| F17 应用安全 | 认证与授权、Session、JWT、OAuth 2.0、Web 应用安全 | OIDC、密钥、证书、审计、供应链安全 | 基础鉴权必会，其他按项目／原理解释 | 前置：F08。能划定身份和资源权限边界，解释输入处理和令牌校验；Agent 额外读取提示注入与工具权限 |

数学、编译原理、Kubernetes 管理和机器学习训练保留为后续相关岗位的分支。本轮只纳入能够支撑上述停止条件的 CPU、运行时和检索基础。

## 2. 第一轮复习集合

| 读者目标 | 先完成的节点 | 自检结果 |
| --- | --- | --- |
| Java 后端核心复习 | 复杂度；数组、链表、哈希、树与堆；进程线程、同步和虚拟内存；DNS/TCP/HTTP/TLS；SQL、索引、事务；Redis 缓存；Git、测试、鉴权 | 能写基本查询和编码题，解释一个请求的运行、持久化与失败过程 |
| AI 应用与 Agent | 基本数据结构；并发任务与 I/O；HTTP/SSE；SQL、索引、事务；向量索引；任务幂等、测试、观测和鉴权 | 能解释模型请求、检索、工具执行、任务保存与取消，定位模型之外的工程错误 |
| 系统设计专项 | 数据访问与存储成本；缓存；消息；网络协议；鉴权与可观测性 | 能为最小读写路径选组件，说明一致性、容量和故障约束 |

算法练习以模式选择为单位。一个主题先完成能体现核心不变量的代表练习，再用另一种题面检查能否迁移；现有 LeetCode 题解继续提供练习入口。

## 5. 归属与质量工作

已有正文继续按当前地址引用，避免相同原理重复维护。目录迁移需要一次性更新正文链接、路线、重定向和页面标题，不能只移动文件。

- 算法与通用测试拟从 Java 调整归属，零拷贝拟归操作系统；语言示例可以保留。
- Maven、可重复交付、可观测性、生产故障诊断和通用安全拟归 tools-and-frameworks；Spring Security 属于 Java。
- 《索引设计》与《数据库索引》仍有重叠，需要按查询优化职责归并。
- 合篇拆分后，原页作为导航或重定向承接；不得继续保留另一套重复正文。
- 新增自测题已区分有公开面经依据与本站自测；没有可靠证据时不填写猜测的公司名称。完整公司来源覆盖仍是编辑工作。

简历、项目与行为面继续归面试准备分支。一站式求职准备的剩余缺口见[内容覆盖检查](../job-preparation-coverage.md)，不把通用基础完成解释为整个求职流程完成。
