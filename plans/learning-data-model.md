# 学习数据原型

本文记录视觉改版分支中闪卡、复习与订阅界面使用的数据结构。它是界面原型的实现说明，不代表账户、支付和服务端已经建设；正式方案仍以[领域术语与内容模型](./content-model.md)和[项目计划](./product-roadmap.md)为准。

## 1. 内容数据

内容数据在构建时由 `plugins/learning-content` 从文档生成，不另外维护卡片文件。

- **领域**：取自 `basicKnowledgeSidebar` 与 `systemDesignSidebar` 的顶层分类，例如“Java”“计算机网络”。
- **主题**：领域下的子分类，例如 Java 的“语言基础”“I/O 与资源管理”；直接放在领域下的文档单独作为一个主题。知识树的第三栏在多篇文章的主题下列出文章，在单篇文章的主题下列出章节。
- **文章**：主题下的所有文档，不含分类首页。记录标题、地址、二级标题、估算阅读时长，以及岗位路线中的优先级。
- **闪卡**：文章“面试题”章节下的每个三级标题是一张卡。问题、出现公司、考察重点、相关内容和参考回答直接读取现有面试题结构，与文章保持同一份来源。
- **优先级与岗位**：从 `src/data/interviewRoadmaps` 读取。文章被多个路线主题引用时取最高优先级；未进入路线的文章不显示优先级。

卡片 ID 由文章的 `knowledge.id` 和卡片显式 ID 组成：`{knowledge.id}#{显式 ID}`（见[元信息规范](./content-schema.md)），移动文件或修改题目措辞都不改变卡片 ID。“相关内容”可以指向其他文章的章节，综合题以 `composite` 标记。

“相关内容”中的章节链接决定卡片关联哪些章节：文章页章节标题下的卡片标记、目录中的卡片图标和“补读”入口都使用这份关联。

全站页面通过全局数据读取压缩后的索引（约 160 KB，gzip 后约 59 KB）；参考回答和考察重点只在复习、闪卡库、题库和模拟测试页面加载。

## 2. 学习者数据

学习者数据保存在浏览器 `localStorage` 的 `coding101.learner.v1` 中，由 `src/learning/store.ts` 统一读写。页面只调用这里的 hooks 和 actions，接入服务端时替换存储实现即可。

| 数据 | 内容 |
| --- | --- |
| 卡片状态 | 上次评分、下次复习日期、间隔天数、次数、暂停、补读标记、答到的要点 |
| 阅读进度 | 读到的二级章节、最后位置、是否读完 |
| 订阅 | 免费、试用、Pro（含方案、到期日、自动续费、扣款失败日期）、到期只读 |
| 记录 | 账单与激活码兑换、复习与测试会话、偏好（岗位、面试日期、每日上限） |

评分间隔使用设计稿的标注：首次“没想起来”为 1 天、“模糊”为 3 天、“记得”为 12 天；之后“模糊”按上次间隔的 1.2 倍、“记得”按 2.5 倍增长。模拟测试按要点覆盖换算评分：全部答到记为“记得”，至少一半记为“模糊”，其余记为“没想起来”。

## 3. 原型限制

- 登录、支付和激活码校验都是模拟实现，数据只存在当前浏览器。
- 激活码规则：16 位，不含 0、O、1、I；以 Y 开头视为年卡，以 M 开头视为月卡，以 X 开头视为已过期，其余视为不存在。
- 价格、试用天数和数据保留期取自设计稿，标记为 `TODO(copy)`，发布前需要确认。

## 4. 当前版本的开放范围

账户相关的功能已经实现，但在有真实账户之前不对读者开放：登录与账户、订阅与激活码、闪卡评分与间隔复习、阅读进度、我的进度、闪卡库、随机自测与模拟测试。默认构建不注册这些页面，导航、知识树、文章页、翻卡和题库也不显示进度、评分和订阅入口。

当前开放的是首页、知识树、文章页、翻卡（可以看参考回答）和题库。`LEARNER_FEATURES=true` 构建或启动站点时开放全部功能；`LEARNER_MOCKS=true` 同时开放全部功能并启用示例数据。

## 5. 页面与本地预览

| 路径 | 设计稿 | 说明 |
| --- | --- | --- |
| `/topics` | 01b | 知识树：岗位筛选、领域、主题、章节 |
| 文档页 | 02 | 知识树文章使用领域侧栏、面试核心、章节卡片标记和面试题卡片区 |
| `/review` | 03、03r、12b | 文章翻卡、今日复习、随机自测和模拟测试作答 |
| `/weak` | 04 | 随机自测结果与补读、重答 |
| `/pricing` | 05 | 大陆版与海外版订阅 |
| `/progress` | 06、06e | 全景进度与今日任务 |
| `/account`、`/account/redeem`、`/account/billing` | 07、07b、07c、07s | 学习偏好、兑换激活码、订阅与账单 |
| `/cards` | 10、10e | 闪卡库 |
| `/questions` | 11 | 题库 |
| `/exam`、`/exam/report` | 12、12c | 模拟测试设置与报告 |

下表中 `/topics`、`/review`（文章翻卡）和 `/questions` 默认开放，其余页面需要开启学习者功能。本地预览不同订阅状态时，用 `LEARNER_MOCKS=true` 构建或启动站点，再在任一学习页面地址后加 `?mock=guest|free|trial|pro|expired`；加 `&region=intl` 切换到海外版。示例数据会覆盖当前浏览器里的学习记录。未设置该环境变量的构建会忽略 `mock` 参数。
