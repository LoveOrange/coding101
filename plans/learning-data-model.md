# 学习数据原型

本文记录视觉改版分支中闪卡、复习与订阅界面使用的数据结构。它是界面原型的实现说明，不代表账户、支付和服务端已经建设；正式方案仍以[领域术语与内容模型](./content-model.md)和[项目计划](./product-roadmap.md)为准。

## 1. 内容数据

内容数据在构建时由 `plugins/learning-content` 从文档生成，不另外维护卡片文件。

- **领域**：取自 `basicKnowledgeSidebar` 与 `systemDesignSidebar` 的顶层分类。文章超过 30 篇的分类（目前是 Java）按子分类拆开，例如“Java · 语言基础”。
- **文章**：领域下的所有文档，不含分类首页。记录标题、地址、二级标题、估算阅读时长，以及岗位路线中的优先级。
- **闪卡**：文章“面试题”章节下的每个三级标题是一张卡。问题、出现公司、考察重点、相关内容和参考回答直接读取现有面试题结构，与文章保持同一份来源。
- **优先级与岗位**：从 `src/data/interviewRoadmaps` 读取。文章被多个路线主题引用时取最高优先级；未进入路线的文章不显示优先级。

卡片 ID 由文章键和题目锚点组成：`{knowledge.id 或文档 ID}#{锚点}`。文章补充 `knowledge.id` 后，ID 不再随文件路径变化；题目标题修改会改变锚点，届时需要为旧 ID 提供迁移。

“相关内容”中的章节链接决定卡片关联哪些章节：文章页章节标题下的卡片标记、目录中的卡片图标和“补读”入口都使用这份关联。

全站页面通过全局数据读取压缩后的索引（约 160 KB，gzip 后约 59 KB）；参考回答和考察重点只在复习、闪卡库、题库和模拟测试页面加载。

## 2. 学习者数据

学习者数据保存在浏览器 `localStorage` 的 `coding101.learner.v1` 中，由 `src/learning/store.ts` 统一读写。页面只调用这里的 hooks 和 actions，接入服务端时替换存储实现即可。

| 数据 | 内容 |
| --- | --- |
| 卡片状态 | 上次评分、下次复习日期、间隔天数、次数、暂停、补读标记、答到的要点 |
| 阅读进度 | 读到的二级章节、最后位置、是否读完 |
| 订阅 | 免费、试用、Pro（含方案、到期日、自动续费、扣款失败日期）、到期只读 |
| 记录 | 账单与激活码兑换、复习与测试会话、偏好（岗位、面试日期、每日上限） |

评分间隔使用设计稿的标注：首次“没想起来”为 1 天、“模糊”为 3 天、“记得”为 12 天；之后“模糊”按上次间隔的 1.2 倍、“记得”按 2.5 倍增长。模拟测试按要点覆盖换算评分：全部答到记为“记得”，至少一半记为“模糊”，其余记为“没想起来”。

## 3. 原型限制

- 登录、支付和激活码校验都是模拟实现，数据只存在当前浏览器。
- 激活码规则：16 位，不含 0、O、1、I；以 Y 开头视为年卡，以 M 开头视为月卡，以 X 开头视为已过期，其余视为不存在。
- 价格、试用天数和数据保留期取自设计稿，标记为 `TODO(copy)`，发布前需要确认。
