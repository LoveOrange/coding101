# 学习数据模型

本文记录当前主题、闪卡、阅读进度与账户页面使用的数据结构。内容概念见[领域术语与内容模型](./content-model.md)，功能范围见[项目计划](./product-roadmap.md)。

## 1. 内容数据

内容数据在构建时由 `plugins/learning-content` 从文档生成，不另外维护卡片文件。

- **领域**：取自 `basicKnowledgeSidebar` 与 `systemDesignSidebar` 的顶层分类，例如“Java”“计算机网络”。
- **主题**：领域下的子分类，例如 Java 的“语言基础”“I/O 与资源管理”；直接放在领域下的文档单独作为一个主题。知识树的第三栏在多篇文章的主题下列出文章，在单篇文章的主题下列出章节。
- **文章**：主题下的所有文档，不含分类首页。记录标题、地址、二级标题、估算阅读时长，以及岗位路线中的优先级。
- **闪卡**：文章“面试题”章节下的每个三级标题是一张卡。问题、考察重点、相关内容和参考回答直接读取现有面试题结构，与文章保持同一份来源。
- **优先级与岗位**：`src/data/interviewRoadmaps/learningRoles.ts` 调用页面使用的路线工厂，按后端语言、前端框架、移动平台与宿主、测试语言生成题库范围。共享文章保存 `rolePriorities`，只在同一岗位内合并重复引用的优先级，不能被其他岗位提升。必会主题中的深入阅读按“常考”处理，核心阅读保留“必会”；未选择岗位或文章未进入所选路线时不显示优先级。
- **选择与跳转**：路线进入题库时带 `role`，题库、翻卡和原文链接继续保留该选择。URL 中明确指定的岗位优先于学习偏好；`role=` 表示全部岗位。旧的前端、移动端和测试岗位 ID 保留为“全部框架／平台／语言”，新选择使用具体方向 ID。稳定的文章与卡片 ID 不变，既有学习记录继续复用。
- **目标岗位**：只在账户设置中修改并保存。主题、题库和模拟测试中的岗位选择是当前浏览范围，通过 URL 传递，不改写目标岗位；切换岗位不清空已有学习记录。
- **统一学习入口**：岗位与技术栈在 `/topics` 中选择，保留“领域—主题—文章/章节”结构。构建时从同一份路线数据生成建议顺序、掌握要求、自测追问和核心/深入阅读，只由主题页加载。题库的“按主题学习”返回当前岗位和主题；主题页的练题入口同时携带 `role` 与 `topic`。本轮新增的前端、Go、移动端和测试独立路线页已收回为主题页兼容跳转，旧 URL 保留所选框架、语言及宿主；原有 Java、Agent 和 SRE 路线页保留。

卡片 ID 由文章的 `knowledge.id` 和卡片显式 ID 组成：`{knowledge.id}#{显式 ID}`（见[元信息规范](./content-schema.md)），移动文件或修改题目措辞都不改变卡片 ID。“相关内容”可以指向其他文章的章节，综合题以 `composite` 标记。

“相关内容”中的章节链接决定卡片关联哪些章节：文章页章节标题下的卡片标记、目录中的卡片图标和“补读”入口都使用这份关联。

全站页面通过全局数据读取压缩后的索引（约 160 KB，gzip 后约 59 KB）；参考回答和考察重点只在复习、闪卡库、题库和模拟测试页面加载。

## 2. 学习者数据

学习者数据由 `src/learning/store.ts` 统一读写，缓存在浏览器 `localStorage` 的 `coding101.learner.v1` 中，通过同源 `/api/c101/learner` 同步到 Coding101 的 `learner_docs`。页面只调用这里的 hooks 和 actions。账户、订阅、账单和激活码以账户服务为准；学习记录先写本地，再以带版本号的文档推送到服务端。

阅读、评分、复习会话与设置在操作时立即保存本地，短时间连续修改合并为一次上传（延迟 2 秒）。页面可见时每 60 秒核对远端；恢复联网、重新获得焦点或回到页面时也会核对。失败后保留本地记录并在后台重试（30 秒），刷新后的首次同步会合并本地未上传的记录。同步、重试和版本冲突处理都不显示状态或失败提醒。

阅读进度取更远章节，读完标记只向前推进；卡片按修改时间合并，会话按 ID 合并；偏好和测试设置使用可选的 `updatedAt` 识别较新的修改，兼容旧记录，无需数据库迁移。同步期间的新操作会参与后续合并，登录状态晚到时重新测量阅读位置。客户端确认登录用户与记录所有者一致后才上传，服务端也校验请求中的用户 ID；退出登录或切换账号后，旧请求的响应不再写入本地。显式退出登录沿用清除当前浏览器缓存的行为。

阅读追踪和远端写入继续沿用试用／Pro 权限；此轮不改变付费边界，也不增加页面或数据库表。

| 数据 | 内容 |
| --- | --- |
| 卡片状态 | 上次评分、下次复习日期、间隔天数、次数、暂停、补读标记、答到的要点 |
| 阅读进度 | 读到的二级章节、最后位置、是否读完 |
| 订阅 | 免费、试用、Pro（含方案、到期日、自动续费、扣款失败日期）、到期只读 |
| 记录 | 账单与激活码兑换、复习与测试会话、偏好（岗位、面试日期、每日上限） |

评分间隔使用设计稿的标注：首次“没想起来”为 1 天、“模糊”为 3 天、“记得”为 12 天；之后“模糊”按上次间隔的 1.2 倍、“记得”按 2.5 倍增长。模拟测试按要点覆盖换算评分：全部答到记为“记得”，至少一半记为“模糊”，其余记为“没想起来”。

## 3. 服务端与离线模式

- 登录、试用、订阅、结账和激活码兑换通过站点 Worker 的 `ACCOUNT` Service Binding 转交账户服务。学习记录和公司标签由 Coding101 自己的 API 与数据库管理。
- 只有开启学习者功能、且不是 `LEARNER_MOCKS` 预览时才连接服务端；其余构建离线运行，登录只保存在当前浏览器。GitHub Pages 镜像与账户服务不同站，始终离线。
- 卡片的出现公司是付费数据，不进入构建产物：Pro 与试用用户从服务端取公司名称，其他人看到“N 家公司考过”。公司名称与完整来源只维护在私有仓库 `linsama-account/content/coding101/companies.json`，公开文章不包含公司字段或来源注释。本站自测由文章中的统一自测注释识别。

## 4. 当前版本的开放范围

正式站点的功能开关以已提交的 `release/production.json` 为准，当前开启账户、订阅和学习进度相关功能。普通本地构建可省略学习者功能，只开放首页、主题、文章、翻卡和题库；`LEARNER_FEATURES=true` 开放账户与学习功能，`LEARNER_MOCKS=true` 同时启用离线示例数据。两种本地模式不代表正式站点的开放状态。

## 5. 页面与本地预览

| 路径 | 设计稿 | 说明 |
| --- | --- | --- |
| `/topics` | 01b | 知识树：岗位筛选、领域、主题、章节 |
| 文档页 | 02 | 知识树文章使用领域侧栏、面试核心、章节卡片标记和面试题卡片区 |
| `/review` | 03、03r、12b | 文章翻卡、今日复习、随机自测和模拟测试作答 |
| `/weak` | 04 | 随机自测结果与补读、重答 |
| `/pricing` | 05 | 大陆版与海外版订阅 |
| `/progress` | 06、06e | 全景进度与今日任务 |
| `/account`、`/account/redeem`、`/account/billing` | 07、07b、07c、07s | 学习偏好、兑换激活码、订阅与账单 |
| `/cards` | 10、10e | 闪卡库 |
| `/questions` | 11 | 题库 |
| `/exam`、`/exam/report` | 12、12c | 模拟测试设置与报告 |

下表中 `/topics`、`/review`（文章翻卡）和 `/questions` 默认开放，其余页面需要开启学习者功能。本地预览不同订阅状态时，用 `LEARNER_MOCKS=true` 构建或启动站点，再在任一学习页面地址后加 `?mock=guest|free|trial|pro|expired`；加 `&region=intl` 切换到海外版。示例数据会覆盖当前浏览器里的学习记录。未设置该环境变量的构建会忽略 `mock` 参数。
