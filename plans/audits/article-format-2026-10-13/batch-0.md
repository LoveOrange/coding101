## 2. Claude 交接复核

保留其已完成的摘要、标题、引用和资料整理。重点核验交接中提出的三条事实：

- **压缩指针**：将“超过约 32 GB 失效”限定为 HotSpot 默认 8 字节对象对齐下的典型寻址范围；增大对象对齐可支持更大的范围，实际是否启用还要检查运行参数。[Oracle Java 25 参数说明](https://docs.oracle.com/en/java/javase/25/docs/specs/man/java.html)
- **Spring Boot 循环引用**：2.6 起默认禁止循环引用的表述有官方发行说明支持，已补入文章参考资料。[Spring Boot 2.6 Release Notes](https://github.com/spring-projects/spring-boot/wiki/Spring-Boot-2.6-Release-Notes#circular-references-prohibited-by-default)
- **Spring Boot 代理方式**：明确为 AOP 自动配置默认使用 CGLIB，可通过 `spring.aop.proxy-target-class=false` 切换；与 Spring Framework 基于接口使用 JDK 代理的默认规则区分。[Spring Boot AOP 文档](https://docs.spring.io/spring-boot/reference/features/aop.html)

交接中“页面只识别二级标题形式的面试核心”不完全准确：现有 Admonition 组件也支持 `:::tip 面试核心`。统一二级标题仍有助于目录和章节锚点，因此不撤回这部分整理。本轮没有对其全部 Java 修改逐句背书。
