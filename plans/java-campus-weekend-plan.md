## 2. 研究口径与限制

来源台账为 [research-sources.json](./audits/java-campus/research-sources.json)，采集于 2026-09-11。职位页面和面经研究页面由台账生成，构建时检查一致性。

JD 按具体职位去重：相同正文仅城市或业务集团不同的合并，同一公司不超过 3 条。19 条来源为企业官网，1 条为招聘平台的企业招聘账号。保留各职位的毕业区间、语言范围、资格、职责和加分项；接受 Java 的通用后端与明确 Java 的职位分别说明。岗位开放情况可能变化，投递时应查看原页。

面经按候选人在同一公司的招聘流程计数，同公司多轮合并；同一作者的多公司复盘按明确的流程分别记录。40 个流程不等于 40 位候选人：38 个直接读取原帖正文，2 个历史流程仅由搜索服务返回原帖正文。还有 1 条未核验材料不参与计数。

7 条面试或发布日期在最近 18 个月，17 条为历史材料，16 条年份不明。近期材料占比较低，尚不能满足“主要依据近期面经”这一研究质量目标；资源页面明确披露，不提供当前校招频率排名。后续优先补充近期原帖与未知年份，而非增加历史样本凑数量。

研究页面只归纳考点，不采用候选人的回答作为技术事实。未溯源推广题单与汇编不作为独立样本；已确认仅依赖此类材料的公司归属标注已移除，保留题目时标为本站自测。

## 3. 质量与发布验收

- 阅读范围、前置关系、题目锚点和来源生成页通过静态检查；前置图无循环。
- 运行 `npm run typecheck` 与 `npm run build -- --config docusaurus.github-pages.config.ts`，检查 Docusaurus 链接和锚点。
- 沿“岗位—范围—正文—题目—回查”及“简历—项目”检查实际页面；核对移动端导航、长表格和折叠答案。
- SQL 教学查询已用 SQLite 验证示例输出；这不代表已运行 MySQL 执行计划或全部 Java 示例。所有技术文章的完整事实复审不作为已完成声明。
- 发布由 GitHub Pages 工作流执行，目标为 `https://linsama.me/coding101/`；以工作流的实际提交 SHA 和线上页面为验收依据，不能用本地构建成功代替发布成功。

内容维护重点包括近期面经来源、目标岗位所需内容、文章事实与版本边界。维护工作贯穿 M1 和 M2；新功能按项目计划推进。
