# Coding 101 study guide

Coding 101 is a technical interview preparation website. It helps you start from a target role and decide what to review, in what order, and how deeply you need to explain each concept.

## Who it is for

- Students, working engineers and career changers who need a clear review scope.
- Readers with some technical background who want to prioritize a large amount of material.
- Candidates checking whether their technical answers, coding skills, project explanations and system design reasoning meet interview requirements.

The site does not provide career promotion or general management tracks. Architecture and collaboration topics for senior positions appear as preparation for those positions' interviews.

## What it provides

- **Role guides** organize topics by prerequisites, review priority and expected answer depth.
- **Technical articles** state the core conclusions, then explain the mechanisms and limits behind them.
- **Self-assessment questions** check whether you can explain an idea independently.
- **Algorithm and project preparation** support live coding, résumé projects and system design discussions.

## How to use it

1. Choose a target direction in the <ChineseLink to="/interview-roadmaps/">role guide catalog (Chinese)</ChineseLink>. Graduate applicants can also use the <ChineseLink to="/docs/interview/java-campus-review">Java graduate interview review scope (Chinese)</ChineseLink>.
2. On the first pass, complete only the essential topics (必会) and core readings (核心阅读).
3. When you can answer the self-assessment questions without the article, move on to frequently covered topics (常考).
4. Add role-dependent topics (按岗选学) and deeper readings based on job descriptions, résumé projects and interview feedback.

:::tip When to move on

Close the article. If you can explain the definition, key mechanism and limits in a minute or two, then handle a follow-up question, you can move to the next topic. You do not need to memorize every detail on the page.

:::

If time is limited, the <ChineseLink to="/docs/interview/java-campus-review">Java graduate interview review scope (Chinese)</ChineseLink> offers a two-week core reading plan and a month of deeper study. Keep your own schedule and notes as you work through it.
