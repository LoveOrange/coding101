# 联系与纠错

Coding 101 由 Linsama 维护。账号、付款和退款问题请发邮件到 [support@linsama.com](mailto:support@linsama.com)。技术纠错和内容建议请提交 [GitHub Issues](https://github.com/LoveOrange/coding101/issues)，需要登录 GitHub。

## 客服与售后

客服邮箱：[support@linsama.com](mailto:support@linsama.com)，3 个工作日内回复。查询付款或申请退款时，请附上注册邮箱、付款日期和订单号。不要发送密码、验证码、完整卡号或身份证件。退款规则见[服务条款](/terms#退款)。

## 反馈技术错误

请在[新建 Issue](https://github.com/LoveOrange/coding101/issues/new)时提供以下信息，方便定位和复现：

- 文章网址、章节标题，以及存在问题的句子或代码。
- 你认为正确的结论，以及支持它的官方文档、规范或源码链接。
- 如果是代码问题，请补充运行环境、版本、最小输入和实际输出。

不确定是否存在错误时，也可以说明你的推导过程。链接失效时，提供原链接和所在页面即可。

## 反馈网站使用问题

请说明操作步骤、预期结果、实际结果，以及浏览器和设备类型。截图中请遮盖个人资料。GitHub Issues 是公开页面，不要上传密码、验证码、访问令牌、身份证明、账单或包含个人信息的完整日志。

## 内容来源与权利

对引用、署名或转载范围有疑问时，请提供本站页面、原始作品链接和争议内容。只需提交公开信息；维护者会核对来源和使用范围，再修改署名、链接或相关内容。你也可以在 [Linsama 的 GitHub 主页](https://github.com/LoveOrange)查看公开项目与维护者信息。

关于广告和数据处理，请先阅读[隐私与 Cookie](https://coding101.linsama.com/privacy/)。
