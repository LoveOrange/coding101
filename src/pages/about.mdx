# 关于 Coding 101

Coding 101 是由 [Linsama](https://linsama.com/resume/) 建设和维护的中文技术面试学习网站。文章和面试自测免费开放，无需登录。本站帮助准备校招、社招和转岗的读者确定复习重点，并把看过的知识转化为能够独立解释的答案。

## 可以在这里学习什么

当前提供 [Java 后端](/java-interview-roadmap/)、[AI Agent 开发](/agent-interview-roadmap/)和[运维 / SRE](/sre-interview-roadmap/)三条岗位路线。路线标注复习优先级、阅读顺序和回答深度。你也可以通过[文章目录](/articles/)查找 Java、数据库、Redis、网络、操作系统、算法和系统设计等主题。

每篇技术文章先列出面试核心，再解释机制、示例和使用边界。文末的题目默认收起参考回答，便于先独立作答。题库中的“相关内容”可以带你回到解释对应原理的段落。第一轮复习以“必会”为主；与目标岗位无关的深入专题可以暂时跳过。

## 内容如何整理

内容围绕求职中需要解释和判断的问题编写。技术结论优先核对官方文档、规范、源码和原始论文，并在文末列出参考资料。Java 主要采用 17 和 21，MySQL 采用 8.0；依赖版本的结论会标明适用范围。

本站的价值在于中文解释、代码示例、边界条件以及题目与原理之间的对应关系。引用的课程、开源项目、招聘页面和第三方题目保留来源；外部资料的权利归原作者所有。

标为“本站原理自测”的题目用于检查理解，不代表任何公司的真实面试题。招聘信息和公开面经只是特定时间的样本，公司名称也不代表固定题库或官方合作。本站不保证录用结果，投递条件请以招聘方当前公告为准。

## 维护与反馈

页面底部提供源文件编辑入口和更新时间。发现解释有误、示例无法运行或链接失效时，请通过[联系与纠错](/contact)提供文章地址和具体问题。修订会直接更新对应文章，避免让读者在多个互相矛盾的版本之间判断。

本站计划通过展示广告支持维护，广告将在审核通过并完成设置后开放。广告与学习内容分开标识，不影响文章的阅读权限，也不构成对广告商品或服务的推荐。数据处理和选择方式见[隐私与 Cookie](https://coding101.linsama.com/privacy/)。
