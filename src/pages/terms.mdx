# 服务条款

本条款适用于 Coding 101（coding101.linsama.com）的访问、账号使用和 Pro 服务。本站由个人开发者 Linsama 运营，提供技术学习和面试准备内容。

## 账号使用 {#账号使用}

每人只能注册一个账号。本站使用邮箱验证码登录，无需设置密码。请妥善保管邮箱及验证码，确保只有你能使用该邮箱登录。

禁止自动化批量注册、刷接口、抓取付费数据或转售账号。

## 免费内容与 Pro 功能 {#免费内容与-pro-功能}

- **免费内容**：文章、题目和参考答案免费开放，无需登录。
- **Pro 功能**：学习进度与间隔复习、薄弱点、进度图、模拟测试记录和卡片关联公司。广告开放后，Pro 用户可免看站内广告。

本站当前不开放在线支付，Lemon Squeezy 收款尚未上线。开放在线支付前，将另行公布支付、订阅与退款规则。

## 试用权益 {#试用权益}

首次通过邮箱验证码登录时，符合条件的新账号会获得 7 天 Pro 试用。每个邮箱仅限一次；已经获得过试用或 Pro 权益的账号不再发放试用。删除账号后用同一邮箱重新注册，也不再发放试用。

为防止重复试用，删除用过试用或 Pro 的账号时，本站保留规范化邮箱的带密钥哈希值（HMAC），目前不设自动到期时间。邮箱别名的识别方式和数据处理详情见[隐私与 Cookie](https://coding101.linsama.com/privacy/)。

## 激活码 {#激活码}

激活码的权益天数和兑换有效期以发放说明为准，每个码只能使用一次。已有未到期权益时，新兑换的天数接在当前权益结束之后。

激活码的发放或销售渠道另行公布。开放销售时，会在购买前说明价格、权益和售后规则。

请妥善保管激活码，不要公开或转发。若激活码丢失或被他人兑换，请联系运营者核查；本站不保证能够找回或补发。

## 到期与学习记录 {#到期与学习记录}

Pro 或试用权益到期后，学习记录进入 90 天只读期。在此期间，你可以查看已保存的记录；重新开通 Pro 后，可以继续使用这些记录。

只读期结束后，服务端学习记录由每日清理任务自动删除，账号本身保留。需要继续使用已有记录时，请在只读期结束前重新开通。

你可以在“账户 → 数据与隐私”删除账号。删除成功后，账号、会话、权益记录和学习记录会从业务数据库移除，剩余权益作废，不能通过重新注册恢复。已兑换的激活码仍保持已使用状态，但解除账号关联；防重复试用的邮箱 HMAC 仍保留。日志、邮件正文预览和数据库恢复历史按[隐私说明](https://coding101.linsama.com/privacy/)中的期限保留。

若账号存在仍可扣费的订阅，需先停止续费或处理未结清的订阅状态，才能删除账号。

## 内容与反馈 {#内容与反馈}

本站内容用于学习和面试准备，不保证录用结果。内容可能存在错误，欢迎通过[联系与纠错](/contact)反馈。

本站引用的第三方资料，其版权归原作者所有。

## 服务变更 {#服务变更}

本站功能和本条款可能调整，重大变化会通过站内公告说明。计划暂停或终止服务时，本站会提前通知；突发故障等情况可能无法提前通知。需要查询或导出数据时，可通过下方邮箱申请。

## 违规处理 {#违规处理}

违反本条款时，本站可以限制账号使用或终止账号。

## 联系方式 {#联系方式}

技术纠错和网站反馈请通过[联系与纠错](/contact)提交。

账号数据和学习记录的查询、导出及其他隐私请求，请发送邮件至 [privacy@linsama.com](mailto:privacy@linsama.com)，由运营者 Linsama 本人处理，并在收到申请后 30 天内答复。为保护账号数据，处理前可能需要核验邮箱归属。本站目前没有自助导出功能，请不要在公开的 GitHub Issues 中提交隐私请求。数据处理方式见[隐私与 Cookie](https://coding101.linsama.com/privacy/)。
