# ChatGPT 辅助面试复习

ChatGPT 可以帮助你整理复习任务、模拟追问和检查回答是否完整。技术结论仍要回到文档、文章和可运行的示例核验。本文给出一套围绕 Coding101 文章练习的方法，适合已经选定目标岗位、需要把知识转化为面试回答的读者。

## 1. 确定本轮练习范围 {#确定本轮练习范围}

先从[岗位路线](/interview-roadmaps/)选一个主题，读完对应文章的“面试核心”，再开始练习。一次只练一个主题，便于判断自己是概念没记住，还是无法解释机制。

给 ChatGPT 的背景应包含目标岗位、技术版本、当前主题和已经读过的内容。不要只说“帮我准备 Java 面试”，这种要求无法区分集合、并发、数据库和项目经验的优先级。

下面的提示可以用于一轮基础练习。方括号中的内容需要替换成自己的资料。

```text
目标：准备 Java 后端开发面试，技术范围为 Java 17/21、Spring Boot 3.x、MySQL 8.0。
本轮只练习：[主题名称]。
我读过的文章要点：
[粘贴自己整理的要点，并保留版本和适用条件]

请先问一道能够检查核心机制的问题，不要同时给出答案。
等我回答后，指出回答中正确、遗漏和错误的部分，再追问一个相关边界条件。
反馈必须说明对应的技术理由。无法从提供的资料确认的结论，请明确标记待核验。
```

网页链接不等于模型已经读过正文。若它无法访问文章，提供相关段落或自己的笔记，并让它说明反馈依据。只提供本轮需要的内容，避免把无关项目和多篇长文一起塞入对话。

## 2. 先回答，再接受追问 {#先回答再接受追问}

面试练习的重点是独立组织解释。先关闭原文，用自己的话回答；卡住时记录具体卡点，再打开文章查看。让模型直接生成“标准答案”可以用于比较表述，但不能据此判断自己已经掌握。

以 HashMap 为例，假设你的回答是“HashMap 是线程安全的，因为有红黑树”。有效的反馈需要分开检查两个概念：红黑树改善特定桶内的查找性能，并没有让并发修改获得同步保证。如果反馈只是把答案改得更流畅，却保留“线程安全”这个前提，就应该拒绝这次改写并回到 [HashMap](../basic-knowledge/java/collections/hashmap-structure-lookup-path.mdx) 的原理核验。

你可以继续要求：

```text
请针对刚才回答中的错误前提提一个追问。
我回答后，再给出一个最小反例或执行顺序，帮助我检查自己的解释。
不要扩展到尚未讨论的主题，也不要因为我回答得肯定就默认结论正确。
```

一轮练习结束时，保留以下三项记录即可：

- **原始回答**：自己实际说出的内容，保留错误，便于下一次对照。
- **遗漏或错误**：例如混淆了性能优化与线程安全，而不是笼统记“HashMap 不熟”。
- **复习入口**：对应文章和章节，以及下一次需要独立解释的问题。

## 3. 核验技术结论 {#核验技术结论}

模型给出的引用、代码和解释都需要检查。引用存在，只能说明有这个页面；还要确认正文是否支持当前结论。模型生成内容与事实之间的差异见[模型幻觉](../ai/llm/hallucination.mdx)。

| 回答中的内容 | 核验方法 | 常见问题 |
| --- | --- | --- |
| 版本行为 | 打开对应版本的官方文档，检查默认配置和适用范围。 | 将其他版本的特性当作当前环境的行为。 |
| 机制解释 | 对照文章中的执行过程，检查每一步的前提。 | 只给出术语，没有说明为什么会得到该结果。 |
| 代码示例 | 先读懂代码，再在隔离的本地示例中编译、运行并检查输出。 | 代码能运行，但没有触发它声称证明的边界情况。 |
| 性能结论 | 检查数据规模、负载、测试方法和比较对象。 | 从一次耗时推断所有场景都更快。 |
| 项目回答 | 逐项对照自己实际做过的工作、约束和结果。 | 把模型补出的架构、故障和指标当作亲身经历。 |

对于并发、性能和故障恢复问题，一次运行不能证明所有执行顺序都成立。应同时检查机制是否提供保证，以及反例需要什么条件。不要把“这次没有报错”当成“实现正确”。

## 4. 把反馈用于下一轮复习 {#把反馈用于下一轮复习}

下一轮先回答上次遗漏的问题，再增加新的追问。判断是否掌握，可以看自己能否说明定义、执行过程、适用条件和代价，而不只看是否复述了相同措辞。

在 Coding101 中，可以从[题库](/questions)找到对应问题，也可以直接展开技术文章末尾的面试题。先完成自己的回答，再核对考察重点与参考回答。需要检查提示词设计时，阅读[提示词工程](../ai/prompting/prompt-engineering.mdx)；需要理解生成过程和上下文限制时，阅读[大语言模型基础](../ai/llm/llm-basics.mdx)。

如果练习转向项目代码，使用自己有权提供的最小示例，移除密钥、客户数据和内部信息。代码修改还需要测试、差异检查和人工理解，具体流程见[AI 辅助开发](../ai/development/ai-assisted-development.mdx)。
