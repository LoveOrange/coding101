# 运维与 SRE

运维与 SRE 覆盖 Linux 排查、容器、Kubernetes、监控告警、故障响应和流量接入，面向 SRE、运维开发、DevOps 和需要负责线上排查的后端岗位。题目来自牛客网上公开的 SRE、运维开发和 DevOps 面试复盘，公司信息只说明候选人曾公开记录相关提问。

:::info 阅读顺序

先读 [Linux 性能排查](./linux/performance-troubleshooting.mdx) 和 [Linux 网络排查](./linux/network-troubleshooting.mdx)，建立“先看整体资源、再定位到进程和连接”的排查习惯；再读[容器原理](./containers/container-principles.mdx)和 [Kubernetes 架构](./kubernetes/architecture.mdx)。SLO、容灾、限流等稳定性原理在系统设计中讲解，这里侧重落地与排查。

:::
