# Git 的安装与配置

安装 Git 后，还需要设置提交时使用的姓名和邮箱。安装让终端能够运行 Git 命令，配置则让每次提交带上作者信息。命令缩写可以按需设置，不影响基本操作。

## 1. 安装 Git

从 [Git 官网](https://git-scm.com/) 选择适合自己操作系统的安装方式。不同系统的步骤有所区别：有的使用安装程序，有的通过系统的包管理工具安装，按对应说明操作即可。

安装完成后，打开终端，输入 `git --version`。能够显示版本号，就说明当前终端可以运行 Git：

```bash
$ git --version
git version 2.24.3
```

示例中的 `$` 表示终端提示符，不需要输入；`2.24.3` 只是示例输出，你的版本号不必与它一致。

## 2. 配置 Git

### 2.1 配置用户信息

Git 用 `user.name` 和 `user.email` 记录提交者的姓名与邮箱，它们对应 [版本控制简介](../introduce.md#112-版本控制的内容) 中的变更人信息。这些字段会写入提交记录，不用于登录远程代码托管平台。

`--global` 表示为当前操作系统用户设置默认值，这样就不用在每个仓库中重复配置。把 `Your Name` 和 `Your Email` 替换为你自己的姓名和邮箱，再执行：

```bash
git config --global user.name "Your Name"
git config --global user.email "Your Email"
```

配置后，新提交会使用这些信息。如果某个项目需要使用不同的邮箱，就进入该项目的仓库目录，去掉 `--global` 后重新设置；仓库自己的配置会覆盖全局默认值。

### 2.2 配置常用的缩写

**别名**（alias）是为 Git 命令设置的另一种写法，用来减少重复输入。例如，把 `status` 配置为 `st`，之后输入 `git st` 就相当于输入 `git status`。

下面是一组可选的别名配置。还不熟悉这些命令时，可以先跳过，等用到后再决定是否设置：

```bash
git config --global alias.co checkout
git config --global alias.br branch
git config --global alias.ci commit
git config --global alias.st status
git config --global alias.sw switch
git config --global alias.last 'log -1 HEAD'
```

别名也可以包含参数：`git last` 相当于 `git log -1 HEAD`，用于查看当前提交。后续教程仍使用完整命令名，因此不设置这些别名也能继续练习。
