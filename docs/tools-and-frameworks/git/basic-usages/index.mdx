# 2. Git 基本使用

本部分从一次本地提交出发，练习 Git 最常用的操作：安装并配置提交身份，在练习仓库中编辑、暂存和提交文件，再核对提交里实际保存了什么。完成这些练习后，再阅读分支、合并和撤销的机制，会更容易判断每条命令改变的是哪个区域。

- [Git 的安装与配置](./git-installation.mdx)：安装 Git，设置提交使用的姓名、邮箱和可选的命令别名。
- [使用 Git 进行第一次提交](./first-commit.mdx)：练习检查状态、暂存文件并保存一次提交。
- [Git](../index.md)：工作区、暂存区、提交、分支合并、撤销修改与协作边界。
