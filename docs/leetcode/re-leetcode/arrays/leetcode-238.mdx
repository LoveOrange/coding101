# 238. 除自身以外数组的乘积

## 1. 题目简介

难度：<Yellow>中等</Yellow>，原题链接：[238. 除自身以外数组的乘积](https://leetcode.cn/problems/product-of-array-except-self/)。

> 给你一个整数数组 `nums`，返回 数组 `answer` ，其中 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的乘积 。
>
> 题目数据 保证 数组 `nums` 之中任意元素的全部前缀元素和后缀的乘积都在  32 位 整数范围内。
>
> 请不要使用除法，且在 O(n) 时间复杂度内完成此题。

## 2. 问题分析

除去 `nums[i]` 后，剩余元素正好分成左、右两部分，因此答案等于**左侧元素的乘积乘以右侧元素的乘积**。这样不需要计算总乘积再做除法。

用两个数组保存已经算过的结果：

- `left[i]` 保存 `nums[0]` 到 `nums[i - 1]` 的乘积，不包含 `nums[i]`。
- `right[i]` 保存 `nums[i + 1]` 到 `nums[n - 1]` 的乘积，同样不包含 `nums[i]`。

从左往右计算 `left`，每一步把前一个结果乘上 `nums[i - 1]`；从右往左计算 `right`，每一步乘上 `nums[i + 1]`。最左侧没有左侧元素、最右侧没有右侧元素，相应的乘积设为 1，这样乘到答案里不会改变结果。

例如 `nums = [2, 3, 4]` 时，`left = [1, 2, 6]`，`right = [12, 4, 1]`。对应位置相乘，得到 `[12, 8, 6]`。代码中的 `ans[i]` 就是这样计算的。

## 3. 代码实现

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int[] left = new int[nums.length];
        int[] right = new int[nums.length];
        left[0] = 1;
        for (int i = 1; i < nums.length; i++) {
            left[i] = nums[i - 1] * left[i - 1];
        }
        right[nums.length - 1] = 1;
        for (int i = nums.length - 2; i >= 0; i--) {
            right[i] = nums[i + 1] * right[i + 1];
        }
        int[] ans = new int[nums.length];
        for (int i = 0; i < nums.length; i++) {
            ans[i] = left[i] * right[i];
        }
        return ans;
    }
}
```

## 4. 复杂度分析

- 时间复杂度：**O(n)**，三次扫描分别计算左侧乘积、右侧乘积和答案。
- 空间复杂度：**O(n)**，需要两个额外的数组来保存前缀和后缀的乘积。
