# 系统设计简介

**系统设计**是在需求明确之后，决定系统由哪些组件组成、组件之间怎样交互，以及数据放在哪里、怎样流动。同一份需求可以有多种结构，选择时要同时考虑用户需要的结果、性能与容量、故障后的行为、成本和日后的修改难度。

面试中的系统设计题，考察的是能否从需求推出这些约束，再解释方案为什么满足它们、代价是什么。本栏目先讲面向对象设计和整体的系统设计方法，再按主题展开分布式系统、可靠性、安全和生产工程，并用案例把这些原理串起来。
