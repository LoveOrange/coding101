# MIT 6.824

MIT 6.824 是麻省理工学院的分布式系统课程，现在的课程编号是 6.5840，官网见 [MIT 6.5840](https://pdos.csail.mit.edu/6.824/)。课程以阅读分布式系统论文为主线，讨论复制、容错和一致性这些问题在真实系统中怎样解决；配套的 Go 实验依次实现 MapReduce、键值服务和 Raft 等组件，让论文中的机制在代码里落地。

本目录目前包含 MapReduce 一讲的课程笔记和实验 1 的实现笔记：

- [Lec 1: MapReduce](<./1. MapReduce/lec1_mapreduce.mdx>)：编程模型、执行流程、容错与性能优化。
- [实验 1: MapReduce](<./1. MapReduce/lab1_mapreduce.mdx>)：Coordinator 与 Worker 的任务调度、超时重派和输出提交。

实验要求、依赖版本和测试命令会随学期调整，动手前以所选学期的实验页面为准。
