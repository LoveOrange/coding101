# 面试准备

面试准备资料帮助你理解岗位要求、选择技术复习范围，并整理简历与项目经历。当前重点面向 Java 后端校招；你自行安排日程、记录问题和维护求职材料。

| 当前要做的事 | 可以使用的资料 |
| --- | --- |
| 找后端岗位，了解要求和投递入口 | [2027 校招岗位与投递](./campus-2027/index.mdx) |
| 还有两周，想先抓住重点 | [Java 校招复习范围](./java-campus-review.mdx)中的核心阅读 |
| 有一个月，希望理解原理 | [Java 校招复习范围](./java-campus-review.mdx)中的深入与迁移练习 |
| 写简历、整理真实经历 | [简历准备](./resume.mdx)、[项目准备](./project-preparation.mdx) |
| 了解公开面经考过什么 | [面经考点与来源](./interview-research.mdx) |
| 独立作答，再回查知识 | [代表题与练习](./questions.mdx) |
| 了解面试环节、练习表达 | [研发类面试流程](./interview-process.mdx) |

已有目标岗位时，可以直接进入 [Java 后端开发面试路线](/java-interview-roadmap/)。基础不足时，沿主题的前置链接补读[通用基础复习](../basic-knowledge/common/index.mdx)。

**优先级**决定先学什么：“必会”是核心范围，“常考”补充机制和追问，“按岗选学”由目标 JD 或项目触发。**回答深度**决定学到哪里：基础回答说明定义与差异，原理解释讲清执行过程，场景分析结合约束判断方案。
