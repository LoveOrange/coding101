# 面试准备

面试准备从目标岗位开始。路线先给出第一轮最小复习集合，再把技术文章、算法、项目和系统设计连接到具体面试环节。

## 开始复习

1. 从[岗位面试路线](/interview-roadmaps/)选择目标方向。
2. Java 后端求职者可以直接进入 [Java 后端开发面试路线](/java-interview-roadmap/)。
3. 第一轮只完成“必会”和每个 Topic 的“核心阅读”。
4. 合上文章完成自测问题，再根据 JD、项目和面试反馈进入“常考”或“按岗选学”。

## 分级含义

- **必会**：该岗位第一轮复习的最小集合。
- **常考**：掌握核心后用于补齐常见追问。
- **按岗选学**：只在目标岗位、简历项目或面试记录明确涉及。
- **基础回答**：能说明定义、用途和直接差异。
- **原理解释**：能讲清关键执行链路和边界。
- **场景分析**：能结合约束、故障和代价做选择。
