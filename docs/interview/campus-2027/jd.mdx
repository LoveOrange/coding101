# 京东 2027 校招岗位

本页转述京东公开招聘页面中已核验的岗位职责和任职要求，采集日期为 2026-09-11。岗位开放状态、地点和资格可能变化，投递前请回到来源页面确认。

## 后端开发工程师 {#jd15}

[官方职位与投递入口](https://campus.jd.com/#/details?id=9108)

| 信息 | 内容 |
| --- | --- |
| 职位编号 | 9108 |
| 招聘类型 | 校招正式 · 2027 届 |
| 团队 | 原页未单列 |
| 地点 | 北京、天津、成都、上海、苏州、西安、深圳、三亚 |
| 页面日期 | 未披露 |
| 语言范围 | Java 或其他后端语言 |

**资格要求**：2026 年 10 月 1 日至 2027 年 9 月 30 日毕业，统招本科及以上。

### 岗位职责

- 分析需求，参与核心系统设计、开发与维护
- 建设系统稳定性和高可用性
- 跨团队协作，探索 AI 辅助研发

### 任职要求

- C/C++/Java/Go 至少一种
- 数据结构、算法、体系结构、操作系统和网络
- TCP/IP、UDP、FTP、HTTP、HTTPS 原理与场景
- 使用 AI 编程助手进行编码、调试和重构的实践
- 逻辑思维、协作、沟通和学习能力

### 加分项

- 分布式系统或大数据开发经历
- 互联网企业实习经历

同一官方职位覆盖多个业务集团和城市，合并为一条。正文可公开阅读，投递需要登录。
