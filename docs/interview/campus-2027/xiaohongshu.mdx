- 有调用模型 API 的 Agent 应用实践
- 分布式存储、缓存、MySQL 等基础
- RAG、Prompt、工具调用和多 Agent 框架知识
- 理解 AI 编程工具、产品设计和问题拆解

- 技术博客、开源贡献或 AI 竞赛经历
