**资格要求**：2027 届应届生项目，毕业时间 2026-11-01 至 2027-10-31；详情未单列学历。

### 岗位职责

- 基础软件、分布式服务、搜索和数据处理
- 按业务参与 RAG、上下文工程、Agent 应用
- 按业务参与全栈交付与 AI 编程工具应用

### 任职要求

- 至少掌握一种编程语言和良好编程习惯
- 网络与多线程编程、TCP/IP 和 HTTP
- 操作系统环境编程、调试与脚本
- SQL 与 MySQL/Oracle 应用项目
- 面向对象设计与设计模式、数据结构和算法
- 大模型 API 和应用框架
- 学习、独立思考和沟通协作

### 加分项

- 模型微调和推理加速基本概念

多个业务集团沿用同一职位正文，合并为一条；具体 AI 技术要求保留在该岗位，不能代表全部 Java 校招。
