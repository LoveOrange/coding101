# Java 校招复习范围

本文面向已经学过 Java、准备后端校招的读者，提供核心范围、前置关系、停止条件与深入入口。两周和一个月是选择资料的参考情境，实际学习量取决于基础和可用时间，日程由你自行安排。

## 1. 两周：选择核心范围

先核对[目标岗位](./campus-2027/index.mdx)，再从下面的核心目录选择尚不熟悉的主题。每个主题只读指定章节，先解释代表问题，再用最小示例或练习检查。熟悉的内容可以直接从题目开始；遇到前置缺口沿链接补读。

每天可用时间很少时，优先覆盖目标岗位要求的语言与集合、编码、SQL、网络和并发基础，同时整理自己项目的关键请求链。框架内容跟随实际使用的技术栈；具体收集器、AQS 源码、Netty 内部实现和复杂架构不必自动加入这一轮。

两周范围不代表只背结论。停止条件要求能说明机制和边界，暂时无法完成全部主题时，在自己的记录中明确遗漏，并继续按目标岗位取舍。

## 2. 一个月：补机制与迁移练习

用核心题检查哪些部分需要回读，再进入 [Java 后端开发面试路线](/java-interview-roadmap/?round=second)中的常考与追问。每读一个深入主题，尝试改变原题的一个条件，解释结果为什么变化。

- 算法：从代表练习换到一个同模式、条件不同的题目，并检查复杂度与边界。
- 数据库与并发：画两次请求或两个事务的执行时序，指出保证依赖哪些条件。
- 项目：加入重复、超时、资源耗尽等约束，说明选择与验证办法。
- 按岗选学：根据 JD 或简历中的实际内容阅读消息、搜索、安全、AI 应用或系统设计。

[简历准备](./resume.mdx)和[项目准备](./project-preparation.mdx)可与技术复习同时进行。不要等读完全部文章才开始整理自己的经历。

## 4. 复习结果怎么检查

先口述，再编码或画时序；对照参考回答后，回到自己解释不清的章节。本站提供问题、依据和练习，不维护个人掌握状态。

具体入口见[代表题与练习](./questions.mdx)。直接从搜索或收藏进入文章时，也可以使用文内“相关内容”链接回查原理，无需从路线起点重新开始。
