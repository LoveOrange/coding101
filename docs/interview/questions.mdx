# 代表题与练习

本页按知识主题索引已有文章中的代表问题，答案维护在对应正文中，默认收起。先独立回答，再核对考察重点与参考推导；“出现公司”仅表示有候选人公开复盘过相关题目，不代表企业固定题库。

## 1. 题目来源与使用

已有题目包含公开面经题和本站原理自测，来源说明以各题为准。[面经考点与来源](./interview-research.mdx)整理了 40 个公司面试流程、20 组考点，并区分近期、历史、年份不明及检索正文材料；不提供面试命中率或公司高频排名。

面经说明考察过什么，技术答案仍须依规范、官方文档或示例验证；不要把候选人的回忆直接当标准答案。

## 2. 编码、SQL 与项目练习

技术问答之外，还应实际写代码、查询和时序。练习入口及自检条件见[编码与 SQL 练习](./coding-practice.mdx)。项目追问使用[项目准备](./project-preparation.mdx)中的材料清单和教学示例。
