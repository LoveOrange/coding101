# 研发类面试复习指南

研发岗位的复习范围由目标职位、使用语言和项目经历决定。先读 JD 中的基础要求，再选择相应资料；不同方向不需要完成完全相同的课程。

- Java 后端校招：从 [2027 校招岗位与投递](./campus-2027/index.mdx)了解岗位，再用 [Java 校招复习范围](./java-campus-review.mdx)选择核心与深入内容。
- 计算机基础：[通用基础复习](../basic-knowledge/common/index.mdx)连接数据结构、算法、操作系统、网络和数据库。
- 现场编码：[算法](../basic-knowledge/algorithms/index.mdx)按模式组织知识，[代表题与练习](./questions.mdx)提供练习入口和自检条件。
- 经历与表达：[简历准备](./resume.mdx)、[项目准备](./project-preparation.mdx)和[研发类面试流程](./interview-process.mdx)。

复习时先检查每个主题的停止条件。能够解释核心机制并完成代表练习后，再补目标岗位需要的深入知识。日程和笔记由你在自己的工具中安排；本站的主题顺序供选择和查阅。
