# Spring 框架

本栏目介绍 Java 后端面试中的 Spring 框架知识，适合准备容器、请求处理和 Spring Boot 原理的读者。内容分为 IoC、AOP、事务、MVC 和 Spring Boot。每个方向先解释核心执行过程，再讨论配置方式、使用边界与常见故障。

复习时，先理解容器怎样创建对象和装配依赖，再沿请求、代理、事务和数据库调用阅读。掌握这些过程后，再按项目与面试要求补充完整启动流程、扩展点和自定义 Starter。

各主题的前置知识、核心阅读和掌握要求见 [Java 校招复习范围](../../../interview/java-campus-review.mdx#spring-ioc)。

需要用题目检查理解时，可查看[代表题与练习](../../../interview/questions.mdx#spring-ioc)，再回到对应文章补充薄弱部分。
