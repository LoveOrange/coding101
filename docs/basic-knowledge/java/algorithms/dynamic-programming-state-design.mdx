# 动态规划

动态规划保存子问题结果，并按依赖组合答案。本文负责状态、转移、初始化、背包压缩和字符串 DP。搜索终止见[递归](../../algorithms/recursion.mdx)，局部选择证明见[贪心](../../algorithms/greedy.mdx)。

## 1. 面试核心 {#core}

- DP 状态必须包含决定后续合法选择的全部信息。
- 编辑距离用两个前缀长度定义状态，并比较插入、删除和替换。[卡](#edit-distance)
- 最长公共子序列允许跳过字符，子串则要求连续。[卡](#longest-common-subsequence)
- 0/1 背包倒序更新容量，完全背包正序更新容量。[卡](#knapsack-state-version)
- 计数 DP 的空方案可为 1，不可达状态需与合法零值区分。

## 2. 适用信号 {#适用信号}

DP 适合最优值、计数与可达性问题。关键是后续问题能由有限状态决定，且同一状态反复出现。最优化问题还需保证最优子结构。

枚举全部方案仍需输出对应结果，见[回溯](../../algorithms/backtracking.mdx)。若存在安全的局部选择，可按[贪心](../../algorithms/greedy.mdx)证明并简化。

## 3. 状态设计 {#状态设计}

每个状态都应写清处理范围、约束与结果含义。股票问题只记录日期和利润会遗漏持仓状态。本文例子允许多次交易、至多持有一股，且无手续费或冷冻期。

```text
cash[i] = 第 i 天结束时，未持股的最大利润
hold[i] = 第 i 天结束时，持有一股的最大利润
```

交易次数受限时，状态还需表达剩余次数。状态只保留影响未来的条件，避免记录完整历史。

## 4. 状态转移 {#状态转移}

```text
cash[i] = max(cash[i-1], hold[i-1] + price[i])
hold[i] = max(hold[i-1], cash[i-1] - price[i])
```

未持股可来自昨日未持股，或今日卖出。持股可来自昨日持股，或今日买入。每条转移都需符合题目规则，并覆盖合法的最后一步。

### 4.1 编辑距离 {#编辑距离}

设 `dp[i][j]` 为 A 的前 i 项变成 B 的前 j 项的最少操作数。这里每项是统一约定的字符单位。插入、删除、替换的成本都为 1。

```text
若 A[i-1] == B[j-1]：dp[i][j] = dp[i-1][j-1]
否则：dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])
dp[0][j] = j，dp[i][0] = i
```

三个前驱分别对应删除、插入和替换。`cat` 变成 `cut` 需一次替换，距离为 1。时间 O(mn)，二维空间 O(mn)。只求距离时，可保留前后两行，空间 O(n)。

### 4.2 最长公共子序列 {#最长公共子序列}

设 `dp[i][j]` 为两个前缀的最长公共子序列长度。

```text
若 A[i-1] == B[j-1]：dp[i][j] = dp[i-1][j-1] + 1
否则：dp[i][j] = max(dp[i-1][j], dp[i][j-1])
dp[0][j] = dp[i][0] = 0
```

相等时可接上末项，不同时至少跳过一个末项。`abc` 与 `ac` 的结果为 2。时间 O(mn)，二维空间 O(mn)。最长公共子串需记录以两位置结尾的连续长度。不相等时归零，答案取全表最大值。

## 5. 初始化 {#初始化}

空前缀的答案由状态含义决定。计数问题若存在一个空方案，初值就是 1。恰好装满背包时，只有容量 0 初始可达。最多容量的非负收益背包可全部初始化为 0。

不可达状态应先判断，再参与加减。用 `Long.MIN_VALUE` 表示负无穷时，减去正数会下溢。即使加正数未溢出，也会生成伪造的有限值。

股票例子可直接由首日初始化，避开哨兵运算：

```java
static long maxProfit(int[] prices) {
    if (prices.length == 0) return 0;
    long cash = 0;
    long hold = -(long) prices[0];
    for (int i = 1; i < prices.length; i++) {
        long previousCash = cash;
        cash = Math.max(cash, hold + prices[i]);
        hold = Math.max(hold, previousCash - prices[i]);
    }
    return cash;
}
```

输入价格要求非负。`[3,1,4]` 返回 3，空数组返回 0。时间 O(n)，辅助空间 O(1)。

## 6. 计算顺序 {#计算顺序}

状态依赖决定计算顺序。二维网格依赖左方与上方，可按行列递增。0/1 背包的一维压缩需读取上一轮结果：

```java
for (int i = 0; i < weights.length; i++) {
    for (int c = limit; c >= weights[i]; c--) {
        dp[c] = Math.max(dp[c], dp[c - weights[i]] + values[i]);
    }
}
```

这里 weights 为正整数，values 为非负收益。dp 按“最多容量”定义并初始化为 0。容量倒序时，较小容量还未被本轮更新。

只有重量 2、收益 3 的一件物品，容量为 4。倒序更新的答案为 3。正序会先写 dp[2]=3，再得到 dp[4]=6，重复使用该物品。完全背包允许重复使用，才采用正序。

## 7. 自顶向下与自底向上 {#自顶向下与自底向上}

### 7.1 记忆化搜索 {#记忆化搜索}

从目标递归，只求实际到达的状态。缓存键和终止机制见[递归](../../algorithms/recursion.mdx#记忆化与缓存键)。

### 7.2 表格递推 {#表格递推}

按依赖顺序填表，可直接控制计算顺序与空间。每个状态求一次时，时间为全部转移工作的总和。每条转移若为 O(1)，可按状态数乘转移数估算。

## 8. 空间压缩 {#空间压缩}

当前行只依赖上一行时，可复用两行数组。LCS 若压成一行，还需保存被覆盖的左上角旧值。背包则通过方向保证读取正确版本。

股票例子保存 previousCash，以表达昨日状态。在本文无费用模型中，改用新 cash 也会得到相同数值。保存旧值能让代码与递推式一致，规则变化时也更易核对。

恢复具体方案需要前驱或选择信息。压缩会覆盖这些信息，可另存决策，或按原表逆推。

## 9. 转移完整性 {#证明转移完整}

合法解应由某个终态表达。每个终态的最后一步应落在列出的转移中。转移的前置状态也需满足约束。

保留的状态应足以决定未来，省略的历史不再影响选择。计算前驱时需遵守同一版本语义。可以从小规模穷举结果验证转移是否漏项。

## 10. 常见问题 {#常见问题}

### 10.1 动态规划与贪心 {#动态规划与贪心}

DP 比较多个状态的合法来源。贪心保留单个选择，需要证明其安全性。具体证明方法见[贪心](../../algorithms/greedy.mdx)。

### 10.2 状态维度 {#状态维度}

维度只需区分会改变未来选择的条件。冗余维度增加状态数和实现成本。遗漏持仓或剩余资源则会混合不同子问题。

### 10.3 方案恢复 {#方案恢复}

记录选中的前驱，即可从终态逆向恢复。存在多个最优来源时，需约定返回任意方案或全部方案。

### 10.4 数值范围 {#数值范围}

方案数会随规模迅速增长。按上界选择 long、BigInteger 或题目规定的模数。最优值比较应保留可比较的真实数值，取模适用于规定的计数输出。

## 11. 面试题 {#面试题}

### 11.1 编辑距离的状态和转移如何定义？ {#edit-distance}

<!-- 面试来源：
- 字节跳动：https://www.nowcoder.com/discuss/594977
-->

**出现公司**：字节跳动

**考察重点**：两个前缀、三类操作与空串。

**相关内容**：[编辑距离](#编辑距离)。

<details>
<summary>参考回答</summary>

用两个前缀长度定义最少操作数。末项相等时沿左上角转移。不同则比较删除、插入、替换的前驱，再加 1。空串到长度 j 需 j 次插入，逆向需 i 次删除。

</details>

### 11.2 最长公共子序列的状态为何不同于子串？ {#longest-common-subsequence}

<!-- 面试来源：
- 美团：https://www.nowcoder.com/discuss/397436796127260672
-->

**出现公司**：美团

**考察重点**：允许跳过与连续匹配。

**相关内容**：[最长公共子序列](#最长公共子序列)。

<details>
<summary>参考回答</summary>

子序列比较两个前缀，允许跳过字符。末项相等时取左上角加 1，否则取上方与左方最大值。子串需记录以当前位置结尾的连续长度。遇到不匹配就归零，并保留全局最大值。

</details>
