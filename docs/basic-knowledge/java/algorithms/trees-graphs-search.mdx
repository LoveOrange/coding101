# 树与图搜索

树与图搜索沿邻接关系访问状态。本文负责 Java 遍历、最短路径、访问标记与判环。结构及存储成本见[二叉树](../../data-structures/binary-tree.mdx)和[图](../../data-structures/graph.mdx)。

## 1. 面试核心 {#core}

- 邻接表完整 DFS、BFS 均为 O(V+E)，访问顺序与空间不同。
- 左先右后的分层 BFS，每层最后访问项组成右视图。[卡](#right-side-view)
- 等正权多源 BFS 首次到达的距离，是到最近源点的距离。[卡](#multi-source-bfs)
- 有向 DFS 遇到当前路径中的灰色节点即可确认环。[卡](#directed-cycle-topological)
- 二叉树后序可合并高度与平衡状态，每个节点只计算一次。[卡](#postorder-balance)

## 2. 图的建模 {#图的建模}

显式图直接保存邻接关系。网格可按上下左右生成邻居，单词变换可按合法编辑生成邻居。

状态身份需覆盖影响后续选择的字段。例如带钥匙的寻路状态应同时包含位置与钥匙集合。只记录坐标会把不同可行动作混为一个状态。

边方向与边权决定可达关系和最短路算法。权重选择见[图](../../data-structures/graph.mdx#使用边界)。

## 3. DFS {#dfs}

以下用 record 表示无环、无共享子节点的二叉树：

```java
record TreeNode(int value, TreeNode left, TreeNode right) {}

static void preorder(TreeNode node, java.util.List<Integer> result) {
    if (node == null) return;
    result.add(node.value());
    preorder(node.left(), result);
    preorder(node.right(), result);
}
```

根 1、左孩子 2、右孩子 3，结果为 `[1,2,3]`。调用顺序对应前序。Java record 语法自 Java 16 正式提供；下文以 Java 21 为基准。

### 3.1 显式栈 {#显式栈}

```java
static java.util.List<Integer> preorderIterative(TreeNode root) {
    java.util.List<Integer> result = new java.util.ArrayList<>();
    java.util.Deque<TreeNode> stack = new java.util.ArrayDeque<>();
    if (root != null) stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        result.add(node.value());
        if (node.right() != null) stack.push(node.right());
        if (node.left() != null) stack.push(node.left());
    }
    return result;
}
```

空根返回空列表，避免向 ArrayDeque 放入 null。右孩子先压栈，左孩子就先弹出。此二叉树实现辅助空间为 O(h)，返回结果另占 O(n)。一般图还需访问集合，空间上界为 O(V)。

## 4. BFS {#bfs}

```java
static java.util.List<Integer> rightView(TreeNode root) {
    java.util.List<Integer> result = new java.util.ArrayList<>();
    java.util.Queue<TreeNode> queue = new java.util.ArrayDeque<>();
    if (root != null) queue.offer(root);
    while (!queue.isEmpty()) {
        int levelSize = queue.size();
        for (int i = 0; i < levelSize; i++) {
            TreeNode node = queue.poll();
            if (i == levelSize - 1) result.add(node.value());
            if (node.left() != null) queue.offer(node.left());
            if (node.right() != null) queue.offer(node.right());
        }
    }
    return result;
}
```

根 1、左孩子 2、右孩子 3，右视图为 `[1,3]`。每层开始时固定 levelSize，避免下一层混入当前层。辅助队列空间为 O(w)，w 为最大层宽。

## 5. visited 标记时机 {#visited-标记时机}

图搜索在入队时标记，可避免多个前驱重复加入同一状态。用整数顶点编号的 BFS 核心如下，省略初始化：

```java
for (int next : graph[current]) {
    if (distance[next] == -1) {
        distance[next] = distance[current] + 1;
        parent[next] = current;
        queue.offer(next);
    }
}
```

distance 初始全为 −1，源点设为 0 后入队。普通 BFS 的边都视为单位成本。首次发现就得到最短边数，同时记录前驱。

### 5.1 最短路径恢复 {#最短路径恢复}

从目标沿 parent 回走到源点，再反转序列即可恢复路径。源点 parent 可设为 −1，作为停止标记。目标 distance 为 −1 时无可达路径。

只记录一个 parent 会返回一条最短路径。若需全部最短路径，需保留所有距离相差 1 的合法前驱。输出数量还会增加总成本。

## 6. 多源 BFS {#多源-bfs}

多源搜索将所有不同源点设为距离 0 并同时入队。之后按普通 BFS 扩展，每项首次到达就是最近源点距离。

```java
for (int source : sources) {
    if (distance[source] == -1) {
        distance[source] = 0;
        queue.offer(source);
    }
}
```

重复源点只加入一次。单位边权下，距离按层递增。阻塞网格跳过不可通行格，无法到达的格保留 −1。总时间和空间为 O(行数×列数)。

## 7. 回溯 {#回溯}

枚举路径时，路径标记随返回撤销；完整机制见[回溯](../../algorithms/backtracking.mdx)。全局 visited 则表示该状态已处理，后续可跳过。

## 8. 拓扑排序 {#拓扑排序}

Kahn 算法先统计入度，并加入所有入度 0 的节点。取出一项后，减少其出边终点的入度。新入度降到 0 时加入队列。

若处理数小于 V，剩余子图含有环。剩余节点都有前驱，沿前驱反复回走必然重复。若所有点都处理完，输出顺序满足每条边的依赖。

多种零入度选择可产生不同拓扑序。要求字典序最小时，用最小堆管理零入度候选。普通邻接表队列实现为 O(V+E)。

### 8.1 有向图三色判环 {#有向图三色判环}

白色表示未访问，灰色表示仍在当前递归路径。黑色表示该节点的出边已处理完成。

遇到灰色邻居，当前路径与该边构成环。遇到黑色邻居只表示到达已完成分支，仍需继续搜索。例如 `0→1、0→2、2→1` 无环，但会重复遇到 1。

无向简单图需排除返回父节点的边。若允许平行边，应按边 ID 区分父边，避免漏检。

## 9. 后序合并与树形结果 {#后序合并与树形结果}

检查高度平衡时，让子树返回高度或失败标记 −1。任一子树失败，或左右高度差大于 1，就返回 −1。否则返回最大子树高度加 1。

每个节点只合并一次，时间为 O(n)，递归空间为 O(h)。若在每个节点重新计算两侧高度，链状树会累计 O(n²) 工作。

### 9.1 最近公共祖先 {#最近公共祖先}

假设两个不同目标都存在，并按节点身份区分。空节点返回空，当前节点等于任一目标时直接返回它。否则分别递归左右子树。两侧都有结果时，当前节点就是最近公共祖先。只有一侧有结果时，将该结果向上传递。

若允许目标缺失，还需核验两个目标是否都找到。若一个目标正是另一个的祖先，应返回该祖先。完整遍历时间 O(n)，递归空间 O(h)。

## 10. 常见问题 {#常见问题}

### 10.1 DFS 与 BFS 的成本 {#dfs-与-bfs-的成本}

邻接表完整遍历均为 O(V+E)。BFS 按距离扩展，DFS 先走完一条路径。峰值空间应分别看待处理前沿、活动路径和访问集合。

### 10.2 递归深度 {#递归深度}

深链的活动调用数接近节点数，超出线程栈时会溢出。迭代版本让程序自己管理待处理节点。

### 10.3 原地访问标记 {#原地访问标记}

允许修改输入，且标记值与合法数据区分时，可在原网格上标记。需要保留输入时，用独立数组。

### 10.4 带权最短路径 {#带权最短路径}

普通 BFS 保证最少边数，边成本不同就需换用对应方法。选择条件见[图](../../data-structures/graph.mdx#使用边界)。

<summary>参考回答</summary>

左先右后的 BFS 取每层最后一项即可。DFS 可先走右侧，并记录每个深度首次访问的节点。两者时间 O(n)。BFS 辅助空间 O(w)，DFS 递归空间 O(h)。

### 11.5 BFS 如何恢复一条最短路径？ {#bfs-path-recovery}
