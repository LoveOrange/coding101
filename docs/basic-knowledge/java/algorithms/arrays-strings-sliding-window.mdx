# 滑动窗口

滑动窗口维护连续区间，并增量更新区间状态。本文负责固定窗口、无重复子串、覆盖计数和窗口极值。相向移动见[双指针](../../algorithms/two-pointers.mdx)，静态求和见[前缀和](../../algorithms/prefix-sum.mdx)。

## 1. 面试核心 {#core}

- 固定窗口按长度移动，可处理含负数的数组。[卡](#sliding-window-conditions)
- 无重复窗口的左端只向前移动，哈希实现期望 O(n)。[卡](#longest-unique-substring)
- 最小覆盖窗口在覆盖成立时记录答案，再收缩左端。[卡](#minimum-cover-counts)
- 单调队列保留未过期的极值候选，窗口最大值总耗时 O(n)。[卡](#window-maximum-deque)
- Java String 按 UTF-16 code unit 索引，一个 code point 可占两个 char。

## 2. 连续区间 {#连续区间}

固定长度窗口每次加入一项、移除一项。可变窗口还需证明移走左端后的候选可被排除。

非负数组中，加入元素让和不减，移除元素让和不增。求最短达标和时可利用这个关系。含负数时，这套按和移动的证明失效。固定长度的求和窗口仍然适用。

## 3. 半开区间与不变量 {#半开区间与不变量}

用 `[left,right)` 表示窗口，长度为 right−left。left 是首项，right 是下一待加入位置。以下为最长有效窗口的伪代码：

```text
while right < n:
    加入 a[right]
    right += 1
    while 当前窗口违反约束:
        移除 a[left]
        left += 1
    用 right-left 更新最长长度
```

内层循环结束时，窗口恢复有效。最短覆盖题则需在仍有效时记录，再尝试收缩。

## 4. 固定窗口 {#固定窗口}

以下代码求长度 k 的最大区间和：

```java
static long maxWindowSum(int[] values, int k) {
    if (k < 1 || k > values.length) throw new IllegalArgumentException();
    long sum = 0;
    long best = Long.MIN_VALUE;
    for (int right = 0; right < values.length; right++) {
        sum += values[right];
        if (right >= k) sum -= values[right - k];
        if (right >= k - 1) best = Math.max(best, sum);
    }
    return best;
}
```

`[-5,-2,-3]`、k=2 返回 −5。best 使用最小 long 值，避免全负数被初值 0 覆盖。每项进出一次，时间 O(n)，额外空间 O(1)。

## 5. 可变窗口 {#可变窗口}

以下按 Unicode code point 计算最长无重复长度：

```java
static int longestUniqueSubstring(String value) {
    java.util.Map<Integer, Integer> lastSeen = new java.util.HashMap<>();
    int left = 0, best = 0, position = 0;
    for (int offset = 0; offset < value.length();) {
        int codePoint = value.codePointAt(offset);
        Integer previous = lastSeen.put(codePoint, position);
        if (previous != null && previous >= left) left = previous + 1;
        best = Math.max(best, position - left + 1);
        offset += Character.charCount(codePoint);
        position++;
    }
    return best;
}
```

`abba` 返回 2，`A😀B😀` 返回 3。position 是 code point 下标，offset 是 UTF-16 偏移。当前闭区间 `[left,position]` 内保持无重复。旧位置在窗口外时，left 保持原值，避免倒退。

哈希操作期望 O(1) 时，总时间为 O(n)。n 表示 code point 数，空间为已见字符种类数。

## 6. Java String 的索引单位 {#java-string-的索引单位}

Java 21 的 `length()` 与 `charAt()` 使用 UTF-16 单元。

```java
String value = "A😀B";
System.out.println(value.length()); // 4
System.out.println(value.codePointCount(0, value.length())); // 3
```

😀 占两个 char，所以两种长度不同。用户看到的字素簇还可包含多个 code point。题目需约定 ASCII、char、code point 或字素簇单位。

已知字符集较小时，可用数组替代哈希计数。返回原串片段时，边界需转换为 UTF-16 偏移。

## 7. 最小覆盖与重复计数 {#最小覆盖与重复计数}

设 need 保存目标频次，have 保存窗口频次。未出现字符的频次视为 0。missing 记录仍缺少的字符总数，并包含重复项。

加入字符前，若 `have[c]<need[c]`，missing 减一。然后增加 have。missing 为 0 时，记录当前窗口并尝试移走左端。移走后若 `have[c]<need[c]`，missing 加一。

目标 `AAB` 需要两个 A 和一个 B。窗口 `AB` 仍缺一个 A，用集合判断会误报覆盖。空目标可约定返回空串。频次处理统一使用题目规定的字符单位。

## 8. 窗口最大值与单调队列 {#窗口最大值与单调队列}

双端队列保存下标，值从队首到队尾严格递减。加入新下标前，弹出尾部所有不大于新值的项。新值更晚过期，且至少一样大，所以这些旧项可淘汰。

每轮弹出队首所有 `index<=right-k` 的过期项。窗口达到 k 项后，队首就是最大值。保存下标能区分重复值并判断过期。

`[1,3,3,2]`、k=2 的窗口最大值为 `[3,3,3]`。每项至多入队、出队一次，总时间为 O(n)。队列最多保存 k 项，空间为 O(k)。

## 10. 正确性证明 {#正确性证明}

右端逐项访问全部候选终点。左端移动则需解释为何可舍弃旧起点。

无重复窗口遇到重复字符 c 时，旧 c 之前的起点都会包含两个 c。它们已失效，所以可将 left 移到旧 c 之后。最小覆盖中，当前已覆盖时才收缩，并先记录答案。

## 11. 常见问题 {#常见问题}

### 11.1 累计移动次数 {#累计移动次数}

两个边界各自至多前进 n 次，总次数至多 2n。单次增删为 O(1) 时，总成本为 O(n)。

### 11.2 最短区间的更新时机 {#最短区间的更新时机}

覆盖成立时先记录长度，再尝试收缩。覆盖失效后继续扩张右端。最长有效区间则在恢复有效后记录。

### 11.3 子串分配 {#子串分配}

反复创建长度递增的子串会累计复制 O(n²) 个单元。保存最佳边界，结束后再创建一次结果即可。

### 11.4 负数与窗口条件 {#负数与窗口条件}

负数破坏的是按区间和单调收缩的依据。频次条件与固定长度仍可用窗口。具体替代方法由求和、计数或最短长度目标决定。
