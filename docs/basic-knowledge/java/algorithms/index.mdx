# Java 算法

本栏目使用 Java 讲解算法面试中的常见方法，适合准备现场编码的读者。复习从输入约束和复杂度入手，再学习窗口、搜索与动态规划，最后练习验证代码。

每个主题都围绕一个目标展开：根据题目定义状态，解释算法为什么成立，再用边界输入检查实现。掌握这些方法后，可以用同样的思路分析新的题目。

## 继续复习

完成一个主题后，先检查自己能否讲清状态含义、移动或转移的依据，以及时间和空间成本。再用一个正常输入和一个边界输入运行代码，确认实现符合推导后，进入下一个主题。
