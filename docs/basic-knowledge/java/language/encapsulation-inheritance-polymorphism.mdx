# 面向对象编程（Object-Oriented Programming）

面向对象编程使用对象组织状态与行为。本文负责封装、继承、多态和接口选择。参数中的引用复制见 [Java 值传递](./types-references-value-passing.mdx)。

## 1. 面试核心 {#core}

- 封装通过受控方法维护对象不变量。[卡](#oop-pillars)
- 继承建立子类型关系，子类应满足父类型契约。
- 动态分派根据实际对象选择重写的实例方法。
- 重载在编译期选签名，重写在运行时选实现。[卡](#overload-vs-override)
- 接口定义能力，抽象类可共享实例状态与构造过程。[卡](#interface-vs-abstract-class)

## 2. 封装 {#封装}

封装把状态变化集中到对象提供的方法中。对象可以在修改前校验条件，从而避免出现无效状态。

```java
final class Account {
    private long balance;

    Account(long openingBalance) {
        if (openingBalance < 0) {
            throw new IllegalArgumentException("negative balance");
        }
        this.balance = openingBalance;
    }

    void withdraw(long amount) {
        if (amount <= 0 || amount > balance) {
            throw new IllegalArgumentException("invalid amount");
        }
        balance -= amount;
    }

    long balance() {
        return balance;
    }
}
```

公开字段或无校验的 setter 会允许负余额。返回可变集合时也应控制修改入口。防御性副本能隔离集合结构；不可修改视图只限制该视图的写入。

## 3. 继承与多态 {#继承与多态}

继承让子类获得父类可见的状态和行为，同时声明子类属于父类型。只有子类能够满足父类型契约时，这种关系才成立。

```java
interface PricePolicy {
    long calculate(long originalPrice);
}

final class DiscountPolicy implements PricePolicy {
    @Override
    public long calculate(long originalPrice) {
        return originalPrice * 80 / 100;
    }
}

PricePolicy policy = new DiscountPolicy();
long price = policy.calculate(1_000); // 800
```

变量的编译时类型为 `PricePolicy`，对象类型为 `DiscountPolicy`。编译器确认接口声明了 `calculate`。运行时根据实际对象选择重写实现。

### 3.1 静态绑定与成员隐藏 {#不参与运行时多态的成员}

- 字段访问由引用的编译时类型决定。
- 静态方法属于类，子类声明同名方法属于隐藏。
- `private` 方法不会被子类继承。
- `final` 方法固定了继承后的实现。

动态分派适用于可重写的实例方法。字段和静态成员按各自绑定规则解析。

### 3.2 重载与重写 {#重载与重写}

```java
void print(String value) {}
void print(Object value) {} // 重载
```

重载使用同名方法和不同参数列表。编译器根据实参静态类型选择签名。单独改变返回类型无法形成重载。

重写为继承的方法提供新实现。引用返回类型支持协变，访问权限须保持或扩大。受检异常须保持或缩小范围。

## 4. 接口、抽象类与组合 {#接口抽象类与组合}

| 方式 | 适合表达 | 主要限制 |
| --- | --- | --- |
| 接口 | 调用方依赖的能力或协议 | 实例状态由实现类保存 |
| 抽象类 | 同一类对象共享的状态、构造过程或模板流程 | Java 只有单类继承，子类与基类耦合较强 |
| 组合 | 一个对象使用可替换的策略或协作者 | 需要显式转发调用和管理依赖 |

接口可以声明抽象方法、`default` 方法、静态方法和私有辅助方法。`default` 方法主要用于在一定范围内兼容地扩展接口；两个无继承关系的接口提供相同默认方法时，实现类必须重写消除歧义。

共享状态和稳定流程时，可使用抽象类。替换计价、存储或通知策略时，可用接口配合组合。协作者因此能独立替换。

```java
final class OrderService {
    private final PricePolicy policy;

    OrderService(PricePolicy policy) {
        this.policy = policy;
    }

    long quote(long originalPrice) {
        return policy.calculate(originalPrice);
    }
}
```

## 5. 重载选择与动态分派 {#重载选择与动态分派}

重载先根据实参的静态类型选择方法签名。运行时再根据接收者的实际类型选择重写实现。

```java
class Parent {
    String show(Object value) { return "parent-object"; }
    String show(String value) { return "parent-string"; }
}
class Child extends Parent {
    @Override
    String show(Object value) { return "child-object"; }
}
Parent service = new Child();
Object value = "java";
System.out.println(service.show(value)); // child-object
```

`value` 的静态类型是 `Object`，所以选中 `show(Object)`。接收者是 `Child`，因此调用子类重写实现。

同签名默认方法的选择也有优先规则。父类的具体实例方法优先于接口默认方法。子接口的默认方法优先于父接口。同级接口发生冲突时，实现类必须显式重写。

## 6. 常见问题 {#常见问题}

### 6.1 访问器与状态约束 {#访问器与状态约束}

没有。封装的判断标准是对象能否持续维护自己的约束。无条件暴露所有字段的读写，只是改变了访问语法。

### 6.2 组合与继承的选择 {#组合与继承的选择}

行为可由协作者独立替换时，组合更灵活。存在稳定子类型关系时，可采用继承。多个子类共享状态和流程时，可采用抽象类。

### 6.3 向下转型与抽象边界 {#向下转型与抽象边界}

频繁判断具体子类，说明父类型抽象未覆盖调用需求。新增子类时，调用方也需要同步修改。
