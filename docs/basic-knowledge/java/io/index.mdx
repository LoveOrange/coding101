# Java I/O

本栏目介绍 Java 的文件与网络读写，以及对象的序列化。复习时，从字节和文本的处理入手，逐步理解数据怎样读取、转换和写出。

流的关闭顺序与异常处理见 [Java 异常](../language/exceptions-error-boundaries.mdx#try-with-resources-与资源关闭)。

- [Java NIO](./buffer-channel-selector.mdx)：再学习缓冲区状态、通道读写与就绪事件。
- [零拷贝](./file-mapping-zero-copy-direct-memory.mdx)：比较文件传输、内存映射和直接内存各自减少的开销。
- [Java 序列化](./java-serialization-compatibility-security.mdx)：理解对象如何保存和恢复，以及版本兼容与不可信输入的边界。
