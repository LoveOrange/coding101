# Java 数据访问

Java 数据访问介绍持久层框架如何执行 SQL，以及怎样控制数据库访问的开销。本栏目适合准备 Java 后端面试的读者，覆盖 MyBatis、JPA、连接池和查询优化。

复习时，先根据项目使用的框架阅读 MyBatis 或 JPA，理解一次读写的执行过程。接着学习 N+1 查询和连接池，判断查询次数与连接占用怎样影响接口性能。最后阅读批处理与分页，并用性能测试验证查询数量、结果规模和分页是否正确。
