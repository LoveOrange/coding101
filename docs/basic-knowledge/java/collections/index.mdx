# Java 集合

Java 集合用于组织对象、查找数据和表达取出规则。第一轮先掌握容器选择、ArrayList 的操作成本和 HashMap 的查找机制。

<ReviewGuide plan={javaCollectionsReview} />

## 1. 关键结论

- **先确定容器语义。** List 保留位置和重复元素，Set 表达唯一性，Map 保存键值关联；需要按规则取出元素时使用 Queue 或 Deque。顺序、去重和查找要求会影响实现选择，见[Java 集合框架](./collection-interface-selection.mdx)。
- **数组存储决定 ArrayList 的主要成本。** 随机访问可以直接定位，尾部追加通常不需要移动已有元素；扩容和中间插入可能复制或搬移数据。要区分一次操作的成本与连续操作的摊销成本，见[ArrayList](./arraylist-growth-memory-locality.mdx)。
- **HashMap 通过哈希缩小查找范围，再确认键是否相等。** 相同哈希不代表相等，自定义键的相等性字段需要保持稳定。平均查询性能依赖哈希分布，它也不保证顺序和无同步并发写的安全，见[HashMap](./hashmap-structure-lookup-path.mdx)。

不熟悉数组、链表或哈希表时，先补充[数据结构](../../data-structures/index.mdx)；不能解释键的相等性时，回看[对象相等性](../language/equals-hashcode-object-identity.mdx)。
