# Java 对象布局

Java 对象包含运行时状态与实例字段。本文负责对象分配、构造顺序和布局组成。类初始化条件见 [类加载](./class-loading-stages.mdx)。字节数计算见 [压缩指针与对象对齐](./compressed-pointers-alignment.mdx)。

## 1. 面试核心 {#core}

- 对象分配先建立字段默认值，构造过程再执行显式初始化。[卡](#object-creation)
- TLAB 是 Java 堆中的线程分配缓冲区，能减少共享分配竞争。[卡](#tlab-allocation)
- HotSpot 对象由对象头、实例字段和对齐填充组成。[卡](#object-layout)
- 数组布局还包含长度字段，对象头编码取决于版本与配置。
- 构造期发布 `this` 会让其他线程访问尚未完成构造的对象。

## 2. 类型检查 {#类型检查}

```java
Order order = new Order(id, amount);
```

这类表达式会生成 `new` 和 `invokespecial <init>` 等指令。`new` 涉及目标类解析和必要的类初始化。`invokespecial` 则调用实例构造器。

对象分配与构造是两个步骤。构造器通过 `this` 已能访问正在构造的实例。

## 3. 内存分配 {#内存分配}

分配方式取决于收集器管理的空间。连续空闲区域可用顶部指针分配。分散的空闲块则需要对应的空闲空间结构。

HotSpot 用 TLAB 减少线程争抢共享分配位置。线程在自己的缓冲区内移动指针完成快速分配。TLAB 耗尽后可申请新 TLAB，或走外部分配路径。

TLAB 位于 Java 堆。它只隔离分配操作，已发布的对象仍可共享。对象超出 TLAB 可用空间也不意味着直接进入老年代。具体去向取决于收集器和分配策略。

## 4. 零值初始化与构造器 {#零值初始化与构造器}

对象的全部实例字段先取得默认值。整数为 `0`，布尔为 `false`，引用为 `null`。父类声明的实例字段也包含在内。

```java
final class Counter {
    int step = 1;
    int value;

    Counter(int initial) {
        value = initial;
    }
}
```

本例隐式调用父类无参构造器。随后执行 `step = 1`，再执行 `value = initial`。初始零值和显式字段初始化属于不同步骤。

Java 17、21 要求显式构造器调用位于首条语句。省略时，编译器会隐式插入 `super()`。

### 4.1 构造器中的动态分派 {#构造器中的动态分派}

父类构造器调用可覆写方法时，会分派到子类实现。此时子类字段初始化表达式尚未执行。

```java
class Parent {
    Parent() { show(); }
    void show() {}
}
class Child extends Parent {
    int value = 7;
    @Override void show() { System.out.println(value); }
}
// new Child() 输出 0。
```

父类构造时调用 `Child.show()`，读取到默认值 0。父类构造返回后，才执行 `value = 7`。构造器应避免调用依赖完整子类状态的可覆写方法。

## 5. 对象的内存布局 {#对象的内存布局}

对象头携带类型关联、身份哈希和同步等运行时状态。实例数据包含本类与父类的字段。对齐填充使对象大小满足实现要求。

数组还包含长度字段。HotSpot 可调整字段排列，以减少空洞。源码字段顺序不足以推算实际偏移。

Java 17、21 的 HotSpot 对象头包含标记字和类指针。具体布局和字节数见 [压缩指针与对象对齐](./compressed-pointers-alignment.mdx)。

## 6. 构造与安全发布 {#构造与安全发布}

```java
final class Listener {
    Listener(EventBus bus) {
        bus.register(this);
    }
}
```

注册会把 `this` 交给外部对象。若事件立即触发，其他线程可在构造结束前调用它。可将注册移到构造完成后的生命周期方法。

正确构造的 `final` 字段具有初始化安全保证。普通可变状态通过锁、volatile 或并发容器发布。发布规则还需覆盖后续修改。

## 7. JOL 布局观察 {#用-jol-观察布局}

```java
System.out.println(ClassLayout.parseClass(Order.class).toPrintable());
```

JOL 输出字段偏移、对象头和对齐结果。记录结果时应附上 JDK 版本、位数与启动参数。压缩类指针与对象对齐都会影响布局。

`Instrumentation.getObjectSize` 返回实现相关的浅大小。引用所指向的对象需另外计算。

## 8. 常见问题 {#常见问题}

### 8.1 对象分配与标量替换 {#对象分配与标量替换}

JIT 可消除完整对象分配，机制见 [逃逸分析与标量替换](./escape-analysis-scalar-replacement.mdx)。

### 8.2 身份哈希的存储 {#身份哈希的存储}

身份哈希可在首次需要时计算。锁状态和对象头方案会影响其存储方式。

### 8.3 空类对象的占用 {#空类对象的占用}

空类实例仍需携带运行时状态，并满足对象对齐。具体大小由当前 JVM 的布局配置决定。
