# JVM

本栏目介绍 Java 虚拟机（JVM）的运行机制与故障诊断，适合准备 Java 后端面试的读者。内容从字节码和类加载讲起，覆盖运行时内存、对象、垃圾回收、JIT 优化与生产诊断。

复习时，建议先掌握**运行时内存、对象可达性与垃圾回收**。在此基础上，再按面试问题补充类加载和诊断方法。JIT 优化与具体收集器实现可作为深入阅读内容。

各章节的前置知识、复习重点和掌握要求见 [Java 校招复习范围](../../../interview/java-campus-review.mdx#jvm-memory)。需要按问题回查时，可使用[代表题与练习](../../../interview/questions.mdx#jvm-memory)。
