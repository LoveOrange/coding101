# Java 并发编程

Java 并发编程介绍多个线程怎样安全地共享数据、协调执行，并管理异步任务。这里面向准备 Java 后端面试的读者，内容覆盖内存可见性、原子性、同步器和线程池。也会讨论任务取消，以及死锁、饥饿等让任务无法继续执行的问题。

复习时，先读线程与共享状态，再用 Java 内存模型理解线程之间的数据可见性。在此基础上，学习锁、原子类和同步器，再进入线程池、异步组合与任务取消。掌握这些内容后，可按面试追问深入 AQS 实现、复杂异步编排与性能诊断。

核心章节、前置知识和各阶段的掌握要求见 [Java 校招复习范围](../../../interview/java-campus-review.mdx#java-concurrency)。

需要按问题回查时，可使用[代表题与练习](../../../interview/questions.mdx#java-concurrency)。
