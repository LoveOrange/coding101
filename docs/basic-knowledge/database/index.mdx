# 关系型数据库

关系型数据库用表表达数据，用键与约束限制合法状态，通过 SQL 查询和更新数据。表中的一行表示一条记录，列定义记录的属性；表之间通过键建立联系。面试复习需要同时掌握查询结果、访问成本和并发读写的保证。

本文目录以 MySQL InnoDB 为主要实现参照。不同数据库的隔离与执行计划细节可能不同，回答时应明确产品、版本及查询类型。
