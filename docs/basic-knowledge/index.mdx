# 基础知识

基础知识覆盖技术面试中的数据结构、算法、操作系统、网络、数据库与缓存。已有一门语言基础的读者，可以先按[通用基础复习](./common/index.mdx)完成核心阅读和自测，再根据目标岗位补语言、框架和深入专题。

## 按复习顺序阅读

- [通用基础复习](./common/index.mdx)：优先级、回答深度与停止条件。
- [数据结构](./data-structures/index.mdx)：查找、顺序、遍历与极值。
- [算法](./algorithms/index.mdx)：复杂度、常见模式与正确性检查。
- [操作系统](./operating-system/index.mdx)：程序运行、内存与 I/O。
- [计算机网络](./network/index.mdx)：解析、连接、加密与请求。
- [关系型数据库](./database/index.mdx)：SQL、约束、索引与事务。
- [NoSQL 数据库](./nosql/index.mdx)：Redis 与缓存场景。
- [消息与中间件](./middleware/index.mdx)：确认、重试、幂等与搜索。
