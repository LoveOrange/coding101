# 双指针

**双指针**是用两个位置在数组或链表上协调移动，利用顺序或位置关系减少重复扫描。在有序两数之和这样的单次扫描中，每个指针只走一遍，就能把枚举配对的 O(n²) 降到 O(n)。常见的形式有三种：从两端相向移动，同向一读一写，以及保持固定间距或不同速度。

双指针的代码很短，关键在于说清楚每次移动的依据：为什么移走这个指针不会错过答案，两个指针之间的区域代表什么。依据一旦依赖某个前提（比如数组有序），前提不成立时方法就不能用。

## 1. 面试核心 {#core}

- 有序数组上的相向双指针，根据两端之和的大小**每次排除一个端点**：和偏小就右移左端，和偏大就左移右端。**有序性保证被排除的组合不可能是答案**。[卡](#two-sum-sorted)
- 两个有序数组求跨数组最小差值时，**更新差值后移动较小值所在的指针**；把较大值继续增大，只会让当前较小值离它更远。[卡](#two-arrays-minimum-difference)
- 三数之和先固定一个值，再在右侧做相向扫描，**外层跳过相同固定值，找到一组后跳过相同左右值**，按值去掉重复三元组；总时间仍是 O(n²)。[卡](#three-sum-deduplication)
- 读写指针可以在保持顺序的前提下原地压缩数组：`read` 扫描原数组，**`write` 是有效前缀的长度**，写入始终发生在已经读过的位置。[卡](#read-write-prefix)
- 两个指针各自最多向前移动 n 次时，**总移动量是 O(n)**。

## 2. 相向移动的排除依据 {#相向移动的排除依据}

在升序数组里找两个数，使它们的和等于目标值。左指针从头开始，右指针从尾开始，每次看两端之和：

- 和偏小：当前左值加上目前最大的右值都不够，加上更小的右值就更不够了，所以当前左值不可能是答案的一部分，左指针右移。
- 和偏大：对称地，当前右值加上最小的左值都太大，右指针左移。

每一步都安全地排除一个元素，所以最多 n 步就能结束。

```java
static int[] twoSumSorted(int[] a, long target) {
    int left = 0, right = a.length - 1;
    while (left < right) {
        long sum = (long) a[left] + a[right];
        if (sum == target) return new int[]{left, right};
        if (sum < target) left++;
        else right--;
    }
    return new int[]{-1, -1};
}
```

`[1,2,4,7]`、`target=9` 时，`1+7` 偏小，左指针右移；`2+7` 等于 9，返回下标 `[1,3]`。循环条件 `left < right` 保证用的是两个不同的位置。求和前先转成 `long`，两个 `int` 相加就不会溢出。时间 O(n)，额外空间 O(1)。

### 2.1 两个数组的最小差值 {#两个数组的最小差值}

**跨数组最小差值**要求从两个数组中各取一个数，让绝对差最小。例如两个班的成绩分别为 `[1, 8, 20]` 和 `[5, 12, 21]`，答案是 `|20-21|=1`。不能把两个数组合在一起后随意挑相邻值，因为最接近的两个值可能来自同一个班。

先把两组数据分别按升序排序，两个指针都从各自数组的开头出发。比较当前的 `a[i]` 和 `b[j]`，更新已知最小差值，再移动较小值所在的指针；相等时差值已经为 0，可以直接返回。

移动依据是剩余元素的大小范围。若 `a[i] < b[j]`，后面的 `b` 值都不小于 `b[j]`，它们与当前 `a[i]` 的差不会更小。当前这对已经检查过，因此可以排除 `a[i]`，让 i 前进。另一种情况对称。任一数组走完后，剩余配对中涉及的另一侧元素已经被安全排除，不必继续扫描。

下面沿用本文的 Java，接收任意顺序的 `int` 数组，只返回最小差值。方法复制后再排序，不改变调用者的数据；任一数组为空时，没有合法配对，返回空的 `OptionalLong`。

```java
static java.util.OptionalLong minimumDifference(int[] first, int[] second) {
    if (first.length == 0 || second.length == 0) {
        return java.util.OptionalLong.empty();
    }
    int[] a = first.clone();
    int[] b = second.clone();
    java.util.Arrays.sort(a);
    java.util.Arrays.sort(b);
    int i = 0, j = 0;
    long best = Long.MAX_VALUE;
    while (i < a.length && j < b.length) {
        long difference = Math.abs((long) a[i] - b[j]);
        best = Math.min(best, difference);
        if (best == 0) return java.util.OptionalLong.of(0);
        if (a[i] < b[j]) i++;
        else j++;
    }
    return java.util.OptionalLong.of(best);
}
```

上面的成绩例子依次比较 `(1,5)、(8,5)、(8,12)、(20,12)、(20,21)`，得到最小差值 1。若输入分别是 `[Integer.MIN_VALUE]` 和 `[Integer.MAX_VALUE]`，差值为 4294967295，已经超过 `int`。因此必须在减法前转成 `long`；先做 `int` 减法再转换，溢出已经发生，补一次 `Math.abs` 也修复不了。这里两个 `int` 的差一定能放入 `long`，不会遇到 `Math.abs(Long.MIN_VALUE)` 仍为负数的边界。

设两组长度为 n 和 m，排序需要 O(n log n + m log m)，之后的扫描是 O(n+m)。这份实现为保留输入复制了数组，额外空间为 O(n+m)。若输入已经有序，可以直接执行扫描；如果还要返回原学生或原下标，排序时应连同身份信息一起保存，不能拿排序后的下标充当原下标。

### 2.2 有限成绩范围下的桶 {#有限成绩范围下的桶}

**按值域建桶**是给每个可能的成绩准备一个位置，记录它是否出现以及来自哪一组。若已经确认成绩都是某个小范围内的整数，可以用每个位置两位标记：一位表示 A 班出现过，一位表示 B 班出现过。两位都存在，最小差值就是 0；同班的重复成绩只需记一次，因为这道题只求差值，不求配对数量。

按成绩从小到大扫描桶，分别保存最近遇到的 A 班成绩和 B 班成绩。遇到 A 班成绩时，与最近的 B 班成绩比较；遇到 B 班成绩时，与最近的 A 班成绩比较。对于当前值，另一班已经扫过的值中最大的那个离它最近；未来另一班的值出现时会反过来检查，因此不会漏掉最优配对。

例如 A 班为 `[1, 2]`、B 班为 `[100]`，正确答案是 98。如果桶只记“有没有人得这个分数”，不记班级，就可能把同班的 1 和 2 当成答案，错误地返回 1。

若值域中共有 U 个可能的整数，建桶和扫描共 O(n+m+U) 时间、O(U) 空间。只有确定值域较小，这个方案才有优势；题目只说“成绩”并不自动意味着 0 到 100 的整数。对小数、负数或很稀疏的大范围，需要先确认表示和范围，不能直接分配覆盖所有可能值的数组。用哈希表只保存出现过的成绩可以节省空桶，但仍需解决按值有序遍历的问题，不能据此声称总时间仍是线性。

### 2.3 固定一项后的三数之和 {#固定一项后的三数之和}

**三数之和**可以先固定一个数，再把剩下的问题交给两数之和。这里采用一个明确的练习约定：输入是整数数组，找出和为 0 的所有三元组，三个元素来自不同位置，结果按值去重。它返回数值而非原下标；现场题目若要求指定目标值、配对数量或原下标，需要先调整约定。

先排序，固定 `a[i]`，让 `left` 从 `i+1` 出发，`right` 从末尾出发。此时三数之和偏小，可以排除当前左值；偏大可以排除当前右值，依据与前面的有序两数之和相同。`i < left < right` 保证不会重复使用同一个位置。

去重要区分两层。外层再次遇到相同的 `a[i]` 时，跳过这一轮，因为第一次固定这个值时已经搜索了更大的右侧范围。内层找到一组后，记录答案，再同时向内移动，并跳过刚才左右两端的相同值。在固定值不变时，重复的左值需要的右值也不变，继续保留这些重复位置只会得到相同三元组。

下面用 Python 展示这一机制，语言是示例的选择。`sorted(nums)` 创建新列表，不改变调用者的数组；不能先对整个输入用集合去重，否则 `[-1,-1,2]` 和 `[0,0,0]` 这样的合法结果会消失。

```python
def three_sum(nums):
    a = sorted(nums)
    result = []
    for i in range(len(a) - 2):
        if i > 0 and a[i] == a[i - 1]:
            continue
        if a[i] > 0:
            break
        left, right = i + 1, len(a) - 1
        while left < right:
            total = a[i] + a[left] + a[right]
            if total < 0:
                left += 1
            elif total > 0:
                right -= 1
            else:
                result.append([a[i], a[left], a[right]])
                left += 1
                right -= 1
                while left < right and a[left] == a[left - 1]:
                    left += 1
                while left < right and a[right] == a[right + 1]:
                    right -= 1
    return result
```

输入 `[-1,0,1,2,-1,-4]`，得到 `[[-1,-1,2],[-1,0,1]]`。固定 `-1` 时，先找到 `(-1,-1,2)`，再找到 `(-1,0,1)`；下一轮固定值仍为 `-1`，直接跳过。输入 `[0,0,0,0]` 只返回一组 `[0,0,0]`。不足三个元素时返回空列表。排序后若固定值已经大于 0，后面的数也都大于 0，因此可以提前结束；固定值等于 0 时不能提前结束。

固定一个位置时，左右指针总共移动 O(n) 次，但固定位置最多有 n 个，因此扫描总成本为 O(n²)，加上排序仍为 O(n²)。本实现的排序副本和排序辅助空间合计 O(n)，还要另计 k 个结果占用的 O(k) 空间，不能因为只声明两个指针就说整个方法空间为 O(1)。这里按整数加法和比较为常数成本分析；Python 整数不会发生固定宽度溢出，但超大整数的运算成本还取决于位数。换成 Java 或 Go 的固定宽度整数时，要在求和前选择足够宽的类型。

### 2.4 现场输入与函数接口 {#三数之和的输入约定}

**算法函数接收数组，不代表已经处理了标准输入。** 现场先确认平台是直接调用函数，还是要求自己读取文本；若读取文本，还要确认有没有长度 n、是否有多组、数值怎样分隔、结果怎样输出。不能从题目名称推断这些格式。

例如，另行约定标准输入是一个 JSON 整数数组，输出是 JSON 三元组数组，可以把下面这段接在 `three_sum` 定义之后：

```python
import json
import sys

nums = json.loads(sys.stdin.read())
if not isinstance(nums, list) or any(type(x) is not int for x in nums):
    raise ValueError("expected a JSON array of integers")
print(json.dumps(three_sum(nums)))
```

输入 `[-1,0,1,2,-1,-4]` 后结束输入，输出 `[[-1, -1, 2], [-1, 0, 1]]`。`[]` 是合法空数组；空文本或损坏的 JSON 会解析失败，字符串、布尔值和小数也不满足这里的整数数组约定。这个入口只演示一组 JSON 输入，不是所有判题平台通用的输入格式；平台若给出 n 和空白分隔整数，应按它的格式另写读取代码。

## 3. 同向指针与快慢指针 {#同向指针与快慢指针}

同向双指针中最常见的是**读写指针**：一个负责读输入，一个负责写输出。`read` 逐项读取，`write` 指向下一个可以写入的位置，有效结果始终保存在 `[0,write)` 里。因为 `write` 不会跑到 `read` 前面，写入只会覆盖已经读过的位置。

**快慢指针**是让两个指针以不同速度沿同一条链移动，常用于判断链表是否有环、找环的入口或中点。判环与入口的推导见[链表](../data-structures/linked-list.mdx#快慢指针与环入口)。

### 3.1 有序数组去重 {#有序数组去重}

```java
static int unique(int[] a) {
    int write = 0;
    for (int read = 0; read < a.length; read++) {
        if (write == 0 || a[read] != a[write - 1]) {
            a[write++] = a[read];
        }
    }
    return write;
}
```

数组有序，相同的值一定相邻，所以只要把 `a[read]` 和最后一个保留的值 `a[write - 1]` 比较，不同就写入。输入 `[1,1,2]` 返回 2，有效前缀是 `[1,2]`；数组 `write` 之后的内容不属于结果，可以忽略。

每一轮 `write` 最多比 `read` 多 1，写入位置 `write` 不超过 `read`，所以覆盖的总是已经处理过的元素。每项只读一次，时间 O(n)，空间 O(1)。

### 3.2 固定间距 {#固定间距}

单向链表不能从尾部往回数，要找倒数第 k 个节点，可以让两个指针保持固定的间距：快指针先走 k 步，然后两个指针同步前进，快指针走到末尾时，慢指针离末尾正好 k 步。

如果目的是删除这个节点，需要停在它的前驱上。在链表前加一个虚拟头节点，删除原来的头节点和删除其他节点就能走同一套逻辑。写代码前要先约定 k 的合法范围，以及两个指针从哪里出发，差一步就会停在错误的节点上。

## 4. 使用边界 {#使用边界}

相向双指针依赖有序性。无序数组里，和偏小时无法判断该排除哪个元素。可以先排序再用双指针，但排序需要 O(n log n)，而且会打乱原下标，题目要求返回原下标时还得额外保存；也可以直接用哈希表。

读写压缩必须先读出当前值，再覆盖已处理的位置。有序去重依赖相同的值相邻；数组无序时，要用额外的结构记录已经见过的值。

### 5.4 两个班成绩的最小差值如何求，排序双指针与桶分别适用什么条件？ {#two-arrays-minimum-difference}

**考察重点**：跨组配对、有序排除、值域与整数溢出。

**相关内容**：[两个数组的最小差值](#两个数组的最小差值)、[有限成绩范围下的桶](#有限成绩范围下的桶)。

<details>
<summary>参考回答</summary>

**分别排序后，用两个指针从头扫描，更新差值，再移动较小值所在的一侧。** 较小值与另一组后面更大的值只会离得更远，所以可以安全排除；相等就返回 0。排序后扫描 O(n+m)，加上排序是 O(n log n + m log m)。

若确认成绩是有限小范围的整数，可以按成绩建桶，但必须记录班级。按值扫描时保留另一班最近的成绩，遇到两班相同成绩就得到 0；不能把同班相邻值算作跨班答案。值域大小为 U 时，成本为 O(n+m+U) 时间和 O(U) 空间。

空数组没有合法配对；计算两个 `int` 的差之前先转成 `long`。是否允许修改输入、是否需要原下标和成绩范围，都应先确认，再选择排序或桶。

</details>

### 5.5 三数之和如何固定一项并去重，现场输入要确认什么？ {#three-sum-deduplication}

**考察重点**：固定一项后的有序排除、不同下标与重复数值、输入契约。

**相关内容**：[固定一项后的三数之和](#固定一项后的三数之和)、[现场输入与函数接口](#三数之和的输入约定)。

<details>
<summary>参考回答</summary>

**先排序，固定一项，再在它右侧用相向双指针；去掉重复结果，而不是删掉输入中的重复元素。** 和偏小右移左指针，和偏大左移右指针。外层跳过重复固定值，内层命中后移动两端并跳过相同值，保证三个不同位置组成的数值三元组只输出一次。

总时间 O(n²)。示例复制后排序，不修改输入，除结果外占 O(n) 空间；如果原地排序，会改变原数组顺序。空数组、不足三个数、全零和大量重复值都要检查，不能把 `[0,0,0]` 提前去重成一个 0。

现场先确认目标和、返回值还是下标、是否允许排序，再确认平台提供函数入参还是标准输入，以及长度、多组数据和输出格式。算法正确与输入处理正确是两件需要分别验证的事。

</details>
