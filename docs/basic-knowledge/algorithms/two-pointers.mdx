# 双指针

**双指针**是用两个位置在数组或链表上协调移动，让每个元素只被扫描常数次，从而把两层循环的 O(n²) 降到 O(n)。常见的形式有三种：从两端相向移动，同向一读一写，以及保持固定间距或不同速度。

双指针的代码很短，关键在于说清楚每次移动的依据：为什么移走这个指针不会错过答案，两个指针之间的区域代表什么。依据一旦依赖某个前提（比如数组有序），前提不成立时方法就不能用。

## 1. 面试核心 {#core}

- 有序数组上的相向双指针，根据两端之和的大小**每次排除一个端点**：和偏小就右移左端，和偏大就左移右端。**有序性保证被排除的组合不可能是答案**。[卡](#two-sum-sorted)
- 读写指针可以在保持顺序的前提下原地压缩数组：`read` 扫描原数组，**`write` 是有效前缀的长度**，写入始终发生在已经读过的位置。[卡](#read-write-prefix)
- 两个指针各自最多向前移动 n 次时，**总移动量是 O(n)**。

## 2. 相向移动的排除依据 {#相向移动的排除依据}

在升序数组里找两个数，使它们的和等于目标值。左指针从头开始，右指针从尾开始，每次看两端之和：

- 和偏小：当前左值加上目前最大的右值都不够，加上更小的右值就更不够了，所以当前左值不可能是答案的一部分，左指针右移。
- 和偏大：对称地，当前右值加上最小的左值都太大，右指针左移。

每一步都安全地排除一个元素，所以最多 n 步就能结束。

```java
static int[] twoSumSorted(int[] a, long target) {
    int left = 0, right = a.length - 1;
    while (left < right) {
        long sum = (long) a[left] + a[right];
        if (sum == target) return new int[]{left, right};
        if (sum < target) left++;
        else right--;
    }
    return new int[]{-1, -1};
}
```

`[1,2,4,7]`、`target=9` 时，`1+7` 偏小，左移；`2+7` 等于 9，返回下标 `[1,3]`。循环条件 `left < right` 保证用的是两个不同的位置。求和前先转成 `long`，两个 `int` 相加就不会溢出。时间 O(n)，额外空间 O(1)。

## 3. 同向指针与快慢指针 {#同向指针与快慢指针}

同向双指针中最常见的是**读写指针**：一个负责读输入，一个负责写输出。`read` 逐项读取，`write` 指向下一个可以写入的位置，有效结果始终保存在 `[0,write)` 里。因为 `write` 不会跑到 `read` 前面，写入只会覆盖已经读过的位置。

**快慢指针**是让两个指针以不同速度沿同一条链移动，常用于判断链表是否有环、找环的入口或中点。判环与入口的推导见[链表](../data-structures/linked-list.mdx#快慢指针与环入口)。

### 3.1 有序数组去重 {#有序数组去重}

```java
static int unique(int[] a) {
    int write = 0;
    for (int read = 0; read < a.length; read++) {
        if (write == 0 || a[read] != a[write - 1]) {
            a[write++] = a[read];
        }
    }
    return write;
}
```

数组有序，相同的值一定相邻，所以只要把 `a[read]` 和最后一个保留的值 `a[write - 1]` 比较，不同就写入。输入 `[1,1,2]` 返回 2，有效前缀是 `[1,2]`；数组 `write` 之后的内容不属于结果，可以忽略。

每一轮 `write` 最多比 `read` 多 1，写入位置 `write` 不超过 `read`，所以覆盖的总是已经处理过的元素。每项只读一次，时间 O(n)，空间 O(1)。

### 3.2 固定间距 {#固定间距}

单向链表不能从尾部往回数，要找倒数第 k 个节点，可以让两个指针保持固定的间距：快指针先走 k 步，然后两个指针同步前进，快指针走到末尾时，慢指针离末尾正好 k 步。

如果目的是删除这个节点，需要停在它的前驱上。在链表前加一个虚拟头节点，删除原来的头节点和删除其他节点就能走同一套逻辑。写代码前要先约定 k 的合法范围，以及两个指针从哪里出发，差一步就会停在错误的节点上。

## 4. 使用边界 {#使用边界}

相向双指针依赖有序性。无序数组里，和偏小时无法判断该排除哪个元素。可以先排序再用双指针，但排序需要 O(n log n)，而且会打乱原下标，题目要求返回原下标时还得额外保存；也可以直接用哈希表。

读写压缩必须先读出当前值，再覆盖已处理的位置。有序去重依赖相同的值相邻；数组无序时，要用额外的结构记录已经见过的值。

<summary>参考回答</summary>

### 5.3 如何用固定间距定位链表倒数第 k 项？ {#fixed-gap-kth}

<!-- 本题为本站原理自测，尚未核验对应公司面经，不作公司归属。 -->

**考察重点**：同步移动与前驱边界。

**相关内容**：[固定间距](#固定间距)。

<details>
<summary>参考回答</summary>

**让 `fast` 先从头走 k 步，再让 `fast` 和 `slow` 同步前进；`fast` 为空时，`slow` 就在倒数第 k 个节点。**

两者始终保持 k 步间距，因此 `fast` 走到链表末尾时即可确定 `slow` 的位置。k 必须在 1 到链表长度之间；若要删除该节点，还需保留 `slow` 的前驱。

</details>
