# 整数运算

**整数运算**首先要区分数值和表示：数学上的整数没有固定上限，机器整数受位宽限制，十进制字符串则只保存一串数字字符。输入超过 `uint64` 时，把字符串转成浮点数再算，会把范围问题变成精度问题。可以使用大整数类型；需要自己实现时，则把运算拆到每个数字位。

算法题的重点也不只是算出一个值。需要说明进位和余数怎样传递，数字顺序能不能改变，结果是否必须严格小于上界，以及零、负数和越界怎样处理。这些约定直接决定实现。

## 1. 面试核心 {#core}

- 整数的**位宽、符号和语言规则**共同决定运算结果；检查溢出应发生在危险运算之前，不能先溢出再比较。
- **整除与余数必须配套解释**。Python 的整除向下取整，Go 的整数除法向零截断；对负数不能直接互换。[卡](#power-two-remainder)
- 正整数是 2 的幂，当且仅当二进制只有一个 1；**`n > 0` 与 `n & (n-1) == 0` 缺一不可**。[卡](#power-of-two)
- 最大公约数满足 **`gcd(a,b)=gcd(b,a%b)`**，余数逐步缩小，直到除数为零。[卡](#gcd)
- 大整数加乘把数值拆成数字位，**每一步只处理当前数字和进位**；长除法则从高位向低位维护余数。[卡](#decimal-multiply) [卡](#decimal-division)
- 十进制转二进制可以**反复除以 2，倒序收集余数**；输入是长字符串时，每次除法也要计入成本。[卡](#decimal-binary)
- 受上界约束的数字构造要区分**前缀相等和已经变小**；数字是否可重复、能否有前导零、是否允许零，需要先约定。[卡](#digit-bound)
- 数位计数保存上界约束和数字是否开始；删除数字则保留原顺序，优先改善更高位。**两类问题的状态与选择条件不同**。[卡](#digit-count) [卡](#delete-digits)

## 2. 表示与输入约定 {#表示与输入约定}

十进制字符串 `"1203"` 表示 `1×10³ + 2×10² + 0×10 + 3`。从左到右读一位 d，当前数值由 x 变为 `10x+d`；从右到左运算，则要把当前位超过 9 的部分进到左边。

本文的字符串算术使用**非负十进制整数**：字符只允许 ASCII `0` 到 `9`，输入可以有前导零，输出统一去掉前导零，零写成 `"0"`。空串、符号、小数点和空格不在这个输入约定内。带符号的大整数需要另行管理符号，并补充绝对值比较、减法等操作。

规范化后，比较两个非负十进制字符串可以先比较长度；长度相等时，字典序就是数值顺序。不能直接用字典序比较不同长度的 `"99"` 和 `"100"`，也不能让前导零影响位数判断。

### 2.1 在运算前检查范围 {#在运算前检查范围}

假设要把非负数放进最大值为 M 的目标类型，已经读出的值为 x，准备接收数字 d。先确认 `0 ≤ d ≤ M`，再判断：

```text
x <= (M-d) // 10
```

成立时才计算 `10*x+d`。这与检查 `10*x+d <= M` 数学等价，但后者可能在做比较前已经溢出。进制为 B 时，把 10 换成 B，且数字必须满足 `0 ≤ d < B`。

Python 的 `int` 可以随数值增长，不按固定机器字自动回绕，但仍受资源限制。Go 的机器整数则有固定范围。更完整的补码与语言差异见[二进制数据表示](../computer-architecture/data-representation.mdx#表示范围与语言溢出)。下面涉及大数的复杂度，以数字位数衡量；不能把任意长度整数的运算一律当成常数时间。

## 3. 商、余数与二进制位 {#商余数与二进制位}

对非负整数 a 和正整数 b，整除得到商 q 与余数 r，满足 `a=q*b+r`，且 `0 ≤ r < b`。这个关系既是长除法的不变量，也是进制转换和欧几里得算法的基础。

带负号时要看语言规则。Python 3.12 的 `-5 // 3` 是 `-2`，`-5 % 3` 是 `1`；Go 1.22 的 `-5 / 3` 是 `-1`，`-5 % 3` 是 `-2`。两者都保持商余关系，但选择的商不同。Go 最小有符号整数除以 `-1` 还有结果溢出的特例，不能用同位宽正数表示其数学结果。

### 3.1 对二的幂求余 {#对二的幂求余}

对于非负整数，除以 `2^k` 的余数就是二进制低 k 位。因此，`x % 1024` 可以表示为 `x & 1023`，其中 1023 的低 10 位全是 1。

下面用 Go 展示适用条件：

```go
package main

import "fmt"

func main() {
    for _, x := range []int64{1025, -1} {
        fmt.Println(x, x%1024, x&1023)
    }
}
```

输出为 `1025 1 1` 和 `-1 -1 1023`。负数的 Go 余数与低位掩码不同，不能直接替换。Python 对正除数使用向下取整，`-1 % 1024` 恰好是 1023，但这是另一套商余规则。

位运算写法也不保证实际程序更快。编译器可能已经把常量除法和求余优化为位运算；需要先保持语义，再讨论具体编译结果与性能。

### 3.2 判断二的幂 {#判断二的幂}

正整数 n 减 1，会把最低位的 1 变成 0，并把它右边的 0 变成 1。因此，`n & (n-1)` 会清掉最低位的一个 1；结果为零，说明原来只有这一个 1。

判断式是 `n > 0 and (n & (n - 1)) == 0`。零必须排除，1 则应接受，因为 `1=2^0`。在固定宽度机器整数上，这只需要固定次数的位运算；在任意精度整数上，处理成本还与表示长度有关。

### 3.3 最大公约数 {#最大公约数}

**最大公约数**是同时整除两个整数的最大正整数。两者都是零时，没有最大的正公约数，本文按照 Python `math.gcd` 的接口约定返回零。**欧几里得算法**利用 `a=q*b+r`：能整除 a 和 b 的数，也能整除 r；能整除 b 和 r 的数，也能整除 a。因此，两组数的公约数集合相同。

```python
def gcd(a: int, b: int) -> int:
    a, b = abs(a), abs(b)
    while b:
        a, b = b, a % b
    return a


print(gcd(48, 18), gcd(-48, 18), gcd(0, 0))
```

输出 `6 6 0`。每次得到的非零余数都小于原除数，过程会终止。正数输入下，取余次数是对数级；大整数取余本身的成本仍需另算。Python 的 `abs` 不受固定字宽限制，移植到机器整数时，要特别处理最小负数无法在同一有符号类型中取正的情况。

## 4. 十进制字符串加乘 {#十进制字符串加乘}

**进位**是当前位无法容纳、需要转到更高位的部分。十进制加法中，当前位总和除以 10 的余数留在本位，商传给下一位。例如 `9+8+1=18`，当前位写 8，进位为 1。

乘法可以照着竖式进行：一个数字与另一个数字相乘，再加上目标位已有值和进位。每一步都把目标位规范到 0—9，避免把大量乘积一直堆在同一机器整数里。

下面是可独立运行的 Python 3.12 程序。输入为两行非负十进制字符串，输出乘积；`add_decimal` 同时提供后续舍入需要的加一操作：

```python
def canonical(text: str) -> str:
    if not text or any(c < "0" or c > "9" for c in text):
        raise ValueError("expected ASCII decimal digits")
    return text.lstrip("0") or "0"


def add_decimal(a: str, b: str) -> str:
    a, b = canonical(a), canonical(b)
    i, j, carry = len(a) - 1, len(b) - 1, 0
    result = []
    while i >= 0 or j >= 0 or carry:
        total = carry
        if i >= 0:
            total += ord(a[i]) - ord("0")
            i -= 1
        if j >= 0:
            total += ord(b[j]) - ord("0")
            j -= 1
        carry, digit = divmod(total, 10)
        result.append(chr(ord("0") + digit))
    return "".join(reversed(result))


def multiply_decimal(a: str, b: str) -> str:
    a, b = canonical(a), canonical(b)
    result = [0] * (len(a) + len(b))
    for i in range(len(a) - 1, -1, -1):
        carry = 0
        for j in range(len(b) - 1, -1, -1):
            k = i + j + 1
            total = result[k] + (ord(a[i]) - 48) * (ord(b[j]) - 48) + carry
            carry, result[k] = divmod(total, 10)
        result[i] = carry
    return "".join(chr(48 + d) for d in result).lstrip("0") or "0"


if __name__ == "__main__":
    a = input()
    b = input()
    print(multiply_decimal(a, b))
```

输入两行 `00012`、`003`，输出 `36`；`add_decimal("999", "1")` 返回 `"1000"`。程序没有把整个字符串转换成机器整数或 Python 大整数，只把单个 ASCII 字符转换为数字。

`result[k]` 和 `carry` 都不超过 9，单步 `total` 最大为 `9+9×9+9=99`。每轮内循环完成后，`result[i]` 是此前还没使用的更高位，可以直接写入剩余进位。长度分别为 m、n 的非零输入，竖式乘法需要 O(mn) 次数字运算、O(m+n) 额外空间；加法是 O(m+n)。这不代表所有大整数库都使用竖式乘法，库还可以按长度采用其他算法。

## 5. 长除法与小数位 {#长除法与小数位}

**长除法**从最高位开始处理，保留已经读过部分的余数。读到下一位 d 时，新的待除值是 `10*remainder+d`，它除以 divisor 的商就是当前商位。

因为此前 `0 ≤ remainder < divisor`，所以新商位一定在 0—9。以下函数复用上一节的 `canonical`：

```python
def divide_small(text: str, divisor: int) -> tuple[str, int]:
    text = canonical(text)
    if divisor <= 0:
        raise ValueError("divisor must be positive")
    quotient = []
    remainder = 0
    for c in text:
        digit, remainder = divmod(remainder * 10 + ord(c) - 48, divisor)
        quotient.append(chr(48 + digit))
    return "".join(quotient).lstrip("0") or "0", remainder


def decimal_quotient(text: str, divisor: int, round_half_up: bool = False) -> str:
    whole, remainder = divide_small(text, divisor)
    fraction = []
    for _ in range(2):
        digit, remainder = divmod(remainder * 10, divisor)
        fraction.append(chr(48 + digit))
    scaled = whole + "".join(fraction)
    if round_half_up and 2 * remainder >= divisor:
        scaled = add_decimal(scaled, "1")
    scaled = scaled.zfill(3)
    return canonical(scaled[:-2]) + "." + scaled[-2:]


print(divide_small("43242", 4))
print(decimal_quotient("1", 8), decimal_quotient("1", 8, True))
print(decimal_quotient("1999", 2000, True))
```

输出依次是 `('10810', 2)`、`0.12 0.13`、`1.00`。补小数位相当于在被除数末尾继续读入零；保留两位之后，余数表示还没输出的部分。若它至少达到 divisor 的一半，非负数的四舍五入需要给已经保留的数值加一，进位可能一直进入整数部分。

“保留两位小数”本身不足以决定算法。上面明确提供**截断**和**非负数四舍五入**两种方式，不涉及负数舍入、银行家舍入或无限循环小数的完整输出。必须根据题目或接口约定选择，不能先转成浮点数再依赖格式化碰巧得到正确结果。

若 divisor 在机器整数范围内，也不代表 `remainder*10` 一定安全。移植到固定宽度语言时，需要更宽的中间类型、受限的 divisor 范围，或能报告进位的多字运算。本例的中间整数由 Python 保存；在 divisor 位宽固定的模型下，处理 L 个输入位是 O(L)，结果空间也是 O(L)。

## 6. 进制转换 {#进制转换}

将非负整数除以 2，余数就是最低二进制位；对商继续除以 2，可以依次得到更高位。字符串输入超过机器整数范围时，重复使用长除法即可：

```python
def decimal_to_binary(text: str) -> str:
    text = canonical(text)
    if text == "0":
        return "0"
    bits = []
    while text != "0":
        text, remainder = divide_small(text, 2)
        bits.append(str(remainder))
    return "".join(reversed(bits))


print(decimal_to_binary("00013"))
print(decimal_to_binary("0"))
```

输出 `1101` 和 `0`。13 依次除以 2 得到余数 `1、0、1、1`，它们是从低位到高位取出的，所以最后要反转。

若输入有 L 个十进制位、输出有 K 个二进制位，算法进行 K 次长除法，每次最多扫描 L 位，总时间上界 O(LK)。十进制与二进制位数成比例，因此这是 O(L²) 的简单转换方案，不能因为只看到一个 `while` 就说是线性时间。当前商和输出占 O(L+K) 空间。

## 7. 受限数字构造 {#受限数字构造}

给定上界 S 和可用数字集合，构造严格小于 S 的最大整数，需要先确认：数字能否重复使用，是否必须使用全部数字，能否有前导零，是否允许零，以及无解怎样表示。

这里选择一个明确的版本：**每个数字可重复使用，不要求全部使用；结果无前导零，但允许单独的零；无解返回 `None`。** 输入上界是非负十进制字符串，数字集合是 0—9 中的整数。这些条件是参考实现的约定，不能从一句“用给定数字构造最大数”中自动推出来。

### 7.1 相等前缀与回退 {#相等前缀与回退}

同样位数的非负整数，先由最高不同位决定大小。只要已选前缀和 S 相同，下一位就不能超过 S 的对应位；一旦某位选得更小，后面全部填最大可用数字，就是这个前缀下的最大结果。

如果某位没有合法数字，或者最后拼出的数恰好等于 S，就向前回退：把最靠后的可降低数字换成更小的可用数字，再把后缀填满。越晚降低，保留的高位越大，所以优先从末尾回退。整个同长度方案失败后，再尝试少一位的最大数。

```python
def max_below(bound: str, digits: set[int]) -> str | None:
    bound = canonical(bound)
    if any(type(d) is not int or not 0 <= d <= 9 for d in digits):
        raise ValueError("digits must be integers from 0 to 9")
    allowed = sorted(str(d) for d in digits)
    if not allowed or bound == "0":
        return None
    prefix = []
    for i, limit in enumerate(bound):
        choices = [d for d in allowed if d <= limit and (i > 0 or d != "0")]
        if not choices:
            break
        chosen = choices[-1]
        prefix.append(chosen)
        if chosen < limit:
            return "".join(prefix) + allowed[-1] * (len(bound) - i - 1)

    while prefix:
        i = len(prefix) - 1
        previous = prefix.pop()
        choices = [d for d in allowed if d < previous and (i > 0 or d != "0")]
        if choices:
            return "".join(prefix) + choices[-1] + allowed[-1] * (len(bound) - i - 1)

    nonzero = [d for d in allowed if d != "0"]
    if len(bound) > 1 and nonzero:
        return nonzero[-1] + allowed[-1] * (len(bound) - 2)
    return "0" if "0" in allowed else None


print(max_below("23256", {2, 3, 9}))
print(max_below("1200", {1, 2}))
print(max_below("1000", {0, 1}))
```

输出 `23239`、`1122`、`111`。第二个例子在第三位遇到无法匹配的 0，回退降低第二位；第三个例子无法找到同长度的合法结果，改用三位数。

数字集合最多 10 个，每一位只被前进、回退有限次，选择成本 O(10L)，即 O(L)，额外空间 O(L)。如果每个数字只能使用有限次，后缀不能随意填最大数字，需要维护剩余次数；上面的代码和证明不能直接套用。

### 7.2 统计不含指定数字的整数 {#统计不含指定数字的整数}

要统计 `[1,n]` 中不含 4 和 7 的整数，逐个枚举可以作为小输入的核对方法，但 n 很大时，可以按位统计。**数位动态规划**保存已经选到哪一位，以及此前选择对后续造成的约束。

这个问题只需要两个状态：

- `tight`：当前前缀是否仍等于 n 的前缀；为真时，下一位不能超过 n 的对应位。
- `started`：是否已经选过第一个非零数字；为假时，当前零只是用来把短数字补到相同长度，不算实际数字的一部分。

下面按位更新状态数量，复用 `canonical`：

```python
def count_without_4_7(bound: str) -> int:
    bound = canonical(bound)
    states = {(True, False): 1}
    for c in bound:
        limit = ord(c) - 48
        next_states = {}
        for (tight, started), ways in states.items():
            for digit in range((limit if tight else 9) + 1):
                new_started = started or digit != 0
                if new_started and digit in (4, 7):
                    continue
                key = (tight and digit == limit, new_started)
                next_states[key] = next_states.get(key, 0) + ways
        states = next_states
    return sum(ways for (_, started), ways in states.items() if started)


print(count_without_4_7("20"))
print(count_without_4_7("0"))
```

输出 `16` 和 `0`。全程都没开始的路径代表数字零，最后排除，才能得到 `[1,n]` 而不是 `[0,n]` 的数量。不同前缀只要剩余约束相同，就可以合并计数；动态规划的状态设计原则见[动态规划](../java/algorithms/dynamic-programming-state-design.mdx#适用信号)。

每位至多 4 个状态、每个状态至多 10 种选择，转移次数是 O(L)。计数结果可能很大，若计算实际位运算成本，还要计入大整数加法；不能把“常数个状态”说成无限大的结果只占常数个字节。

## 8. 删除数字与顺序约束 {#删除数字与顺序约束}

从一个数字序列中删除 k 位，剩余顺序必须保持不变。目标是得到最大的剩余数，所以遇到更大的新数字时，可以优先删除它前面较小的数字，把大数字放到更高位。

栈保存当前保留的前缀。只要还有删除额度，且栈顶小于新数字，就弹出栈顶；扫描完成后仍有额度，则从末尾删除。新数字相等时不必删除前面的相同数字，应把额度留给后续更有用的位置。

```python
def max_after_removals(text: str, k: int) -> str:
    if not text or any(c < "0" or c > "9" for c in text):
        raise ValueError("expected ASCII decimal digits")
    if not 0 <= k <= len(text):
        raise ValueError("invalid deletion count")
    stack = []
    remaining = k
    for digit in text:
        while remaining and stack and stack[-1] < digit:
            stack.pop()
            remaining -= 1
        stack.append(digit)
    if remaining:
        del stack[-remaining:]
    return "".join(stack).lstrip("0") or "0"


print(max_after_removals("31452", 2))
print(max_after_removals("987", 1))
print(max_after_removals("001", 1))
```

输出 `452`、`98`、`1`。最后一个例子必须按原来的三位输入删除一位，不能先去掉前导零，否则就改变了题目允许删除的位置。这里返回规范化后的数值字符串；删除全部数字时约定返回 `"0"`。

贪心选择依据是最高不同位：在删除额度允许时，把较小的前位换成当前更大的数字，后面怎样选择都无法弥补高位的差距。每个数字最多入栈一次、出栈一次，总时间 O(L)、空间 O(L)。这是栈维护候选前缀的应用；累计操作次数的说明见[栈](../data-structures/stack.mdx#单调栈)。

## 9. 面试题 {#面试题}

### 9.1 怎样求两个整数的最大公约数，零和负数怎样处理？ {#gcd}

**考察重点**：商余不变量、终止条件和数值范围。

**相关内容**：[最大公约数](#最大公约数)。

<details>
<summary>参考回答</summary>

**反复用 `gcd(a,b)=gcd(b,a%b)` 缩小问题，直到 b 为零，返回 a。** 因为 `a=q*b+r`，两组数的公约数集合相同，且非零余数严格小于原除数。

可以先把输入转为非负数；一个输入为零时返回另一个的绝对值，两者都为零时需要接口约定，示例返回零。固定宽度有符号类型的最小负数不能直接在原类型中取正，需要扩大表示范围或单独处理。

</details>

### 9.2 怎样判断一个整数是否为 2 的幂？ {#power-of-two}

**考察重点**：最低有效位和正数约束。

**相关内容**：[判断二的幂](#判断二的幂)。

<details>
<summary>参考回答</summary>

**判断 `n > 0` 且 `n & (n-1) == 0`。** 正整数减一后，最低位的 1 被清掉，右边各位变成 1；按位与可以清掉原数最低位的一个 1。结果为零说明原数只有一个 1。零不是 2 的幂，1 是 `2^0`。

</details>

### 9.3 一个数对 1024 求余，可以直接用按位与吗？ {#power-two-remainder}

**考察重点**：位掩码、符号与语言商余规则。

**相关内容**：[对二的幂求余](#对二的幂求余)。

<details>
<summary>参考回答</summary>

**非负整数可以用 `x & 1023`，因为结果就是低 10 位。** 题目没有明确符号和类型时，应先确认。Go 的负数余数不能直接替换，例如 `-1 % 1024` 是 `-1`，按位与却得到 1023。还不能仅凭表达式判断速度，编译器可能已经优化了常量求余。

</details>

### 9.4 不把整个输入转换成大整数，怎样实现十进制字符串乘法？ {#decimal-multiply}

**考察重点**：位权、局部进位、前导零与输入输出。

**相关内容**：[十进制字符串加乘](#十进制字符串加乘)。

<details>
<summary>参考回答</summary>

**用数字数组模拟竖式，将每一对数字的乘积累加到对应位，并及时处理进位。** 示例只把单个 ASCII 字符转成 0—9，结果数组长度至多 m+n。每一步规范数字位，最后去掉前导零，并保留零结果。

还要根据题目补全读入和输出；正文采用两行非负十进制字符串，并不声称所有题目都使用这个格式。竖式方法时间 O(mn)、空间 O(m+n)，带符号输入还需要单独管理符号。

</details>

### 9.5 超过 uint64 的十进制字符串除以一个整数，怎样保留两位小数？ {#decimal-division}

**考察重点**：长除法、余数范围、舍入与中间值溢出。

**相关内容**：[长除法与小数位](#长除法与小数位)。

<details>
<summary>参考回答</summary>

**从高位到低位维护余数，用 `10*remainder+digit` 产生下一位商，再继续补零生成小数位。** 不能把完整输入或结果塞进 uint64，也不能用浮点数代替精确运算。

先约定符号、除零和舍入。正文采用非负被除数、正除数，支持截断或非负数四舍五入；保留两位后，若 `2*remainder >= divisor`，四舍五入需要加一，并处理进入整数部分的进位。固定宽度实现还要保证 `remainder*10` 不溢出。

</details>

### 9.6 怎样把十进制大数字符串转换成二进制字符串？ {#decimal-binary}

**考察重点**：长除法复用、余数位序与复杂度。

**相关内容**：[进制转换](#进制转换)。

<details>
<summary>参考回答</summary>

**对十进制字符串反复做除以 2 的长除法，收集余数，最后反转。** 余数从最低二进制位开始产生；输入零单独返回 `"0"`。

L 位十进制输入产生 K 位二进制输出，需要 K 轮长除法，总时间上界 O(LK)，在这两种固定进制间就是 O(L²)。完整输入不必转成机器整数。

</details>

### 9.7 用给定数字构造严格小于 S 的最大整数，怎样处理回退？ {#digit-bound}

**考察重点**：题设约束、前缀比较、贪心与无解边界。

**相关内容**：[受限数字构造](#受限数字构造)、[相等前缀与回退](#相等前缀与回退)。

<details>
<summary>参考回答</summary>

**先确认数字使用次数和前导零等规则；在可重复使用的版本中，尽量保持与 S 相同的前缀，一旦变小就用最大数字填满后缀。** 某位无合法选择，或最终等于 S 时，从末尾向前寻找可以降低的位置；同长度方案失败后，尝试更短的最大合法数。

数字只允许有限次使用时，需要记录剩余次数，不能直接复用本文的后缀填充。零是否允许、无解如何返回，也必须由题目约定。

</details>

### 9.8 怎样统计 1 到 n 中不含数字 4 和 7 的整数数量？ {#digit-count}

**考察重点**：数位状态、上界约束与前导零。

**相关内容**：[统计不含指定数字的整数](#统计不含指定数字的整数)。

<details>
<summary>参考回答</summary>

**按位统计，保存前缀是否仍等于 n，以及实际数字是否已经开始。** 仍相等时下一位受 n 限制；已经变小时可以选任意合法数字。前导零只用于对齐长度，实际数字位排除 4 和 7，结束后排除全零路径。

每位状态数和候选数字数都是常数，转移次数随位数线性增长；结果很大时仍需足够的计数表示。小范围可以用直接枚举核对端点和零的处理。

</details>

### 9.9 从数字序列删除 k 位，怎样让剩余数最大？ {#delete-digits}

**考察重点**：原顺序约束、最高位优先与剩余额度。

**相关内容**：[删除数字与顺序约束](#删除数字与顺序约束)。

<details>
<summary>参考回答</summary>

**用栈保存当前前缀，遇到更大的数字时，在删除额度允许的情况下弹出前面较小的数字。** 高位更大优先于低位的任何改善。扫描结束仍有额度，就从末尾删除；每位最多入栈和出栈一次，总时间 O(L)。

必须保留未删除数字的原顺序，不能排序。输入的前导零也占位置，不能在删除前先规范化；k 为零、删除全部和非法 k 的行为需要明确。

</details>
