# 贪心

**贪心**算法每一步只做当前看起来最好的一个选择，做完就不再回头，然后在剩下的问题上继续。它写起来通常很短，难点不在实现，而在证明：凭什么这一步选了它，最后的结果仍然是最优的。

贪心规则很容易「看起来对」，换一组输入就错。因此，既要用交换论证说明局部选择不会丢掉最优解，也要知道目标一变（比如区间带了权重），原来的规则为什么会失效。

## 1. 面试核心 {#core}

- 贪心的每一次选择都要**保留至少一个全局最优解**。常用交换论证来证明：把某个最优解的一步换成贪心的选择，结果仍然可行，目标值也不变。[卡](#greedy-proof)
- 无权区间调度**按结束时间升序选择**。结束得越早，留给后面的空间越大，最终能选出最多的互不重叠区间。
- 区间带上不同收益后，**最早结束的规则不再保证最优**。早结束的低收益区间可能挤掉高收益区间，这时要比较选与不选的总收益。[卡](#weighted-interval-counterexample)

## 2. 区间选择与交换论证 {#区间选择与交换论证}

问题是：给一组区间，选出尽可能多的互不重叠区间。这里区间写成 `[start,end)`，且 `start < end`，首尾相接（比如 `[1,3)` 和 `[3,5)`）算作不重叠。贪心规则是：按结束时间排序，每次选择与已选区间兼容、且结束最早的那个。

为什么这样选不会吃亏？用**交换论证**：假设存在一个最优解，它选的第一个区间是 B，而贪心选的第一个区间是 A。因为 A 是所有区间里结束最早的，A 的结束时间不晚于 B。最优解里 B 后面的区间都在 B 结束之后才开始，自然也在 A 结束之后。所以把 B 换成 A，不会和后面的区间冲突，区间数量也没变，所以换完仍然是一个最优解。

这样就得到一个包含 A 的最优解。去掉 A 以后，剩下的部分是同类问题，对它重复同样的论证，就能证明贪心每一步都没有偏离最优。

## 3. 区间调度实现 {#区间调度实现}

```java
static int maxIntervals(int[][] intervals) {
    java.util.Arrays.sort(intervals,
        (a, b) -> Integer.compare(a[1], b[1]));
    long end = Long.MIN_VALUE;
    int count = 0;
    for (int[] interval : intervals) {
        if (interval[0] >= end) {
            count++;
            end = interval[1];
        }
    }
    return count;
}
```

`end` 记录上一个选中区间的结束时间，初始化为 `Long.MIN_VALUE`，保证第一个区间一定能选上。只要当前区间的开始不早于 `end`，就和已选区间不冲突。

输入要求每项包含两个值，且 `start < end`。`[[1,3],[2,4],[3,5]]` 先选 `[1,3]`，跳过与它重叠的 `[2,4]`，再选 `[3,5]`，返回 2。排序耗时 O(n log n)，扫描是 O(n)。注意这个实现会直接改变输入数组的顺序，排序用的辅助空间取决于库的实现。

## 4. 权重与目标变化 {#权重与目标变化}

交换论证保住的是区间数量，没有保住收益。一旦目标变成最大收益，最早结束的规则就可能出错。

举个反例：A=`[0,2)` 收益 1，B=`[2,4)` 收益 1，C=`[0,4)` 收益 100。按最早结束会选 A 和 B，总收益只有 2；而只选 C 能拿到 100。把 C 换成 A 时，数量没少，收益却掉了很多，原来的论证在这里不成立。

带权区间调度要比较「选当前区间」和「不选」两种情况，用动态规划解决。按结束时间排序后，令 `p(i)` 为区间 i 之前最后一个与它兼容的区间，转移为 `dp[i]=max(dp[i-1],weight[i]+dp[p(i)])`：前者表示不选 i，后者表示选 i 并接上 `p(i)` 之前的最优结果。

## 5. 使用边界 {#使用边界}

不是所有「每次拿最大的」都成立。用面额 1、3、4 凑出 6，每次拿最大面额会得到 4+1+1，共 3 枚；最优解却是 3+3，只要 2 枚。所以任意面额的最少硬币问题，不能直接套用贪心，需要单独证明或改用动态规划。

一个反例足以否定一条贪心规则，但样例全部通过只说明这些输入没出错。要说明规则对所有合法输入都成立，需要交换论证、「贪心始终领先」这类完整的证明。

### 6.2 最早结束为何能最大化区间数量，却无法保证收益？ {#weighted-interval-counterexample}

**考察重点**：优化目标与交换证明边界。

**相关内容**：[权重与目标变化](#权重与目标变化)。

<details>
<summary>参考回答</summary>

**交换论证中替换第一个区间能保住数量，却会改变收益。**

最早结束的区间给后面留的空间最多，所以替换后数量不会减少。但收益不随结束时间变化：两个收益为 1 的短区间 `[0,2)`、`[2,4)` 会挤掉收益为 100 的长区间 `[0,4)`。带权问题需要比较选与不选，用加权区间调度的动态规划来解。

</details>
