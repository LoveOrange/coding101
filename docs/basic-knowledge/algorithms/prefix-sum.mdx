# 前缀和

前缀和预先保存从起点到每个位置的累计值，把静态区间求和变成两次前缀值相减。本文使用左闭右开的区间，前缀数组比原数组多一个元素。

## 1. 面试核心 {#core}

- prefix[0]=0，prefix[i+1]=prefix[i]+a[i]。
- 区间 [l,r) 的和为 prefix[r]−prefix[l]，单次查询 O(1)。
- 预处理时间和空间均为 O(n)；频繁修改时需要考虑其他结构。

## 2. 共同前缀抵消 {#mechanism}

`prefix[r]` 包含下标 0 到 r−1，`prefix[l]` 包含下标 0 到 l−1，相减后恰好剩下 l 到 r−1。

```java
static long[] prefix(int[] a) {
    long[] sums = new long[a.length + 1];
    for (int i = 0; i < a.length; i++) {
        sums[i + 1] = sums[i] + a[i];
    }
    return sums;
}
```

输入 `[2,-1,4]` 得到 `[0,2,1,5]`。区间 `[1,3)` 的和是 `5-2=3`，空区间 `[2,2)` 为 0。long 降低累计 int 数据时溢出的风险，仍需根据最大输入规模检查 long 是否足够。

## 3. 子数组和与哈希计数

如果某个区间和为 k，就有 `prefix[r]-prefix[l]=k`。扫描右端 r 时，可在哈希表中查找之前出现过多少个 `prefix[r]-k`。

初始记录前缀 0 出现一次，用来覆盖从下标 0 开始的区间。每步先查计数再加入当前前缀，避免把空区间算进去。重复前缀必须保存次数，不能只保存是否存在。负数不会破坏这个等式，因此这种方法能处理不满足滑动窗口单调性的输入。

## 4. 使用边界 {#boundaries}

普通前缀和适合数据固定、查询频繁的情况。修改一个位置会影响其后的全部前缀，最坏更新成本 O(n)。若更新和查询都多，可以按岗位需要学习树状数组或线段树。

区间最大值通常不能靠两个前缀最大值相减求出，因为 max 没有对应的逆操作。练习可使用现有[304. 二维区域和检索 - 矩阵不可变](../../leetcode/re-leetcode/arrays/leetcode-304.mdx)，先写出一维公式，再推导二维容斥。
