# 二叉树

**二叉树**是每个节点最多有两个孩子的树，而且两个孩子有次序之分，分别叫左孩子和右孩子。只有一个孩子时，它是左还是右也是树结构的一部分。

二叉树上的大多数操作都建立在遍历之上。要答好，需要能手推几种遍历的顺序，能说清遍历的时间和空间分别由节点数、树高和层宽决定，并且知道哪些遍历序列能唯一还原一棵树、为什么另一些不能。

## 1. 面试核心 {#core}

- 前序、中序、后序的区别只在于**根在什么时候访问**：分别在两棵子树之前、之间、之后。
- 遍历 n 个节点需要 O(n) 时间。递归 DFS 的额外空间是 **O(h)，取决于树高**；BFS 的额外空间**取决于最大层宽**。[卡](#traversal-complexity)
- **完全二叉树**除最后一层外都是满的，最后一层从左到右连续填充，所以可以紧凑地存进数组。
- 节点值互异时，**合法的前序和中序序列可以唯一重建二叉树**。[卡](#reconstruct-traversals)

## 2. 递归结构与遍历 {#递归结构与遍历}

二叉树天然是递归定义的：一棵非空二叉树由根、左子树和右子树组成，左右子树本身也是二叉树；空节点就是递归的终点。所以遍历也写成递归：处理根，再分别遍历左右子树，三种 DFS 遍历只是「处理根」这一步放的位置不同。

```text
    4
   / \
  2   7
   \
    3
```

- 前序（根、左、右）：`4,2,3,7`
- 中序（左、根、右）：`2,3,4,7`
- 后序（左、右、根）：`3,2,7,4`

注意 2 只有一个右孩子 3，中序时先访问 2（它的左子树为空），再访问 3。这个例子的中序正好是升序，因为这棵树同时满足二叉搜索树的条件；一般的二叉树中序不一定有序。键的顺序约束见[二叉搜索树](./binary-search-tree.mdx)。

除了这三种深度优先遍历，**层序遍历**（BFS）按层从上到下、每层从左到右访问，通常用队列实现，上图的层序是 `4,2,7,3`。

## 3. 高度与空间 {#高度与空间}

这里约定空树的高度为 0，叶节点的高度为 1。一个节点的高度是它较高那棵子树的高度加 1：`height(x)=1+max(height(x.left),height(x.right))`。每个节点只算一次，时间是 O(n)。

遍历的空间取决于同时要记住多少节点。递归 DFS 在任一时刻只保留从根到当前节点这条路径上的调用帧，所以空间是 O(h)。树的形状决定了 h：退化成链的树 h=n，平衡的树 h 是 O(log n)。

BFS 用队列保存待访问的节点，队列里同时最多有相邻两层的一部分节点，所以空间是 O(w)，w 是最大层宽。对完美二叉树来说，最底层有大约一半的节点，w 是 O(n)。所以同一棵树，DFS 和 BFS 哪个更省空间，要看它是又高又瘦还是又矮又宽。

## 4. 遍历序列重建 {#遍历序列重建}

给出前序和中序序列，并且节点值互不相同，就能唯一还原这棵树。思路是：前序的第一项一定是根；在中序里找到这个根，它左边的部分就是左子树，右边是右子树；左子树有几个节点，前序里紧跟根的那几项就属于左子树。这样就把问题拆成两个更小的同类问题，递归处理即可。

只有前序和后序则不够，因为它们分不清单孩子是在左边还是右边。比如前序 `1,2`、中序 `2,1`，说明 2 是根 1 的左孩子；如果中序是 `1,2`，2 就是右孩子。但这两棵树的后序都是 `2,1`，前序也都是 `1,2`，只看前序和后序无法区分它们。

实现时，先用哈希表记下每个值在中序里的下标，递归时传递区间的边界，而不是复制子数组。哈希表访问是期望 O(1) 时，总时间是 O(n)；如果每次都线性扫描中序去找根，退化成链时最坏是 O(n²)。如果有重复值，同一个值在中序里出现多次，就无法确定根的位置，需要额外的身份信息，或者接受重建结果不唯一。

## 5. 使用边界 {#使用边界}

几种「满」的说法容易混淆，需要分清：

- **完全二叉树**：除最后一层外都填满，最后一层从左到右连续填充。这种形状可以直接按层序存进数组，适合堆这样的结构。
- **完美二叉树**：所有层都填满，高度为 h 时有 `2^h-1` 个节点。
- **满分支二叉树**：每个节点有 0 个或 2 个孩子。

不同教材里的「满二叉树」有时指完美二叉树，有时指满分支二叉树，讨论时先确认用的是哪种定义。

二叉树还默认每个节点只有一个父节点，并且没有环。用树来表示真实的对象关系时，要先确认没有环、也没有被多个父节点共享的子节点；存在这些关系时，应该当作图来处理，否则遍历可能重复访问甚至停不下来。

## 6. 面试题 {#面试题}

### 6.1 二叉树遍历的时间与空间由什么决定？ {#traversal-complexity}

**考察重点**：节点数、树高和层宽。

**相关内容**：[高度与空间](#高度与空间)。

<details>
<summary>参考回答</summary>

**完整遍历的时间为 O(n)，DFS 的额外空间取决于树高 h，BFS 的额外空间取决于最大层宽 w。**

每个节点只处理一次，因此时间线性。递归 DFS 同时保存一条调用路径，空间为 O(h)，链状树可达 O(n)；BFS 保存待访问的一层节点，空间为 O(w)，完美二叉树可达 O(n)。

</details>

### 6.2 哪些遍历序列能唯一重建二叉树？ {#reconstruct-traversals}

<!-- 本题为本站原理自测，尚未核验对应公司面经，不作公司归属。 -->

**考察重点**：根定位、子树切分和单孩子歧义。

**相关内容**：[遍历序列重建](#遍历序列重建)。

<details>
<summary>参考回答</summary>

**节点值互异时，合法的前序加中序可以唯一重建；后序加中序也可以。**

前序的第一项（或后序的最后一项）确定根，根在中序里的位置把左右子树分开，再按子树大小切分另一个序列，递归处理。前序加后序不行，因为只有一个孩子时，无法判断它在左边还是右边。含重复值时，根在中序里的位置不唯一，需要额外的信息区分节点。

</details>
