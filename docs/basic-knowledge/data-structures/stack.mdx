# 栈

**栈**是按**后进先出**（LIFO）组织元素的结构：只能在栈顶放入和取出，最后放进去的最先被取出。它适合保存「开始了但还没结束」的状态：括号匹配、函数调用、撤销操作，都是越晚开始的越早结束。

栈的操作只有几个，题目的难点在于栈里该放什么、要维护什么不变量。括号匹配、最小栈和单调栈是三个典型例子，分别对应嵌套顺序、极值查询和「找下一个更大的元素」这类问题。

## 1. 面试核心 {#core}

- 栈按后进先出的顺序访问元素，**`push`、`pop`、`peek` 分别是入栈、出栈和查看栈顶**。
- 栈保存**尚未结束的嵌套顺序**。匹配多种括号时，右括号必须和**栈顶左括号的类型一致**，只比较数量不足以保证合法。[卡](#bracket-matching)
- 入栈时**同步记录每一层的最小值**，查询最小值就能做到 O(1)。[卡](#min-stack-duplicates)
- 单调栈里**每个元素最多入栈、出栈各一次**，总时间是 O(n)。[卡](#monotonic-stack)

## 2. 后进先出与待完成状态 {#后进先出与待完成状态}

括号匹配是栈最直接的应用：越晚出现的左括号，越早被右括号匹配。扫描时把左括号压栈，遇到右括号就和栈顶配对。

```java
static boolean balanced(String text) {
    java.util.Deque<Character> stack = new java.util.ArrayDeque<>();
    for (char c : text.toCharArray()) {
        if (c == '(') stack.push(c);
        else if (c == ')') {
            if (stack.isEmpty()) return false;
            stack.pop();
        }
    }
    return stack.isEmpty();
}
```

这段代码只检查圆括号，忽略其他字符。扫描过程中，栈里保存的是还没被匹配的左括号。遇到右括号时栈为空，说明它前面没有可以配对的左括号，直接返回 `false`；扫描结束栈不为空，说明有左括号没被关闭。所以 `(a())` 返回 `true`，`)(` 和 `(()` 都返回 `false`。时间 O(n)，最坏辅助空间 O(n)。

只有一种括号时，栈里的元素都一样，其实只需要一个计数器：遇到左括号加 1，右括号减 1。扫描过程中任何时刻计数都不能变成负数（对应「右括号前没有左括号」），结束时必须为 0。多种括号就不行了，要用栈记住每个未关闭括号的类型，原因见[面试题](#bracket-matching)。

## 3. 显式栈与调用栈 {#显式栈与调用栈}

递归调用本身就是在用栈：每次调用把当前的执行状态压进调用栈，返回时弹出，具体机制见[递归](../algorithms/recursion.mdx)。递归太深可能栈溢出时，可以改用**显式栈**，由程序自己保存待处理的项。

比如用显式栈做二叉树的前序遍历（根、左、右）：弹出一个节点并访问后，先压右孩子、再压左孩子。因为后进先出，左孩子会先被弹出处理，访问顺序正好是根、左、右。

## 4. 最小栈 {#最小栈}

**最小栈**要求在支持入栈、出栈的同时，能在 O(1) 时间取到当前所有元素的最小值。难点在于出栈以后最小值可能变化，重新扫描就不是 O(1) 了。

做法是用一个辅助栈和主栈同步：每次入栈时，辅助栈压入「此前的最小值」和「新值」中较小的那个；出栈时，两个栈一起弹出一层。这样辅助栈的每一层记录的都是「栈里到这一层为止的最小值」，辅助栈顶就是当前全部元素的最小值。查询最小值是 O(1)，额外空间是 O(n)。

依次压入 `2,1,1`，辅助栈保存 `2,1,1`。弹出最后一个 1 后，辅助栈顶仍是 1，因为另一个 1 还在栈里。有一种节省空间的写法是只在最小值变化时才往辅助栈压入。用这种写法时，遇到和当前最小值相等的新值也必须压入（或者记录次数），否则弹出第一个 1 时就会把最小值记录一起弹掉，误以为最小值变回了 2。

## 5. 单调栈 {#单调栈}

**单调栈**是栈内元素保持单调顺序的栈，常用来找每个元素左边或右边第一个比它大（或小）的元素。

以「找每个元素右侧第一个严格更大的值」为例。栈里保存还没找到答案的下标，它们对应的值从栈底到栈顶单调不增。读到一个新值时，只要它严格大于栈顶对应的值，栈顶元素的答案就是这个新值：弹出栈顶并记录答案，继续比较下一个栈顶。比较结束后，把新下标压栈，等待后面的值来回答它。

输入 `[2,2,3]` 时，两个 2 都留在栈里，直到 3 出现时依次弹出，答案都是 3。相等的值不能互相弹出，因为题目要求的是「严格更大」，一个 2 不是另一个 2 的答案。

一轮循环可能连续弹出很多元素，看起来是嵌套循环，但每个下标只入栈一次，出栈最多一次，所有轮次的弹出次数加起来不超过 n，所以总时间是 O(n)，空间最坏 O(n)。

## 6. 使用边界 {#使用边界}

Java 里通常用 `ArrayDeque` 当栈用。它不允许放入 `null`，对空栈调用 `pop` 会抛出异常；端点 API 在空容器上的具体行为见[队列](./queue.mdx#入队与出队)。栈占用的空间取决于同时有多少个状态还没处理完。

**数量相同时，类型的嵌套次序仍可能出错，例如 `([)]`。**

`([)]` 中圆括号和方括号各有一对，数量都对，但 `)` 出现时，最近一个还没关闭的是 `[`，类型不匹配。右括号必须和最近一个尚未匹配的左括号配对，栈正好保存了这个顺序：遇到右括号就检查栈顶的类型，扫描结束时还要检查栈是否为空。

### 7.2 最小栈遇到重复最小值时如何处理？ {#min-stack-duplicates}

<!-- 本题为本站原理自测，尚未核验对应公司面经，不作公司归属。 -->

**考察重点**：辅助状态与重复值生命周期。

**相关内容**：[最小栈](#最小栈)。

<details>
<summary>参考回答</summary>

**可以让辅助栈和主栈同步，每一层都保存当时的最小值。**

这样即使有重复的最小值，比如依次压入 `2,1,1`，弹出一个 1 后，辅助栈下一层仍然是 1，最小值不会出错。如果为了省空间只在最小值变化时压入辅助栈，那么遇到和当前最小值相等的值也要压入，或者维护一个计数，否则弹出第一个 1 时就会丢掉另一个 1 的记录。

</details>

### 7.3 单调栈中嵌套弹栈为何仍为 O(n)？ {#monotonic-stack}

<!-- 本题为本站原理自测，尚未核验对应公司面经，不作公司归属。 -->

**考察重点**：待回答集合与累计操作次数。

**相关内容**：[单调栈](#单调栈)。

<details>
<summary>参考回答</summary>

**每个下标最多入栈一次、出栈一次，所有轮次加起来的操作次数是 O(n)。**

某一轮可能连续弹出很多元素，但被弹出的元素已经得到答案并离开栈，之后不会再被处理。所以不能按「外层 n 次 × 内层最多 n 次」估算，而要看每个元素一生中被操作的总次数。以「右侧第一个严格更大的值」为例，只有新值严格大于栈顶时才弹出，相等的值留在栈里。

</details>
