# 图

**图**由顶点和连接顶点的边组成，用来表示「谁和谁有关系」：道路连接城市，课程之间有先修依赖，游戏里一个状态可以转换到另一个状态。树和链表都可以看成特殊的图。

图的题目千变万化，但底层问题很集中：边有没有方向、有没有权重；用邻接表还是邻接矩阵存储，成本有什么差别；搜索时怎样避免重复访问；以及「连通」在无向图和有向图里分别是什么意思。边权决定了该用哪种最短路算法。

## 1. 面试核心 {#core}

- **邻接表**的空间是 **O(V+E)**，适合边比较少的稀疏图；**邻接矩阵**的空间是 **O(V²)**，但能在 **O(1) 时间判断一条边是否存在**。[卡](#adjacency-list-vs-matrix)
- 无向图按「能否互相到达」划分成若干**连通分量**。从一个起点完整搜索一次，能找出它所在的分量；再从还没访问过的顶点继续搜索，就能遍历所有分量。
- 有向图的**强连通要求双向可达**。从一个起点单向搜索，只能得到它能到达的顶点集合。[卡](#directed-connectivity)
- 最短路算法取决于边权：**边权都相等时用 BFS**，**非负权用 Dijkstra**。

## 2. 顶点、方向与权重 {#顶点方向与权重}

边的方向和权重要按问题的含义来定。课程 A 是 B 的先修课，这种关系是单向的，用有向边 A → B 表示。双向通行的道路用无向边，单行道用有向边。如果每条路的长度不同，就给边加上权重；这时「经过的边最少」和「总距离最短」是两个不同的目标，答案可能不一样。

图最常见的两种存储方式是邻接表和邻接矩阵。**邻接表**为每个顶点保存一个邻居列表：

```text
0: [1, 2]
1: [2]
2: []
```

这是一个有向图，边为 0→1、0→2、1→2。要判断 0→2 是否存在，需要线性扫描 0 的邻居列表，成本是 O(deg(0))，deg 表示顶点的出度，也就是从它出发的边数。

**邻接矩阵**用一个 V×V 的表格，第 i 行第 j 列表示是否有边 i→j。查边只要读一个格子，是 O(1)；代价是无论边有多少，都要存 V² 个位置。顶点很多而边很少时，矩阵里绝大部分是空的，很浪费。

## 3. 搜索与访问状态 {#搜索与访问状态}

在邻接表上做一次完整的 BFS 或 DFS，每个顶点访问一次，每条边检查一次，耗时 O(V+E)。换成邻接矩阵，找一个顶点的邻居要扫描整行，完整搜索就变成 O(V²)。无向图的每条边在两端的邻居列表里各存一次，空间仍是 O(V+E)。

和树不同，图里可能有环，也可能有多条路径通向同一个顶点。如果不记录哪些顶点已经访问过，搜索会反复扩展同一个顶点，遇到环甚至停不下来。BFS 通常在入队时就标记为已访问，这样同一个顶点不会被多次放进队列。具体实现见[树与图搜索](../java/algorithms/trees-graphs-search.mdx#visited-标记时机)。

## 4. 连通分量与可达性 {#连通分量与可达性}

在无向图里，如果两个顶点之间有路径，它们就能互相到达。**连通分量**是一组互相可达的顶点，并且不能再加入别的顶点。从一个顶点出发搜索，能访问到的正好是它所在的整个连通分量。所以统计分量数的方法是：依次检查每个顶点，遇到还没访问过的，就从它开始搜索一次，计数加 1。

有向图要区分三个概念：

- **可达**：从 u 出发沿边的方向能走到 v。
- **弱连通**：忽略边的方向后是连通的。
- **强连通**：分量内任意两个顶点都能互相到达。

以只有一条边 0→1 的图为例：0 能到 1，1 却回不到 0。忽略方向后它们是连通的，所以这是一个弱连通分量；但它们不能互相到达，所以是两个强连通分量。

因此，在有向图上照搬无向图的「从未访问顶点开始搜索并计数」，得到的数字会随起点顺序变化，不能当作弱连通分量数，也不能当作强连通分量数。求强连通分量需要专门的算法，比如 Tarjan 或 Kosaraju，按岗位需要学习即可。

## 5. 使用边界 {#使用边界}

很多题目没有直接给出图，而是一个**隐式图**：顶点是某种状态，边是合法的状态转换。这时要先定义状态的身份（什么情况下算同一个状态）和每个状态有哪些合法邻居。比如网格题里，顶点可以用行列坐标表示，邻居是上下左右可走的格子。需要枚举所有路径时，访问状态要在返回时恢复，做法见[回溯](../algorithms/backtracking.mdx)。

求最短路时，按边权选择算法：

| 边权与目标 | 方法与条件 |
| --- | --- |
| 等正权最短路 | BFS 按边数扩展。 |
| 0 或 1 权重 | 0-1 BFS 用双端队列维护距离顺序。 |
| 非负权最短路 | Dijkstra 按当前最小距离扩展。 |
| 含负权最短路 | Bellman-Ford 可检测源点可达的负环。 |

BFS 一层一层向外扩展，每层多走一条边，所以只有所有边权都相等时，先到达就意味着最短。Dijkstra 每次确定当前距离最小的顶点，依赖「后面再走只会更长」，有负权边时这个前提就不成立了。

负权还可能形成**负环**，也就是一圈边权之和为负的环。如果从源点能到达一个负环，并且从负环还能走到目标，每多绕一圈路径代价就更小，源点到目标就不存在有限的最短距离。

## 6. 面试题 {#面试题}

### 6.1 邻接表和邻接矩阵如何选择？ {#adjacency-list-vs-matrix}

**相关内容**：[顶点、方向与权重](#顶点方向与权重)。

<details>
<summary>参考回答</summary>

**稀疏图适合邻接表，空间是 O(V+E)；需要频繁判断边是否存在、并且放得下 V² 空间时，适合邻接矩阵。**

邻接矩阵查边只需读一个格子，是 O(1)，但无论边多少都要占 O(V²) 空间。邻接表查边要扫描邻居列表，成本是该顶点的出度。完整遍历时，邻接表是 O(V+E)，邻接矩阵要逐行扫描，是 O(V²)。

</details>

### 6.2 有向图从一个起点搜索后，能得到强连通分量吗？ {#directed-connectivity}

<!-- 本题为本站原理自测，尚未核验对应公司面经，不作公司归属。 -->

**考察重点**：单向可达与相互可达。

**相关内容**：[连通分量与可达性](#连通分量与可达性)。

<details>
<summary>参考回答</summary>

**不能。一次搜索只得到起点能到达的顶点集合，这些顶点之间不一定能互相到达。**

只有一条边 0→1 的图就是反例：从 0 出发能访问到 1，但 1 回不到 0，它们属于两个不同的强连通分量。强连通分量要求任意两点互相可达，需要用 Tarjan 或 Kosaraju 这类专门的算法。

</details>

### 6.3 边权改变时，最短路径算法如何选择？ {#shortest-path-weight}

<!-- 本题为本站原理自测，尚未核验对应公司面经，不作公司归属。 -->

**考察重点**：等权、非负权与负环。

**相关内容**：[使用边界](#使用边界)。

<details>
<summary>参考回答</summary>

**边权都相等用 BFS，边权只有 0 和 1 用 0-1 BFS，一般非负权用 Dijkstra，含负权用 Bellman-Ford。**

BFS 按边数一层层扩展，只在边权相等时等价于最短距离。Dijkstra 依赖「已确定的最小距离不会再被更新」，负权边会破坏这一点。Bellman-Ford 能处理负权，并能检测从源点可达的负环；如果负环还能通往目标，就不存在有限的最短距离。

</details>
