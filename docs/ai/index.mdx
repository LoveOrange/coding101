# AI 应用与 Agent

AI 应用与 Agent 栏目介绍大模型应用和智能体开发的核心知识。它面向准备 Agent 开发、LLM 应用开发，以及允许使用 AI 编码的面试的读者。

你可以在这里学习模型调用、上下文管理和检索，再了解工具执行、任务状态、评估与安全。各主题提供原理文章和面试练习，帮助你解释机制，并结合任务判断怎样设计应用。

题目来自 2025-07 至 2026-09 公开的 167 篇候选人复盘。公司信息只说明候选人曾公开记录相关提问。

:::info 阅读顺序

先理解模型怎样提出动作、程序怎样执行并返回结果，再按岗位要求补充工具、上下文和评估。

建议从[工作流与 Agent](./agents/workflow-vs-agent.mdx)和 [Agent 执行循环](./agents/agent-loop.mdx)开始。

面试只考 AI 辅助编码时，从 [AI 辅助开发](./development/ai-assisted-development.mdx)开始。

:::
