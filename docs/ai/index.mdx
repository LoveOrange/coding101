# AI 应用与 Agent

AI 应用与 Agent 覆盖模型调用、上下文、检索、工具执行、状态、评估和安全，面向 Agent 开发、LLM 应用开发和允许使用 AI 编码的面试。题目来自 2025-07 至 2026-09 公开的 167 篇候选人复盘，公司信息只说明候选人曾公开记录相关提问。

:::info 阅读顺序

先读[工作流与 Agent](./agents/workflow-vs-agent.mdx)和 [Agent 执行循环](./agents/agent-loop.mdx)，确定“模型提出动作、程序执行动作”这条主线；再按岗位补工具、上下文和评估。面试只考 AI 辅助编码时，从 [AI 辅助开发](./development/ai-assisted-development.mdx)开始。

:::
