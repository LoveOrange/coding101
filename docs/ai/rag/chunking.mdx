# 文档解析与切分

文档解析保留文本结构，切分生成可检索的片段。本文负责解析策略、块边界、父子索引和表格处理。召回机制见 [Embedding 与向量检索](./embedding-vector-search.mdx)。切分组件行为核对日期为 2026-10-13。

## 1. 面试核心 {#core}

- 块大小同时影响检索匹配、语义完整性和上下文预算。[卡](#chunk-size)
- 结构切分保留标题与段落，超长部分再递归细分。[卡](#chunk-size)
- 重叠补充边界信息，也增加索引体积和重复召回。[卡](#chunk-size)
- 父子索引检索子块，再回取父块作为回答依据。[卡](#parent-child-index)
- 表格切分应保留表头、单位和行列关系。[卡](#heterogeneous-documents)

## 2. 解析 {#解析}

| 文件类型 | 解析要点 |
| --- | --- |
| Markdown、HTML | 保留标题层级，去除导航与页脚。 |
| 文字 PDF、Word | 恢复阅读顺序，处理分栏与跨页段落。 |
| 扫描件 | OCR 后检查数字、单位和版面。 |
| 表格、Excel | 保留表头、单元格和行列关系。 |
| PPT | 关联页标题、正文与备注。 |
| 代码 | 保留函数、类、文件路径与符号名。 |

解析错误会直接污染后续检索。数字顺序被打乱后，重排也难以恢复原表。重复页眉会让多个块混入相同噪声。应抽查原文件与解析结果，尤其是表格和扫描件。

## 3. 切分策略 {#切分策略}

| 策略 | 做法 | 取舍 |
| --- | --- | --- |
| 固定长度 | 按长度截取 | 实现简单，语义边界容易断开。 |
| 递归切分 | 依次尝试段落、句子等分隔符 | 保留结构，同时限制长度。 |
| 结构切分 | 按标题、条款或函数划分 | 需要可靠的结构解析。 |
| 语义切分 | 根据相邻片段的语义变化划分 | 增加向量计算，边界仍需评测。 |

### 3.1 块大小与重叠 {#块大小与重叠}

块过小会缺少主语、条件和例外。块过大则混入其他主题，并占用更多提示空间。问题需要的证据跨度，是选择大小的重要依据。

重叠让边界两侧重复一段内容。它有助于保留跨边界关系，但会增加重复候选。重叠比例应作为待测参数，和零重叠一起比较。

长度单位要明确写成字符或 Token。按 Token 限长时，使用目标模型的分词器。上下文前缀也需要计入长度。超过模型限制后的行为取决于接口。部分服务报错，部分本地组件按配置截断。

比较切分方案时，固定文档快照和问题集。统计证据覆盖率、回答正确率与重复占比。块大小变化后，评测应按原文证据区间对齐。

### 3.2 块上下文补充 {#块上下文补充}

孤立片段会丢失指代对象。例如“上述费用由乙方承担”，需要前文定义费用。块前可以附上文档标题与章节路径。

模型生成的上下文说明可以补充主题。生成说明应与原文分开保存，并经过抽查。向量化时可使用说明，引用时仍定位原文。来源、版本、权限和页码放入元数据。

## 4. 父子索引 {#父子索引}

父块保存较完整的段落或章节。子块保存其中的细粒度内容，并记录父块 ID。检索命中子块后，再从文档存储读取父块。

```text
父块：差旅费用
  子块 A：住宿标准
  子块 B：交通工具等级
  子块 C：报销时限
命中子块 A → 读取父块及原文位置
```

子块负责匹配，父块补充回答条件。多个子块命中同一父块时，需要去重。父块超出预算时，可只扩展相邻片段。回取父块仍需检查版本和权限。

## 5. 表格与异构文档 {#表格与异构文档}

小表格可以整体作为一个块。大表格按行分组，每组重复表头和单位。跨页表格应保留连续关系。合并单元格表达的分组信息也要传给各行。

Excel 的求和、同比和排序应使用确定性计算。向量检索可帮助定位表与字段。具体数值由 SQL 或计算工具返回。

制度文档按章、条、款组织。块内保留条款编号、生效日期和版本。混合 PDF 应分别处理文字、表格和图像。图像描述用于检索时，应保留对应页图。

### 5.1 跨块证据与原文定位 {#跨块证据与原文定位}

正文、脚注和例外条款经常分处不同位置。仅靠相邻重叠无法保留所有关系。解析时可记录标题路径和引用条款 ID。命中主体条款后，再补取其明确引用的内容。

每块应记录文档 ID、版本和原文区间。页码便于定位，字符偏移或段落 ID 便于精确引用。切分策略变化时，旧块 ID 也需随版本区分。索引发布与删除机制见[检索增强生成（RAG）](./rag.mdx#知识更新)。
