# 文档解析与切分

文档解析把各种格式的文件转换成带结构信息的文本，切分再把文本分成适合检索的块。块是 RAG 检索和放入上下文的基本单位，切得太大会混入无关内容，切得太小会丢失上下文。本文讲切分策略、块大小与重叠、父子索引，以及表格和异构文档的处理。

## 1. 面试核心 {#core}

- 块大小是在“检索精度”和“上下文完整性”之间取舍：小块与问题匹配更精确，但缺少前后文；大块信息完整，但向量被无关内容稀释，占用更多上下文。[卡](#61-chunk-的切分大小如何确定重叠度如何设置分块过大或过小会有什么问题)
- 优先按文档结构切分（标题、段落、列表、代码块），超长部分再按长度细分；固定长度硬切会把句子、表格和条款切断。
- 重叠用于减轻边界处信息被切断，一般取块长的 10%–20%；参数要在评测集上对比，而不是凭经验固定。
- 父子索引用小块检索、返回大块：检索精度来自小块，回答所需的上下文来自父块。[卡](#62-rag-为什么需要父子索引检索小块返回父文档解决什么问题)
- 表格、Excel、扫描件、PPT 需要不同的解析方式；每个块都要带来源、章节、版本、权限等元数据。[卡](#63-知识库中有制度文档excel-报表pdf-等不同文件应该怎么解析和切分)

## 2. 解析 {#parsing}

| 文件 | 处理要点 |
| --- | --- |
| Markdown、HTML | 保留标题层级，按标题分节；去除导航、页脚 |
| Word、PDF（文字版） | 抽取文本和标题样式；处理页眉页脚、分栏、跨页段落 |
| 扫描件、图片 | OCR；版面分析识别标题、段落、表格区域 |
| 表格、Excel | 保持行列关系，不能按字符切断；见下文 |
| PPT | 每页作为单元，合并标题、正文和备注 |
| 代码 | 按函数、类切分，保留文件路径和符号名 |

解析质量直接决定检索上限。PDF 中的表格被抽成一串无序数字、页眉“内部资料”在每个块中重复出现，后续任何检索优化都难以弥补。

## 3. 切分策略 {#strategies}

| 策略 | 做法 | 适用 |
| --- | --- | --- |
| 固定长度 | 每 N 个 Token 切一刀 | 无结构纯文本；实现最简单，容易切断语义 |
| 递归切分 | 按段落 → 句子 → 字符的分隔符逐级尝试，直到长度满足 | 通用默认方案 |
| 结构切分 | 按标题、章节、条款、函数切分 | 有清晰结构的文档、法规、代码 |
| 语义切分 | 计算相邻句子的向量相似度，在相似度明显下降处切分 | 结构不明显的长文本，成本较高 |

### 3.1 块大小与重叠

- **问题类型决定大小**：事实型问答（“年假几天”）答案在一两句话中，小块（数百 Token）更精确；需要理解整段规则或流程的问题，块要更大。
- **Embedding 模型的输入上限**：超过模型最大长度的部分会被截断，后半段内容无法被检索到。
- **重叠**：相邻块重复 10%–20% 的内容，减少答案正好落在边界的情况。重叠会增加索引大小和召回结果中的重复内容。
- **评测确定参数**：准备一组问题和对应的正确段落，比较不同块大小、重叠下的召回率和最终回答正确率。

### 3.2 给块补充上下文

孤立的块可能缺少主语：“上述费用由乙方承担”中的“上述费用”在上一块。常用补充方式：

- 在块前拼接文档标题和章节路径，如“《采购管理制度》> 第三章 费用 > 3.2”。
- 用模型为每个块生成一句说明它在全文中位置和含义的上下文，再与块一起向量化。
- 元数据中保存来源、页码、版本、权限，用于过滤和引用。

## 4. 父子索引 {#parent-child}

父子索引把文档切成两级：父块是完整的章节或较大段落，子块是从父块中再切出的小段。只对子块建向量索引；检索命中子块后，返回它所属的父块给模型。

```text
父块：3.2 差旅费用（约 1500 Token）
 ├─ 子块：国内出差住宿标准……（约 200 Token）  ← 与问题匹配
 ├─ 子块：交通工具等级……
 └─ 子块：报销时限……
命中子块 → 返回整个父块
```

它解决了“小块检索准、大块回答全”的矛盾。多个子块命中同一父块时需要去重；父块过大时会占满上下文，可以只返回命中子块及其前后相邻的子块。

## 5. 表格与异构文档 {#tables}

- **表格**：小表格整体作为一个块，转成 Markdown 表格保留表头；大表格按行分组，每组都重复表头。也可以把每一行转成“字段: 值”的描述文本，便于语义检索。
- **Excel 报表**：数值计算类问题（求和、同比）不适合靠向量检索回答，应该把数据导入数据库，用 SQL 工具查询；向量索引只存表的说明和字段含义，用于找到该查哪张表。
- **制度文档**：按章、条、款的结构切分，块中保留条款编号和制度版本、生效日期，检索时过滤失效版本。
- **混合 PDF**：版面分析区分正文、表格、图片；图片可以用多模态模型生成文字描述后入库。
