UTM 命名规则与示例

四项必填，统一小写英文、数字和下划线；标签发布后保持稳定。

  • 来源 utm_source：zhihu、juejin、wechat、xiaohongshu、bilibili、newsletter、github。
  • 媒介 utm_medium：免费社交分享 social，邮件 email，站外合作链接 referral；付费社交 paid_social，付费搜索 cpc。
  • 活动 utm_campaign：c101_年月_主题_目标，例如 c101_202610_java_interview_trial；跨平台使用同一个活动名。
  • 内容 utm_content：形式_主题_位置_版本，例如 article_hashmap_footer_v1；微信社群可以使用 text_java_group01_v1。

示例：https://coding101.linsama.com/topics?utm_source=zhihu&utm_medium=social&utm_campaign=c101_202610_java_interview_trial&utm_content=article_hashmap_footer_v1

只在站外推广链接使用，不填写个人信息。完整命名规则与链接登记模板见仓库 plans/utm-conventions.md。

接入方法与统计边界
  1. 在本机配置文件中填写两个独立只读数据库连接，以及 GA4 数字 Property ID 和服务账号密钥文件路径。不要把密钥提交到仓库。
  2. 运行 npm run ops:collect 更新汇总。看板每分钟重读本地结果；“刷新视图”不会发起数据库查询。
  3. 每日汇报任务调用同一采集脚本。运行机器必须在线，且能访问凭证和数据源。

详细权限 SQL 和接入步骤见仓库 plans/operations-dashboard.md。
